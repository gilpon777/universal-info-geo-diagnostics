# 関連研究・既存ツールと本フレームワークの位置づけ

本フレームワークは、Fisher 情報行列（FIM）の固有値診断や最適実験計画という
確立した部品の上に立つものであり、それらの再発明を主張しない。
ここに主な先行例と、本フレームワークとの差分を明記する。

## 先行例

- **最適実験計画（OED）と PyOED** — FIM の A/D 最適基準やセンサー配置選定は
  実験計画法の古典であり、PyOED（Attia ら, ACM Trans. Math. Softw. 50, 2024）は
  ベイズ逆問題とデータ同化までを含む包括的な Python 実装である。
  本フレームワークより遥かに広範で重厚。
- **Pyomo.DoE** — 方程式指向モデルに対する実験計画。FIM の固有値基準
  （E 最適、条件数に基づく ME 最適など）を扱う。
- **Sloppy モデルと SloppyCell** — 固有値スペクトルが何桁にも広がる「sloppy」な
  構造の概念は Sethna グループ（Gutenkunst et al. 2007; Daniels et al. 2008）が
  システム生物学で確立し、SloppyCell がその解析ツールである。
  本フレームワークの r_eff は Roy & Vetterli の実効ランクのエントロピー版である。
- **分野特化 Fisher コード** — 重力波の GWFish / GWFast / GWBench、宇宙論の
  各種予測コードなど、波形・観測モデルが分野内に閉じた Fisher 実装は多数ある。
- **大域感度解析（SALib など）** — Sobol 指数等は別の系統（大域・分散ベース）であり、
  本フレームワークの局所・情報幾何アプローチとは相補的。

## 本フレームワークの差分

1. **ブラックボックス前提の軽さ**: モデル関数とノイズ共分散だけで動く単一クラス。
   分野の観測モデルや事前分布の枠組みを要求しない。
2. **Raw / Scaled の併記**: 単位依存の生スペクトルと、スケーリング不変な
   相関化スペクトルを常に対で返し、単位の取り方に騙されない（v2）。
3. **絶対量の申告（v3）**: スケールフリーな r_eff と並べて、方向 SNR・
   クラメール・ラオ σ・目標 SNR までの情報倍率を返す。「形は決まるが
   絶対量が桁で足りない」事態を、診断自身が言語化する。
4. **吸収の周辺化（v3）**: フィットで吸収される線形 nuisance（検出器ごとの
   振幅など）を診断段階でプロファイル／周辺化し、潰れる方向を先に示す。
5. **注目点の勝因内訳（v3）**: 貪欲選定の各ピックに、勾配で勝ったか
   ノイズ構造で勝ったかの内訳とマージンを付ける。順位表の「読み方」を
   出力に含めた。
6. **応用**: 宇宙ボイド内部の観測点選定という、作成者自身の観測構想が
   出発点であり、公開データ（VAST ボイドカタログ、GWOSC）での検証一式が
   `results/` に同梱される。
