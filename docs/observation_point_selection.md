# 観測点の選定 ― このフレームワークの主用途

このフレームワークは、**観測者が自分で選べる通常の観測**のために
作られた。「どこを測るか」を実測の前に数値で決めるための物差しで、
重力波のようなイベント待ちの観測は本来の対象ではない
（ボイド＋重力波の検証は、この物差しの応用として後から乗せたもの）。

## 使い方の型

必要なのは2つだけ:

1. **モデル関数** θ → 予測値（候補となる観測点すべての予測）
2. **ノイズ共分散** Σ（各観測点の測定ノイズ）

これを与えると、フレームワークは次を返す:

- どのパラメータの組み合わせがその観測で決まるか（r_eff、スペクトル）
- 決まる方向ごとの絶対量（方向 SNR、Cramér–Rao σ、目標までの情報倍率）
- どの観測点から測るべきか（貪欲選定。各選定に「勾配で勝ったか、
  ノイズ構造で勝ったか」の勝因と、次点とのマージンつき）
- フィットで吸収されてしまう邪魔者成分の除去（nuisance の射影）

## 「観測点」は題材ごとに姿を変える

| 題材 | 観測点 | 知りたいパラメータ | 実行例 |
|---|---|---|---|
| 宇宙ボイドのプロファイル | 動径ビン | プロファイル形状（δc, rs, α, β） | `demo_v3.py`、`results/` |
| 反応速度論 | 測定時刻 | 速度定数 k1, k2, k3 | `example_biochem.py` |
| 粉末の組成分析 | 分光チャンネル | 成分分率 | `example_powder.py` |
| ボイドの内容物 | 波長帯（電波〜X線） | 成分ごとの放射量 | `example_wavelength_void.py` |
| 銀河の SED 分解 | 波長帯（測光バンド） | 星・塵・AGN の振幅 | `example_wavelength_sed.py` |
| 天の川の回転曲線 | 銀河半径の測定点 | 円盤・ハローのパラメータ | `results/reports/milkyway_validation.md` |

望遠鏡の向け先、露光を配分するバンド、センサの配置、サンプリング
時刻など、「候補が列挙できて、各候補の予測値とノイズが書けるもの」
なら同じ型に乗る。

## 自分の観測に当てる手順

1. 候補の観測点を全部並べ、各点の予測値を返す関数を書く
   （ブラックボックスでよい。解析式でなくシミュレータでもよい）。
2. 各点のノイズを見積もる（装置の感度、既存データのばらつきなど）。
3. `evaluate` で全体像（何が決まり、何が決まらないか）を見て、
   `greedy_select` で測る順序と最小集合を得る。
4. 選定の勝因（driver）とマージンを確認する。マージンが ~1 の
   選定は「ほぼ同点」であり、実務上の都合で入れ替えてよい。
   ノイズで勝っている点は、ノイズ見積もりが変わると順位が
   動くので、その前提を明記して使う。

## 限界（先に読んでほしい）

- 診断は評価点 θ の近傍の局所線形化。θ を動かせば順位は変わりうる。
- ノイズ共分散は既知として扱う。ノイズ自体の正体が曖昧な場合は、
  診断の前にそちらの検証が要る（本リポジトリのボイド検証では、
  ノイズの正体は「ボイド間の個体差」だったと別途確かめた）。
- これは「観測計画の地図」であり、観測そのものの代わりではない。
