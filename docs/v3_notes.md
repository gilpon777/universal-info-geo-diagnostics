## 追加した3層（2026-11-09 の検証で v2 が言えなかったことへの対応）

1. **絶対スケール `Absolute`** — 固有方向ごとに DirectionSNR = √λ、
   クラメール・ラオ σ = 1/√λ、目標 SNR までの情報倍率 target²/λ を返す。
   r_eff（形）と絶対量を併記できるようにした。
2. **邪魔者の周辺化** — `nuisance_basis=`（観測空間の線形基底を Schur 補完で
   プロファイル）と `nuisance_params=`（パラメータ空間の周辺化）。
   フィットに吸収される成分は診断の段階でゼロとして現れる。
3. **貪欲選定の内訳 `greedy_select`** — 各ピックに利得・マージンと、
   勝因の分解（勾配 ‖J_i‖² vs ノイズ 1/σ_i²）と driver ラベルを付ける。

## テストで確認したこと

- v2 との完全一致（同一入力で固有値・FIM が allclose）
- 絶対スケールの解析値一致と「観測を2倍にすると λ が2倍」の再現
- 定数振幅の nuisance 基底で、定数方向の FIM が厳密に ~0（吸収の再現）
- Schur 周辺化の既知例（[[2,1],[1,2]] → 1.5）
- 実データ: ボイドの貪欲順序 [中心, 0.79 Rv, 1.36 Rv] を再現し、
  第1位に driver=noise、マージン 14.2 倍が自動で付いた

## 実演の結果

- ボイド: Scaled の方向 SNR は [1.29, 1.15, 0.85, 0.53]。形は取れているが
  方向 SNR は 1 前後 — 絶対量の物差しが新たに付いた。
  なお第2位以降の利得マージンは ~1.0（ほぼ同点）で、v3 のマージン表示は
  「第1位だけが決定的で、残りは構造で選ばれている」ことも可視化する。
- GW 射影観測量 Σ(b)（現実的ノイズ、6横切り）: v2 は r_eff = 1.004 で止まったが、
  v3 は最硬方向 SNR = 0.019、SNR 1 に必要な情報倍率 ≈ 2,711 倍
  （= 同型の横切り ≈ 16,266 本）を同じ出力で返す。以前の手計算と一致。
