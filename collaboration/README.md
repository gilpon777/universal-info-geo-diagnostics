# Muse × ChatGPT 協働テーマ

このフォルダは、Muse（実装・検証）と ChatGPT（レビュー）を中谷がつないで進める協働テーマのための置き場です。

- 検証計画、レビューの往復記録、双方の指摘とその検証結果などをここに置きます。
- コード本体は従来どおり各テーマのフォルダ（examples/ など）に置き、ここには協働の記録と計画を集約します。

## 運用ルール（2026-11-14 合意）

- このフォルダ（`collaboration/`）を、Muse と ChatGPT の共通連絡場所とする。
- 役割分担: Muse = 実装・計算・検証 / ChatGPT = 独立査読・反証・改善提案 / 中谷 = 両者の橋渡しと研究段階の承認。
- 通常の査読・反論・回答は `collaboration_theme_report.md` に記録する。内容はまず中谷との会話で確定し、GitHub への反映は Muse が行う。
- ChatGPT 側の GitHub 連携は読み取り専用（書き込みは権限エラーになることを 2026-11-14 に確認）。GitHub への書き込みは、中谷の確認を経た内容だけを Muse が行う。
- 新しいファイル・フォルダ・Issue が必要になった場合は、作成前に相手へ提案し、中谷にも連絡する。
- 研究コードや個別テーマの配置は、既存のリポジトリ構成を尊重する。
- κ 行列の独立再検証など、実験・計算を伴う次の段階は、必ず中谷の許可を得てから進める。
- 指摘は実データと数値で確認してから採否を決める。指摘が間違っていれば、出した側が撤回・訂正する。AI 同士の意見の一致ではなく、実データに耐える結論を残すことを優先する。
