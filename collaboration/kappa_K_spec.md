# κ 混線行列 K の独立実装仕様書

作成: 2026-11-15（Muse）/ 目的: ChatGPT が Muse のコードを見ずに K を独立実装し、要素ごとに比較するための仕様。
対象バージョン: `kappa_stage2_kmatrix.py` による K（生成条件の固定記録は `kappa_K_record.md`）。
位置づけ: 本書は定義と入力だけを定める。実装方法（言語・ライブラリ・画素化の扱い）は実装者の自由。ただし §7 の比較手順と許容誤差は本書で事前に固定する。

## 1. 定義

K_ij = Δcomp_i / t_j

- j の理論 κ プロファイル（§3、偏光バイアス b=1.0、振幅 1）を空のマップに単独で置き、§2 の測定演算子で平滑化・測定したときの、ボイド i の補償開口値の変化 Δcomp_i を、j のテンプレート補償値 t_j（§4）で割ったもの。
- 添字の範囲: i, j ∈ {0, …, 440}（ボイドカタログの選択順、§5）。
- K は非対称行列として扱う。対称化しない。逆行列は使わない（前方適用のみ）。

## 2. 測定演算子（Stage 1 と同一）

1. κ マップを HEALPix NSIDE=512 の画素格子で表し、FWHM 0.5° のガウスビームで平滑化する（σ_beam = 0.5 / (2√(2 ln 2)) = 0.21221°）。平滑化は球面調和空間での通常のガウス平滑化（healpy `smoothing` 相当）。
2. ボイド i の中心方向について、画素中心との角距離 γ を画素ごとに測る。
3. comp_i = （γ < θ_i の画素の値の単純平均） − （1.4 θ_i ≤ γ < 1.8 θ_i の画素の値の単純平均）。
   - θ_i はボイド i の角度半径（§5）。
   - 画素集合は query_disc（半径 2 θ_i、inclusive）で得られる画素。平均は画素値の算術平均（面積重みなし、各画素等重み）。

## 3. 理論プロファイル κ_j(x)

x = γ/θ_j ∈ [0, 2] に対するボイド j の収束プロファイル。密度コントラストの普遍形 g(u)（u = r/R_v,j）:

- ノット: u = [0, 0.5, 0.8, 0.95, 1.07, 1.25, 1.6, 2.0]
- 値: g = [0.007, 0.05, 0.25, 0.70, 1.55, 1.15, 1.02, 1.00]、δ(u) = interp(u, ノット, g − 1)（線形補間、範囲外は端点値）

視線積分（s は視線方向の物理座標、単位 Mpc）:

κ_j(x) = (3/2) · Ω_m · (H0/c)² · (1 + z_j) · Dc_j · ∫_{−2.5 R_v,j}^{+2.5 R_v,j} δ( √(s² + (x·R_v,j)²) / R_v,j ) ds

- Ω_m = 0.315、H0 = 100·h km/s/Mpc（h = 0.674）、c = 299792.458 km/s。
- Dc_j はボイド j の共動距離（Mpc、§5 の入力値を使う。再計算しない）。
- 積分の数値評価: s のグリッドは等間隔 801 点、台形則（Muse 実装）。独立実装では積分が収束する解像度なら方法は問わない。

## 4. テンプレート補償値 t_j

未平滑プロファイルに対する面積重み付き補償開口:

t_j = [ ∫_0^1 κ_j(x)·2x dx ] − [ ∫_{1.4}^{1.8} κ_j(x)·2x dx / (1.8² − 1.4²) ]

（円板側は ∫_0^1 2x dx = 1 のため正規化済み。）全 441 個の平均は −1.577×10⁻⁴（検算値: 独立実装でも最初にこの平均が再現することを確認してほしい。許容: ±2×10⁻⁷）。

## 5. 入力データ（ボイドサンプル）

- カタログ: VIDE/ZOBOV ボイド（NSA ベース、`V2_VIDE-nsa_v1_0_1_zobovoids.dat`）。
- 選択: 0.02 < z < 0.114、R_v（カタログ値）≥ 12 h⁻¹ Mpc、|b| > 20°。該当 441 個、カタログ順。
- 各ボイドの入力値（RA, Dec, z, R_v [Mpc] = カタログ値/h、Dc [Mpc] = カタログ共動距離/h、θ [deg]）は、比較用データ `kappa_stage2_kmatrix.npz` の配列（ra, dec, zz, Rv, theta, t_vec）に同梱する。θ は θ = atan(R_v / (Dc/(1+z))) で再計算してもよい（一致するはず）。

## 6. Muse 実装の実現方法（参考：定義ではない）

Muse 側は §2 の演算子を半解析で実現した。各画素 y について、平滑化された指標関数の重み:

B_i(y) = F_disc,i(y)/N_disc,i − F_ann,i(y)/N_ann,i

- F_disc,i(y) = Φ( (θ_i − γ_y) / σ_beam )、F_ann,i(y) = Φ( (1.8θ_i − γ_y)/σ_beam ) − Φ( (1.4θ_i − γ_y)/σ_beam )。Φ は標準正規分布の CDF（境界の直線近似、いわゆる erfc 近似）。
- N_disc,i, N_ann,i は §2 の画素集合での実画素数（厳密）。
- K_ij = Σ_{y: γ_yj ≤ 2θ_j} κ_j(γ_yj/θ_j) · B_i(y) / t_j（和は i のパッチ＝中心から 1.8θ_i + 1.0° 以内の画素）。
- 対の列挙: γ_ij < 2θ_j + 1.8θ_i + 1.0° の順序対のみ計算し、それ以外は 0 とする（保存形式は疎行列、格納要素 34,054）。

既知の系統誤差（記録 E1）: この erfc 近似により、対角要素は厳密演算子に対して最大 +0.0043（絶対差、無次元）まで小さく出る。誤差は ∝ 1/θ で主に円板境界由来。非対角の直接検証は 6 対のみ（差 ≤ 0.002、記録 E2＝未確定）。

## 7. 比較手順と許容誤差（事前固定）

比較は2水準で行い、混同しない。

- **水準 1（式の転写確認）**: 独立実装が §6 の半解析式そのものを実装した場合。許容: 全格納要素で |ΔK| ≤ 10⁻⁶（浮動小数点の集積差の範囲）。
- **水準 2（演算子の独立確認、本命）**: 独立実装が §2 の厳密演算子（画素マップへの実注入＋実平滑化、または平滑化した指標マップによる重み付け）で K を作った場合。Muse 側の erfc 誤差 E1 を見込むため、許容は:
  - 対角: |ΔK_ii| ≤ 0.005（絶対差）。かつ差（独立 − Muse）が +側に偏り、1/θ の傾向を持つことを確認する（E1 の署名と一致すれば、差は近似誤差として説明済み）。
  - 非対角: |ΔK_ij| ≤ 0.005（絶対差）を全格納要素の 99% 以上で満たすこと。最大の不一致要素は個別に報告する。
  - 必須の部分集合: 対角 441 個すべて、|K_ij| の大きい順に非対角 100 対、距離指標 s = γ/(θ_i+θ_j) が 0.8–1.0 の非対角 50 対。
- 報告形式: 差の平均・標準偏差・最大絶対差、差と θ_i、θ_j、γ、s、|t_j| との相関。Pearson 相関は参考値とし、合否には使わない。
- ゼロ近傍の要素では相対誤差を使わない（絶対誤差を優先する。ChatGPT §4.3 の方針に同意）。

## 8. 振幅線形性試験（試験 B の手順）

K 自体は t_j で正規化されており振幅に依らない。線形性の実証は測定パイプライン側で行う:

- 実 κ マップに、全 441 ボイドのプロファイルを振幅 A ∈ {0.5, 1.0, 2.0} で同時注入し、各ボイドの Δcomp を測る。
- Δcomp(A) / A が A に依らず一定（相対偏差 ≤ 1%）であることを確認する。
- 単独注入については Stage 1b で A=0.5 と 2.0 の回収率が小数第 4 位まで一致済み。同時注入での確認が本試験の新規部分。

## 9. 本仕様の範囲外

- erfc 誤差の最終推定量 Â への伝播（記録 E3）は GLS フィットの段階で別途行う。本比較の合否には含めない。
- プロファイル形そのもの（§3 の g(u)）の妥当性は本仕様では固定条件とし、検証対象にしない。異なる物理プロファイルが K を通した後に識別可能か（モデル識別性）は将来の検討項目。
