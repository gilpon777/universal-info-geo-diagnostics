# κ K 行列の「指紋」— 現データで実施できる部分の固定（2026-11-17）

Claude v8 が提案した K 受け入れ基準の「指紋」方式（複数の統計量の組）と、
ChatGPT の追加要求（Kt ベクトルの要素ごとの一致・最大/RMS 誤差・
誤差の θ や近傍数との関係）への対応。

**本書の目的は合否判定ではなく、実測値の固定である。** 第 2 の K 実装
（ChatGPT の独立実装）がまだ無いため、独立実装との照合を要する項目は
合否を出さない。ここでは「現行パイプラインの K」と「現行パイプラインの
実注入応答」の自己整合として測れる統計量を、再計算可能な形で固定する。
計算: `kappa_fingerprint_partial.py`、数値: `kappa_fingerprint_partial.json`。
既存ファイルは無改変。σ = 4.4×10⁻⁴（スタック雑音、δc 文書と同じ）。

## 1. 定義とデータの出所

- 予測: pred = K·t。`kappa_stage2_kmatrix.npz` の疎行列（rows/cols/vals、
  34,054 要素）から再構成して計算した。
- 実測: d_meas = 全 441 ボイド同時注入に対するボイド別応答
  （Stage 1 の `comp_injected − comp`）。
- 残差: **r = d_meas − K·t**（実測 − 予測）。
  `kappa_stage2_kcheck.py` は逆符号（pred − actual）で集計しているため、
  符号に依存する量は本書と符号が反転する。大きさの量は一致する。

### F6 の内訳（空間的な偏り）

- 符号つき残差には有意な偏りはない（F5・F6）。θ 三分位ごとの平均残差は
  +3.5×10⁻⁷ / +3.7×10⁻⁷ / +1.7×10⁻⁷ で、帯域による符号の局在はない。
- 一方、**残差の大きさは小 θ 側に集中する**。θ 三分位ごとの RMS は
  低 θ 帯（2.42–3.93°）3.12×10⁻⁶、中帯 1.50×10⁻⁶、高 θ 帯（5.70–21.3°）
  0.74×10⁻⁶ で、約 4 倍の差がある。|r| 上位 10 件は全て θ ≤ 4.5°
  （中央値 2.97°、全体の中央値 4.68°）、z の中央値も 0.108 と全体
  （0.088）より高い（小 θ = 遠方・大半径のボイドに残差が集まる）。
  これは既知の対角誤差 E1 の ∝1/θ の傾向と方向が一致するが、r は
  対角分だけの量ではないため、原因の切り分けはここではしない。
- 上位 10 件の位置（RA/Dec）は特定の狭い領域には集まっておらず、
  天球上の一点への局在は見られない（詳細は JSON の top10）。

## 3. 独立実装が来たら何と照合するか（項目ごとの合格の考え方）

現時点では合否ではなく、照合の設計だけを 1 行ずつ固定する。

- **F1 回収率**: 独立実装 K′ でも予測回収率 mean(K′·t)/mean(t) を出し、
  現行 0.715124 との差が、実測側回収率との差（0.713240、差 0.0019）と
  同程度かそれ以下であること。
- **F2 最大絶対残差**: K′·t と実測の残差 r′ の最大値が、現行の
  0.0412σ と同桁（ファクター 2 以内）に収まること。
- **F3 RMS 残差**: r′ の RMS が現行 0.00465σ と同桁であること。
  平均（符号つき）が両者とも σ の 0.1% 級以下であること。
- **F4 Pearson 相関**: K′·t と実測の相関が 0.9999 以上であること。
- **F5 相関構造**: Spearman(|r′|, θ) の負の相関（小 θ 集中）が K′ でも
  再現すること。符号つき相関が |ρ| ≲ 0.1 に留まること。
- **F6 符号の偏り**: 正負の数が二項検定で有意（p < 0.01）にならないこと。

これらの「考え方」は目安の設計であり、正式な合格基準は独立実装の
到着時に、両実装の差の実測を見てから固定する。

## 4. 実施できない部分（第 2 実装待ち）

- **K と K′ の要素ごとの照合**: ΔK_ij = K′_ij − K_ij の分布・最大値・
  層別（|K| の大きさ別）統計。K′ が無いため未実施。
- **K′·t と K·t の直接比較、および K′ に対する δc（行和の誤差伝播）**:
  δc 文書で評価不能とした非対角分は、K′ が来て初めて実測できる。
- **共分散 C を含む伝播**: 対照 A/B から C を構築し GLS で Â へ伝播させる
  段階は未実施（従来どおりゴーサイン待ち）。指紋は C を含まない
  パイプライン内部の整合に限る。
- **本指紋の性質上の限界**: pred と d_meas は同じパイプライン系統
  （同じ開口演算子の系）から出ているため、本指紋は「重ね合わせの
  線形性と数値実装の整合」を固定するもので、演算子そのものの
  独立な正しさの証明にはならない。その役割は第 2 実装との照合が担う。
