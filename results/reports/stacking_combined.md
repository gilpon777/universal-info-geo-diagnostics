## 2. 結果

### Fisher の組み合わせ p 値（−2Σln p、自由度 8）

- 計画窓: X = 6.40、組み合わせ p = **0.60**
- 信号整合窓: X = 7.13、組み合わせ p = **0.52**
- 対照を加えた5件でも p = 0.67 / 0.68 と変わらない。

→ 4件束ねても有意な残差なし。単独の null が4つ並んだだけの、予想通りの結果。

### 逆分散重みつきの組み合わせ感度（目安）

全イベントに共通の割合 f の信号同形コヒーレント残差があると仮定し、
f_comb = 1 / sqrt(Σ 1/f99_i²) と見積もると：

- 計画窓: **約 0.21**（最良の単独 GW250114 の 0.26 から約2割改善）
- 信号整合窓: **約 0.17**（同 0.24 から約3割改善）

10% 級（f = 0.10）に届くには、GW250114 級のイベントがあと
(0.26/0.10)² ≈ 6.8 件（計画窓）／(0.24/0.10)² ≈ 5.8 件（整合窓）
— すなわち同級を合計 6〜7 件 — 束ねる必要がある計算になる。

## 3. この試算の限界（重要）

- **ストレインを束ねた解析ではない。** 報告書の p 値・f99 という要約数値だけの
  組み合わせで、検出器ペア（H1×L1 が3件、H1×V1 が1件）や背景窓数・有効区間
  （936〜3698 窓）の違いは f99 の中にしか反映されていない。
- **共通 f の仮定は強い。** 実際の波動光学レンズの増幅はレンズ質量・距離・
  周波数で変わるため、4イベントで同じ割合の残差が出るとは限らない。
  この組み合わせ f は「もし共通なら」という条件付きの目安。
- **GW240925 と GW241011 は同じ Local Void を通る**ため、レンズ仮説の下では
  完全独立とは言い切れない。Fisher の独立性の仮定は近似。
- 結論は変わらない：束ねても 10% 級には届かない。届かせるには
  (a) GW250114 級の高 SNR イベントをさらに集めるか、
  (b) レンズモデル付きテンプレート型解析に変えるか、のどちらかが必要。

## 4. 次の選択肢（未決定・承認待ち）

- **A. 本格的なスタッキング解析**：各イベントの残差系列（`wf_data/*/waveform_series.npz`）
  を読み、S 統計量をイベント間で重み付き合成する。重みは f99 ではなく各イベントの
  背景分布から決める。数日規模の作業になる見込み。
- **B. テンプレート型（レンズモデル付き）解析**：周波数依存の増幅・うなりを
  直接探す。感度は上がる可能性があるが、モデル依存になる。
- **C. ここで区切る**：4点の上限を最終結果として残し、新しい高 SNR の
  ボイド経路イベントが出るのを待つ。

本ファイルは A/B/C いずれの実行でもない。数値の試算と選択肢の整理のみ。
