# GW250114_082203 波形レンズ残差解析レポート

作成: 2026-11-07 / 対象: GW250114_082203 (GPS 1420878141.2, H1+L1, ネットワーク SNR 78.6)
位置づけ: waveform_analysis.md §4.2 で「未実施・次段階の最優先」とした対象の実施結果。
手法は GW231123_135430 主解析・GW240413_022019 対照と同一 (μ-GLANCE 流:
最良適合波形の差引 + 残差の検出器間相互相関)。本イベントは A90 = 42 deg²、
Pcov = 1.00、距離 405 Mpc と経路条件がクリーンで、SNR が GW231123 の 3.6 倍ある。
目的は (a) 干渉の署名の有無、(b) 感度がどこまで改善するかの実測、の 2 点。

---

## 1. 結論 (上限的表現)

- 計画窓 [-1.5, +0.5] s: 残差統計量 S_resid = 0.061。オフソース背景 (n=1045 窓) の
  中央値 0.066 と同水準で、経験的 p ≈ 0.71。**有意な残差相互相関なし。**
- 信号整合窓 [-0.6, +0.3] s: S_resid = 0.086 (背景中央値 0.097、p ≈ 0.81)。
  こちらも有意でない。
- 正対照 (未差引データ): S_raw = 0.598 / 0.742 で、両窓とも背景の全窓を超過
  (exceed = 0、p は背景サイズの分解能限界 ≈ 1×10⁻³)。GW231123 の正対照
  (0.122 / 0.231) と比べ桁違いに強く、パイプラインがコヒーレント成分を
  捉えることは本イベントでも実証された。
- よって結論は: **「この感度では、干渉の証拠は得られなかった」**。
  これはボイド内の不可視天体の不存在を意味しない (存在の否定ではない)。
- 感度の実測 (注入法、§5): 背景 99% 点を超えるのに必要な信号同形コヒーレント
  残差は信号振幅の **約 24〜26%** (窓依存)。GW231123 の同一手法実測
  (約 47〜82%) から計画窓で約 3.2 倍、信号整合窓で約 2.0 倍の改善。
  ただし 10% 級の波動光学レンズ増幅は依然として感度外である
  (f=0.10 の注入では S は両窓とも背景中央値以下)。

  (開始 GPS 1420877824、イベントはファイル内 317.2 s 地点)
  - https://gwosc.org/archive/data/O4b_4KHZ_R1/1420820480/H-H1_GWOSC_O4b_4KHZ_R1-1420877824-4096.hdf5
  - https://gwosc.org/archive/data/O4b_4KHZ_R1/1420820480/L-L1_GWOSC_O4b_4KHZ_R1-1420877824-4096.hdf5
- PE: GWTC-5.0 PEDataRelease、C00:IMRPhenomXPHM-SpinTaylor (13,969 サンプル)。
  PE 付属 PSD も使用 (前回と同一方針)。
- 環境: 前回と同一の venv (lalsuite 8.0.0 系)。実行スクリプトは

### 2.1 データの注意: 配布ファイル末尾の NaN と有効区間の限定

- 両検出器の 4096 s ファイルは、末尾が NaN になっている (H1 は 1285.0 s 以降、
  L1 は 1275.0 s 以降が全て NaN。NaN 数は H1 = 11,513,856、L1 = 11,554,816)。
  ダウンロード破損を疑い GWOSC から再取得したが、サイズ・NaN 数とも完全一致し、
  **配布元ファイル自体の内容**であることを確認した (ファイルサイズとサンプル数が
  規定通りでも内容が全区間有効とは限らない、という教訓)。
- このため解析は両検出器共通の非 NaN 先頭区間 **1275.0 s** に限定した。
  イベント (317.2 s 地点) とオンソース 64 s セグメントは有効区間内に十分収まる。
  背景は同区間のホワイトニング済み 1216 s から取り、窓数は計画窓 1045 /
  信号整合窓 1029 (GW231123 の 3703 / 3667 より少ない)。p 値の分解能限界は
  約 1×10⁻³ (前回は約 2.7×10⁻⁴)。
- なお最初の実行 (区間限定なし) は NaN が filtfilt で全区間に伝播し全統計量が
  NaN となったため破棄した (run.log に記録)。本レポートの数値は修正後の再実行
  (run2.log) のものである。

## 3. 手法と検証

1. **テンプレート再選択**: 前回と同一手順 (logL 上位 2000 サンプルを 8 s
   セグメント・PE PSD での network MF で測り直し)。採用サンプルは idx 2773
   (m1 = 36.2, m2 = 35.5 Msun (検出器系)、DL = 402 Mpc、χeff = −0.02)、
   network MF (8 s) = 76.48 (H1 = 50.03, L1 = 57.85)。
2. **較正の整合性**: argmax logL サンプルの MF は H1 = 49.86, L1 = 57.24 で、
   PE 保存の matched filter SNR (H1 = 50.37, L1 = 58.26) とよく一致する。
   GW231123 で見られた「保存最尤サンプルの振幅不整合」は本イベントでは
   ほぼ無く、PE の素性が良い。
3. **複素振幅フィット**: |α| は H1 = 1.003 (実効距離 400 Mpc)、L1 = 1.004
   (同 400 Mpc)。両検出器とも α ≈ 1.00 で、テンプレート振幅の再調整が
   ほぼ不要だった (GW231123 の 0.65 / 0.59、GW240413 の 0.88 / 0.95 と対照的)。
   時間ずれフィットは H1 = 0.0 ms、L1 = +0.98 ms。64 s セグメントでの
   network MF は 76.0 (探索 SNR 78.6 と整合的水準)。
4. **統計量**: S = max_{|lag|≤50 ms} |C(lag)| (正規化相互相関)、前回と同一。
   背景は同一ファイル内のオフソース窓 (イベント ±40 s 除外、RMS 外れ値窓は
   除外して件数を記録: 計画窓 89 件、信号整合窓 107 件)。

## 5. 感度の実測 (注入法)

方法: 差引後の残差 (ホワイトニング済み) に、差引済みテンプレートそのものを
割合 f で加えた系列を作り、同一統計量 S(f) を測る。S(f) が背景 p99 (および
参考として背景 max) を超える f を線形内挿で求める。検証として f=0 で
S_resid、f=1 で S_raw を両イベントとも厳密に再現した (data = resid + templ
のため)。GW231123 についても保存系列 (waveform_series.npz) に対して同一の
注入測定を行い、直接比較できるようにした (gw231123_sensitivity.py)。

| 窓 | GW231123 f99 | GW231123 f (背景 max) | GW250114 f99 | GW250114 f (背景 max) | 改善 (f99) |
|---|---|---|---|---|---|
| 計画窓 | 0.82 | 1.00 | **0.26** | 0.27 | 約 3.2 倍 |
| 信号整合窓 | 0.47 | 0.83 | **0.24** | 0.25 | 約 2.0 倍 |

- 前回レポートの概算 (「信号振幅のおよそ 6〜8 割」) は計画窓寄りの見積りで、
  注入実測では計画窓 0.82 / 信号整合窓 0.47 だった。以後の比較は注入実測同士で行う。
- GW250114 の S(f) の実測点 (抜粋): f=0.10 で 0.056 / 0.080 (両窓とも背景
  中央値以下)、f=0.20 で 0.061 / 0.102、f=0.25 で 0.091 / 0.155、
  f=0.30 で 0.126 / 0.212 (計画 / 信号整合の順)。
- 解釈: SNR が 3.6 倍になっても必要残差割合の改善は 2〜3 倍に留まる。
  これは本統計量が正規化相互相関であり、背景側のばらつき (窓長で決まる) が
  支配的になるためで、SNR に単純比例はしない。10% 級の波動光学レンズを
  本手法で見るには、さらなる高 SNR イベントか、μ-GLANCE 本来の最適化
  (窓設計・複数イベント組合せ) が必要、という前回の見通しは変わらない。

## 6. 限界と注意

- **感度**: §5 の通り、本解析が届くのは信号振幅の約 25% 以上の信号同形
  コヒーレント残差まで。10% 級の波動光学レンズは感度外であり、本結果は
  「証拠なし (上限)」に留まる。
- **注入形状の仮定**: 感度はテンプレート同形の残差に対する定義。実際の
  波動光学レンズの署名 (周波数依存の増幅・うなり) はテンプレートと完全には
  同形でなく、直交成分は本統計量で見えにくい可能性がある。
- **背景の分解能**: 有効区間の制約で背景窓は約 1000 個、p の分解能は約 10⁻³。
  正対照の p は分解能限界での上限表現に留めた。
- **テンプレートの不完全さ**: PE 標本内再選択 + 線形 α フィットであり完全な
  再 PE ではない。ただし本イベントでは較正 MF が PE 保存値と一致し
  α ≈ 1.00 と、前回 2 件より差引の前提は堅い。
- **経路側の近似・単一イベント性**: waveform_analysis.md §5 の留保
  (ボイド球近似、z<0.114 のみ、単一イベントではレンズ天体の存否に結論しない)
  は本解析にもそのまま当てはまる。
