# GW241011_233834 波形レンズ残差解析レポート (H1×V1 版)

作成: 2026-11-08 / 対象: GW241011_233834 (GPS 1412725133.0、H1+V1 のみで検出
(L1 は当時停止中)、ネットワーク SNR 35.8 (GWOSC GWTC-5.0 v2 カタログ値))
位置づけ: local_voids.md §6 で「Local Void (天の川銀河の側のボイド) を最終区間で
通る経路」のうち **弦長最長 (45.3 Mpc、Tully 球モデル、全 228 イベント中最大)**
かつ **最も近いイベント (距離 212 Mpc)** とされたもの。GW240925_005809
(弦長 44.8 Mpc、356 Mpc) と対になる候補であり、本解析で Local Void を
最も長く通る経路に初めて物差しを当てた。手法は μ-GLANCE 流 (最良適合波形の
差引 + 残差の検出器間相互相関) で先行件と同一だが、検出器ペアが H1×L1 ではなく
**H1×V1** のため、パイプラインを組み替えて適用した (変更点は §2.3)。

---

## 1. 結論 (上限的表現)

- 計画窓 [-1.5, +0.5] s: 残差統計量 S_resid = 0.076。オフソース背景 (n=3698 窓)
  の中央値 0.066 に対し、経験的 p ≈ 0.18。**有意な残差相互相関なし。**
- 信号整合窓 [-0.6, +0.3] s: S_resid = 0.101 (背景中央値 0.098、p ≈ 0.42)。
  こちらも有意でない。
- 正対照 (未差引データ): S_raw = 0.159 / 0.247 で、両窓とも背景の全窓を超過
  (exceed = 0、p は背景サイズの分解能限界 ≈ 2.7×10⁻⁴)。組み替えた H1×V1
  パイプラインがコヒーレント成分を捉えることは本イベントでも実証された。
- よって結論は: **「この感度では、Local Void を最も長く通るこの経路について、
  干渉の証拠は得られなかった」**。これはボイド内の不可視天体の不存在を
  意味しない (存在の否定ではない)。また本結果は本イベントの視線・最終区間に
  対する上限であり、**Local Void 全体への一般化はしない**。
- 感度の実測 (注入法、§5): 背景 99% 点を超えるのに必要な信号同形コヒーレント
  残差は信号振幅の **約 47% (計画窓) / 37% (信号整合窓)**。実行前は
  「V1 の SNR が弱い (MF ≈ 8.8) ため GW240925 の実測 (58% / 36%) より悪化する
  可能性が高い」と見ていたが、実測では計画窓でむしろ小さく、信号整合窓で
  ほぼ同等となり、**GW240925 の水準より悪化しなかった** (§5 で議論)。
  10% 級の波動光学レンズ増幅は本イベントでも感度外。

### 2.1 較正バージョン: PE は C00 のみ (C01 は存在しない)

- ダウンロードした PE ファイルのグループは **全て C00**
  (C00:IMRPhenomXPHM-SpinTaylor / C00:IMRPhenomXPNR / C00:SEOBNRv5PHM) で、
  C01 グループは存在しない。GW240925 (公開 PE が較正済み C01 のみ) とは
  逆の構成であり、本イベントの公開 PE は C00 が唯一の版である。本解析は
  自動選択により **C00:IMRPhenomXPHM-SpinTaylor** (14,339 サンプル) を使用した。
  GWOSC Event API の PE セット名も C00 表記で一致する。
- ストレインは GWOSC の標準公開リリース (O4b_4KHZ_R1) を使用。差引時の
  複素振幅フィット α (§3) が H1 = 0.925 / V1 = 0.884 と 1 の 12% 以内であり、
  C00 PE と公開ストレインの間に実務上の大きな不整合は見られなかった
  (H1 の実効距離 211 Mpc はカタログ距離 212 Mpc とほぼ一致)。

### 2.2 データの注意: NaN は皆無 (先行 2 件と異なる)

- H1/V1 両ファイルとも **NaN サンプルは 0** で、4096 s 全区間が有効だった
  (GW250114 の末尾 NaN、GW240925 の H1 欠落区間のような事情はない)。
- このため解析は両検出器共通の有効区間として **ファイル全体
  GPS [1412722688, 1412726784) (4096 s)** をそのまま使用し、ゼロ充填は
  行っていない。背景は同区間のホワイトニング済み 4096 s (64 ブロック × 64 s)
  から取り、窓数は計画窓 3698 / 信号整合窓 3711 (RMS 外れ値窓の除外は
  317 / 305 件)。p 値の分解能限界は約 2.7×10⁻⁴ で、先行 2 件
  (GW250114・GW240925 の約 1.1×10⁻³) より細かい。

### 2.3 パイプラインの組み替え点 (H1×L1 → H1×V1)

gw240925_runner.py からの変更は以下に限られ、統計量・窓・前処理・注入法の
定義は同一に保った:

1. 検出器リスト ["H1", "L1"] → ["H1", "V1"] を、PE PSD 読込・ストレイン
   読込・MF 再選択・テンプレート投影・α フィット・相互相関・注入の
   全箇所に適用。
2. V1 テンプレート投影は lal の V1 検出器 (cached_detector_by_prefix["V1"])
   でアンテナパターンと地球中心からの到達時間差を計算。
3. 有効区間の決め方: 両ファイルの NaN 構造を確認した結果、欠落がないため
   ファイル全体を採用 (先行件の区間限定・充填処理は不適用)。
4. 背景窓は H1×V1 ペアで取り直し (窓数・RMS 除外件数は §2.2)。
5. 正対照は先行件と同一 (未差引データの S_raw が背景全窓を超過するか)。

## 3. 手法と検証

1. **テンプレート再選択**: 先行件と同一手順 (logL 上位 2000 サンプルを 8 s
   セグメント・PE PSD での network MF で測り直し)。採用サンプルは idx 14122
   (m1 = 20.6, m2 = 6.2 Msun (検出器系)、DL = 195 Mpc、χeff = +0.53)、
   network MF (8 s) = 34.29 (H1 = 33.23, V1 = 8.45)。カタログの
   ネットワーク SNR 35.8、および源系質量 (19.5 / 5.96 Msun、z = 0.05 の
   検出器系換算で約 20.5 / 6.3 Msun) と整合的。
2. **較正の整合性**: argmax logL サンプルの MF は H1 = 32.42, V1 = 8.28 で、
   再選択後の値とほぼ一致。先行件のような大きな不整合はない。
3. **複素振幅フィット**: |α| は H1 = 0.925 (実効距離 211 Mpc)、V1 = 0.884
   (同 221 Mpc)。時間ずれフィットは H1 = −4.88 ms、V1 = −2.93 ms
   (正対照の相互相関ピーク lag = +19.5 ms (両窓) は検出器間到達時間差を
   含む量で、個別の τ フィットとは定義が異なる)。64 s セグメントでの
   MF は H1 = 33.43、V1 = 8.75 (合成で約 34.6)。
4. **統計量**: S = max_{|lag|≤50 ms} |C(lag)| (正規化相互相関)、先行件と同一。
   背景は同一ファイル内のオフソース窓 (イベント ±40 s 除外)。

## 5. 感度の実測 (注入法)

方法は先行件と同一: 差引後の残差 (ホワイトニング済み) に差引済みテンプレート
そのものを割合 f で加え、同一統計量 S(f) を測り、背景 p99 (および参考として
背景 max) を超える f を線形内挿で求める。検証として f=0 で S_resid、f=1 で
S_raw を両窓とも厳密に再現した。

| 窓 | GW241011 f99 | GW241011 f (背景 max) | GW231123 f99 | GW240925 f99 | GW250114 f99 |
|---|---|---|---|---|---|
| 計画窓 | **0.47** | 0.62 | 0.82 | 0.58 | 0.26 |
| 信号整合窓 | **0.37** | 0.53 | 0.47 | 0.36 | 0.24 |

- 本イベントの S(f) の実測点 (抜粋): 計画窓では f=0.40 で 0.087、f=0.5 で
  0.098、f=0.6 で 0.109、f=1 で 0.159。信号整合窓では f=0.10 で 0.108、
  f=0.25 で 0.124、f=0.40 で 0.145、f=1 で 0.247。
- **実行前の見通しとの差異 (正直な記録)**: 準備段階では「V1 の SNR が約 9 と
  弱く、相互相関は V1 側ノイズに律速されるため、GW240925 の f99 = 0.58 / 0.36
  より悪化する可能性が高い」と見積もっていた。実測は計画窓 0.47 (GW240925
  より小さい)、信号整合窓 0.37 (ほぼ同等) で、悪化はしなかった。背景分布の
  中央値・p99 (0.066 / 0.094、0.098 / 0.140) が H1×L1 の先行件とほぼ同じ水準で、
  正規化相互相関では背景のばらつきが支配的という先行件の知見と整合する。
  ただしこれは単一実現での実測であり、「H1×V1 は一般に H1×L1 と同感度」と
  一般化はしない。
- 解釈: f99 は本イベントでも 10% 級の波動光学レンズには届かない。
  本手法で 10% 級を見るには、さらなる高 SNR イベントか、テンプレート型
  (レンズモデル付き) 解析・複数イベントの組合せが必要、という見通しは
  変わらない。

## 6. 限界と注意

- **感度**: §5 の通り、本解析が届くのは信号振幅の約 37〜47% 以上の信号同形
  コヒーレント残差まで。10% 級の波動光学レンズは感度外であり、本結果は
  「証拠なし (上限)」に留まる。
- **一般化の禁止**: 本結果は単一イベント・単一視線の最終区間 (Local Void の
  一部の弦) に対する上限である。Local Void 全体、あるいは他の経路について
  不可視天体の存否を結論するものではない。
- **検出器ペアの非対称性**: V1 の MF は 8.75 で H1 (33.43) の約 1/4。
  相互相関はペアで定義されるため、本結果は「H1×V1 ペアとしての」上限であり、
  L1 が稼働していれば感度は変わり得た (ただし §5 の通り、実測 f99 は
  GW240925 の H1×L1 と同水準だった)。
- **窓と信号長の関係**: 本イベントは検出器系チャープ質量 ≈ 9.5 Msun で、
  20 Hz からの信号長は概算で約 5 s ある。比較可能性のため窓は先行件と同一
  (マージャー前後の 2.0 s / 0.9 s) に揃えたため、窓外のインスパイラル区間に
  仮に署名があっても本統計量の対象外である。正対照が両窓とも背景全窓を
  超過していることから、窓内のコヒーレント成分の検出能力自体は確認済み。
- **注入形状の仮定**: 感度はテンプレート同形の残差に対する定義。実際の
  波動光学レンズの署名 (周波数依存の増幅・うなり) はテンプレートと完全には
  同形でなく、直交成分は本統計量で見えにくい可能性がある。
- **テンプレートの不完全さ**: PE 標本内再選択 + 線形 α フィットであり、
  完全な再 PE ではない。V1 の α = 0.884 は先行件の第 2 検出器
  (0.59〜1.036) の範囲内だが、1 からのずれは H1 (0.925) よりやや大きい。
- **較正版**: 本イベントの公開 PE は C00 のみ (§2.1)。GW240925 のような
  「C00 は誤較正」という事情は本イベントについては報告されておらず、
  α・較正 MF の整合 (§3) からも実務上の問題は見られなかった。
- **経路側の近似**: 弦長 45.3 Mpc は Tully 球モデルに基づく近似値であり、
  Local Void の形状・境界の不確かさを含む (local_voids.md の留保を参照)。
