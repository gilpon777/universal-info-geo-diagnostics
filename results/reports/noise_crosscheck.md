# ノイズ照合: 天の川検証はボイドのノイズの対照実験だったのか

作成: 2026-11-09
中谷の設計意図（本人の説明）: そのノイズを確認するために天の川銀河を検証した。
データの多い場所のノイズとボイドのノイズが同じであれば、ボイドのノイズは検証できると思った。

## 判定

意図は正しく、対照実験として実際に機能していた。ただし検証の射程を正確に分けると:

- 天の川が検証したのは **コードのノイズ処理の忠実さ**（σ の構造をそのまま写すか）。
- ボイドの σ の **値そのもの**は、天の川では検証できない（発生源が違う）。
  こちらは本日、ボイド内部の直接テストで検証した（§3）。両方そろって結論が立つ。

## 1. 2つのノイズ構造の比較

| | ボイド（スタック） | 天の川（回転曲線、実務で使った総誤差） |
|---|---|---|
| σ の発生源 | ボイド間の標本ばらつき（ブートストラップ） | 測定誤差＋3%系統誤差フロア |
| σ の最大/最小 | 12.7 倍 | 3.7 倍 |
| σ の形 | 中心で隣のビンの 1/6.5 に急落する「窪み」 | 半径に対して滑らか |
| スコア1位のマージン | 14.2 倍 | 1.005 倍（ほぼ同点） |

天の川では、σ が滑らかで突出した窪みがないため、コードは鋭い注目点を出さなかった
（1位はマージンほぼゼロの競り合い）。ボイドでは σ の窪みがある場所に、
ちょうどその深さに見合うマージン（14倍）で注目点が出た。
前回の等ノイズ化アブレーション（σ を均すと1位が壁に交代）と合わせると、
**コードは σ 構造を「発明」せず「転写」する**ことが、両対象の対照で示されている。
これが中谷の対照実験の設計が捉えていた部分である。

なお天の川の formal 誤差だけを見ると最大/最小は 59.7 倍にもなるが、
実際の診断は系統誤差フロアを加えた総誤差で回しており、χ² も formal のみでは
107.7/33 だったものが総誤差で 7.0/33 まで落ち着いた。つまり天の川側でも
「ノイズは既知」ではなく「ノイズをモデル化して初めて検証になる」という
同じ構図だった点は、留保として記録しておく。

## 2. なぜ天の川だけではボイド σ の値が検証できないか

ボイドの σ は測定誤差ではなく、386個のボイドを重ねたときの標本ばらつきである。
天の川の σ とは発生源が違うため、値の正しさはボイドの内部で確かめるしかない。
必要な性質は3つ: (a) データを割っても同じ窪みがある、(b) σ が N^-1/2 で縮む、
(c) 推定法を変えても同じ σ になる。

## 3. ボイド σ の直接検証（本日実施）

- **ジャックナイフ vs ブートストラップ**: 中心ビンの σ は 0.00305 vs 0.00305、
  比率 **0.999**。独立な2つの推定法が 0.1% で一致。
- **分割半分（5回試行）**: 毎回、両半分とも中心プロファイルはほぼゼロ（0.001–0.012）で、
  中心ビンが最小 σ のビンだった（**10半分中10**）。半分の σ / 全体の σ は
  中央値 約1.37 で、理論値 √2 = 1.41 と整合。
- **N スケーリング**: 標本数を 386→256→128→64 と減らすと、σ は単調に増大。
  中央値ビンの傾きは **−0.503**（理論 −0.5 と一致）。中心ビンの傾きは −0.34 と
  やや浅いが、これは中心ビンの値が「銀河0個のボイドと稀な1個のボイド」の
  離散分布で標準偏差の推定自体が揺れるためで、絶対値は全範囲で 1/√N 予測の
  2倍以内にある。

中心の σ の窪みは、推定の人工物ではなく、データの分割・本数・推定法の
すべてに対して残る、標本ばらつきの実在の構造である。

## 4. 結論

- 中谷の推論「データの多い場所でノイズの振る舞いが確かめられれば、
  ボイドのノイズも検証できる」は、コードの忠実さについては天の川対照で成立していた。
- ボイド σ の値については、内部検証（ジャックナイフ＝ブートストラップ、
  分割半分での窪みの持続、N^-1/2 スケーリング）が本日そろい、検証できたと言える。
- したがって前回の結論「中心の注目点は σ の窪みが主因」は、
  その σ 自体が実在であることまで含めて、足場が固まった。
