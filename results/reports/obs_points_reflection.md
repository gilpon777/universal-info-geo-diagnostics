# 深掘り: コードが出した「観測点」は、なぜ重力波検証に反映されなかったのか

作成: 2026-11-09
問い（中谷）: ボイド検証では自分のコードで検証点（観測点）が複数出ていたはず。
重力波の重ね合わせで検証してきたのに、なぜその観測点が反映されないのか。

## 結論（3層ある）

1. **実装層（事実）**: GW検証の選定基準に、FIMの観測点（動径ビン）は一度も入っていない。
   重ね合わせは「弦長・b/Rv・A90・Pcov」、波形は「時間窓」で選んでおり、ビン順位は使わなかった。
2. **幾何層（計算で確認）**: 仮にビンを反映させようとしても、重力波の視線はビンを
   「点として選べない」。視線は全ビンを一度に貫く直線であり、観測量はその線積分
   （射影密度 Σ(b)）に潰れる。中谷のコードにGW側の観測量を入れて診断し直すと、
   **Raw r_eff は横切りを何件足しても ≈1.00 のまま**（銀河側は 1.40、Scaled 3.42）。
   ビンごとの勾配の多様さが、射影で失われるためである。
3. **結合層（物理）**: 滑らかなボイドプロファイルが重力波に与える収束は
   κ ≈ 2.8×10⁻⁵（最大ボイド、GW231123 の幾何）で、増幅の変化 2κ ≈ 5.7×10⁻⁵ は
   実測感度 f99 = 0.24–0.82 の約4桁下。しかも周波数に依らない増幅は、波形解析で
   検出器ごとに自由にフィットした複素振幅 α に完全に吸収される。残差法が見られるのは
   コンパクトなレンズによる周波数依存の波動光学成分だけで、そのパラメータ
   （レンズ質量・位置）はプロファイルの θ = (δc, rs, α, β) の中に存在しない。

つまり「反映されなかった」のは単なる手抜かりではなく、**観測点が答えていた問い
（銀河カウントからプロファイルの形を決める）と、重力波波形が答えられる問い
（コンパクト天体の波動光学レンズ）が、別の問いだった**ことが構造的な理由である。
ただし第1層は事実としてこちら側の設計の問題であり、§6 に正しい翻訳の仕方を示す。

## 1. コードが出した観測点とは何だったか

対象は銀河の動径密度プロファイル（386ボイドのスタック、14ビン、r = 0–2 Rv）。
パラメータは Hamaus+2014 の θ = (δc, rs/Rv, α, β)。貪欲選定（logdet 増分）の順序:

| 順位 | ビン中心 r/Rv | 主に縛るもの |
|---|---|---|
| 1 | 0.07（中心） | δc（stiff 方向はほぼ純 δc、固有ベクトル成分 −0.999） |
| 2 | 0.79 | rs と内側の立ち上がり |
| 3 | 1.36 | β（壁の外側） |
| 4 | 0.36 | δc と α の内側スロープ |
| 5 | 1.07（壁ピーク） | 壁の高さ |
| 6 | 1.64 | β |
| 7 | 0.93 | 壁の内側 |

上位7ビンで Raw r_eff の 98.3%（1.380/1.405）を保持。
重要なのは、これらの「点」は**空の上の位置ではなく、スタックされたプロファイルの
動径座標**だということ。各ビンの観測量は「その殻にいる銀河の数」であり、
ビンごとに θ への勾配（ヤコビアンの行）が違う向きを向くから、複数点に意味があった。

なお近傍30ボイドだけのスタックでは順位が反転し、中心ビンは最下位（14位）になった
（中心ビンの銀河数がゼロ）。観測点は対象スタックごとに変わる、という性質も持つ。

## 2. GW検証で実際に使った選定基準との照合

| 段階 | 使った基準 | FIMビンとの関係 |
|---|---|---|
| 重ね合わせ（228件） | A90、Pcov、ピーク視線の横切りの有無 | なし |
| 候補の順位付け | 弦長合計、最小 b/Rv（中心性） | b→0 の嗜好だけが、中心ビン（r<0.14 Rv）を視線が通る条件と偶然重なる |
| 波形解析（4件） | SNR、経路、検出器の組。統計量は合体前後の時間窓（計画窓・整合窓） | なし。「窓」は時間軸の区間であり、空間の観測点ではない |
| ローカルボイド候補 | Tully 球モデルでの弦長 | ローカルボイドはカタログ外で、そもそもビンが存在しない |

GW250114・GW240925・GW241011 については、横切る個々のボイドの b の一覧すら作っていない
（詳細な視線表を作ったのは GW231123 のみ）。よって「反映されていない」は事実である。

## 3. 定量1: 弦は各ビンをどれだけ通るか

直線視線（衝突パラメータ b）が r < 2 Rv の領域を進む距離のうち、各ビン（殻）に
滞在する割合を幾何学的に計算した（obs_points_reflection.py）。

| b/Rv | 上位1位ビン（中心 r<0.14） | 上位7ビン合計 | Rv 内側の割合 |
|---|---|---|---|
| 0.00 | 7.1% | 50.0% | 50.0% |
| 0.088（GW231123・ボイド7） | 5.6% | 48.9% | 49.9% |
| 0.146（同・最大ボイド283） | 0%（b がビン外縁を超える） | 44.1% | 49.6% |
| 0.374 | 0% | 49.7% | 47.2% |
| 0.802 | 0% | 63.1% | 32.6% |
| 0.972 | 0% | 56.3% | 13.4% |

読み方:
- 第1位の中心ビンを視線が通るのは **b < 0.143 のときだけ**。GW231123 の6ボイドでは
  1個（idx 7）だけが該当し、6ボイド合計の経路長（Rv 加重）に対して中心ビンの滞在は
  **1.1%** にすぎない。
- 「上位7ビン合計 ~50%」は見かけほど意味がない。上位7には外側ビン（1.07, 1.36, 1.64 Rv）
  が含まれ、どの視線も出入りで必ずそこを通るため、b によらず自動的に稼がれる。
  ビンの情報価値は「滞在時間」ではなく「勾配の向きの違い」にあるので、
  経路占有率は情報量の代理指標にならない。

## 4. 定量2: GW側の観測量でコードを回し直す

中谷の v2 コードをそのまま使い、観測量だけを銀河プロファイルから
「視線の射影コントラスト Σ(b; θ) = ∫ δ(r(s); θ) ds」（単位 ρ̄·Rv）に差し替えた。
仮定: 各横切りの Σ を相対誤差10%で測れる（現実より遥かに楽観的）、同一スタック θ を共有。

| 観測量の集合 | Raw r_eff | Scaled r_eff |
|---|---|---|
| 銀河プロファイル14ビン（元の検証） | 1.40 | 3.42 |
| GW Σ(b) 1件（b=0.088） | 1.00 | 1.00 |
| GW Σ(b) 6件（GW231123 の全横切り b=0.09–0.97） | 1.004 | 1.40 |
| GW Σ(b) 理想7件（b=0.05–0.95 を均等に） | 1.005 | 1.45 |

さらに、b を自由に選べる場合の貪欲選定も回した。選ばれた順序は
b = 0.02 → 0.98 → 0.26 → 0.74 → 0.22 → 0.70 → …と、中心・縁・中間を交互に拾う
（天の川検証で見た「両端と内側を拾う」パターンに似る）。しかし **10点選んでも
Raw r_eff は 1.003 のまま**だった。

解釈: Σ(b) の θ への勾配は、b を変えてもほぼ平行（相関 >0.999）である。
射影という操作が、動径方向の構造の違いを1本の積分値に畳み込むため、
「どの b を選ぶか」では新しい方向が増えない。ビン観測では14本あった
独立な勾配の向きが、GW側では実質1本になる。これが第2層の正体であり、
**観測点を完璧に反映させたとしても、プロファイルの形はGWからは復元できない**
という結論になる（少なくとも滑らかな成分については）。

## 5. 定量3: 結合の大きさと、振幅フィットへの吸収

滑らかなボイド1個の弱レンズ収束（GW231123 の最大ボイド、Dl≈130 Mpc、
光源距離 ≈2200 Mpc の幾何で）:
- Σ_contrast（b=0.146）≈ 3.9×10¹¹ M☉/Mpc²、Σ_crit ≈ 1.36×10¹⁶ M☉/Mpc²
- **κ ≈ 2.8×10⁻⁵**、増幅率の変化 2κ ≈ 5.7×10⁻⁵
- 実測 f99 は 0.24–0.82。つまり滑らかな成分の効果は感度の約1万分の1。

近傍ボイドは Dl が小さいため幾何学因子 Ds/(Dl·Dls) がさらに不利で、
ローカルボイドでは κ はもっと小さい（10⁻⁵ 以下）。

加えて、周波数に依らない増幅（幾何光学）と一様な時間遅延（Shapiro）は、
今回のパイプラインが検出器ごとに自由パラメータとしてフィットした
複素振幅 α と時刻シフトに、それぞれ完全に吸収される。α≈1.00 という結果は
「ボイドの滑らかなレンズが無い」ことの証拠ですらなく、**設計上見えない**のである。
残差統計量が感度を持つのは、周波数依存の増幅（波動光学マイクロレンズ）と
遅延した副像だけであり、そのパラメータ（レンズ質量 M、規格化衝突パラメータ y、
レンズまでの距離）は θ に含まれていない。

## 6. では、どうすれば観測点をGW検証に「反映」できるか

正しい翻訳は「ビンをGWに持ち込む」ことではなく、「観測点の定義をGW側で作り直す」こと:

1. **GW版の観測点 = （イベント, ボイド, b）の組**。候補の横切りすべてについて
   Σ(b; θ) を観測量としてコードにかけ、貪欲にイベントを選ぶ。
   ただし §4 の通り、滑らかなプロファイル復元については r_eff の天井が ≈1 であり、
   この翻訳は「プロファイルを測る」目的には使えない、という結論まで含めての結果になる。
2. **パラメータを取り替える（有望なのはこちら）**: 本来の仮説はコンパクト天体の存在なので、
   θ を レンズパラメータ（M, y, 経路上の位置） に替え、観測量を残差統計量または
   周波数依存増幅 A(f) にする。このとき「観測点」は（イベント, 周波数バンド）の組になり、
   どのイベントのどの帯域がレンズ質量に効くかを、コードが本来の姿で順位付けできる。
   これは以前から選択肢にあった「テンプレート型レンズ解析」に、観測点選定として接続する。
3. **銀河側の観測点を事前情報として使う**: θ は銀河側で既に決まっている
   （Scaled r_eff 3.42）。GW側はその θ から予測される κ（≈10⁻⁵、検出不能）を
   確認するだけになるため、独立した検証にはならない。

## 7. 前提と限界

- Σ の測定誤差10%は仮定の楽観値。ただし §4 のランク崩壊は勾配の幾何（平行性）に
  起因し、誤差の絶対スケールには依らない（相対構造のみに依る）。
- Hamaus フィット点（δc が境界 −0.999）での局所診断であること、球対称ボイドの仮定、
  b はピーク視線の値で A90 が大きいイベントでは b 自体に大きな不確定性があること
  （GW231123 で A90=471 deg²、領域内の平均横切り数は 6.13）。
- ローカルボイドにはカタログのプロファイルもビンも無い。近傍30スタックの順位反転が
  示すように、足元については銀河側の観測点自体が別物になる。
