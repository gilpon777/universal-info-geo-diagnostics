# 天の川銀河への情報幾何診断 v2 の適用 — 回転曲線の質量モデル診断

「最も空な環境」（宇宙ボイド）に適用してきた診断フレームワーク v2 を、
「最も密な身近な環境」である天の川銀河に適用する対比実験。
方法はボイド検証と同一系列（フィット → 共分散推定 → v2 診断 → 貪欲選定）。

## 1. 使用データ

- **Eilers et al. 2019, ApJ 871, 120, Table 2** の円速度曲線
  （DOI: 10.3847/1538-4357/aaf648。同データは VizieR J/ApJ/871/120 および
  Zenodo DOI 10.5281/zenodo.1468053 にも収録。本解析では IOPscience の
  論文 PDF 掲載表から転記した値を使用し、`milkyway_data_eilers2019.csv` に保存）
- 点数: **38 点**、R = 5.27–24.82 kpc、APOGEE DR14 + Gaia DR2 の赤色巨星
  23,129 個から Jeans 方程式で導出された vc(R)
- 誤差の定義: 論文表の **formal（統計）誤差**（−/+ 非対称 → 本解析では平均で対称化）。
  論文自身が系統誤差 2–5% 級の存在を明記しているため、系統誤差は §3 の通り別途モデル化した
- R0 = 8.122 kpc（Gravity Collaboration 2018、Eilers+2019 と同じ値）を前提とする
  データであり、本解析でもそのまま採用

## 2. 前向きモデル（5 パラメータ）

vc²(R) = vc,bulge² + vc,disk² + vc,halo² の球対称・軸対称近似。

| パラメータ | 意味 | 備考 |
|---|---|---|
| M_bulge [10¹⁰ Msun] | バルジ質量 | Hernquist 型、スケール a = 0.6 kpc **固定** |
| M_disk [10¹⁰ Msun] | 円盤質量 | 指数円盤（Freeman 1970 の厳密解） |
| R_d [kpc] | 円盤スケール長 | 自由 |
| log10 rho_s | NFW 特性密度 [Msun/kpc³] | 自由 |
| r_s [kpc] | NFW スケール半径 | 自由 |

固定した前提: バルジスケール 0.6 kpc、R0 = 8.122 kpc、ガス円盤は独立成分として
入れない（円盤質量に吸収）、バー・非軸対称性は無視（データ自体が R < 5 kpc を欠く）。

## 3. フィットと共分散

- フィット重み: formal 誤差に系統誤差 3% を二乗和で加えたもの
  sqrt(σ_formal² + (0.03·vc)²)。理由: formal 誤差のみで最小化すると、後述の
  「平らな谷」のため解が R_d 上限＋極小 r_s の隅に走り物理的に無意味になるため。
  さらに R_d ∈ [2, 4] kpc、r_s ∈ [8, 40] kpc の文献的標準範囲を仮定として課した
  （無制約探索では境界解が支配的になること自体が縮退の証拠であり、本節末尾に記録）
- 結果: χ² = 7.0 / dof 33（系統込み誤差、χ²_red = 0.21。系統が支配的で保守的）。
  formal 誤差のみでは χ² = 107.7（χ²_red = 3.3）となり、モデルは formal 精度では
  データの微細構造（例: 19–21 kpc の ~15 km/s の偏差）までは再現しない。
  これは Eilers+2019 自身の系統評価と整合する
- パラメータ不確かさ: wild bootstrap（残差の符号ランダム反転、600 回再フィット）
- FIM 用共分散: Σ = diag(σ_formal² × 膨張係数) + 系統カーネル
  （振幅 3%、相関長 5 kpc の指数カーネル。仮定として明記）。
  感度チェックとして wild bootstrap データ集合の標本共分散版でも診断を回した（§4）

### フィット結果

| パラメータ | 値 | bootstrap σ |
|---|---|---|
| M_bulge | 2.61 ×10¹⁰ Msun | 0.36 |
| M_disk | 4.27 ×10¹⁰ Msun | 1.21 |
| R_d | 4.00 kpc（範囲上限に張り付き） | 0.19 |
| log10 rho_s | 7.533 (rho_s = 3.4×10⁷ Msun/kpc³) | 0.59 |
| r_s | 8.0 kpc（範囲下限に張り付き） | 13.6（谷のため実質無情報） |

派生量: vc(R0) = **229.3 km/s**（Eilers の 229.0 と一致）、
M200 = **4.6×10¹¹ Msun**、r200 = 164 kpc、c200 = 20.5、
局所暗黒物質密度 rho_DM(R0) = **0.31 GeV/cm³**（Eilers の 0.30 ± 0.03 と一致）。
なお Eilers の Mvir = 7.25×10¹¹ Msun はバリオン固定・定義（virial 半径）も異なる値で、
本解析の M200 と直接は比べられない。

**平らな谷の記録**: 広範囲で r_s を 10 / 15 / 20 kpc に固定して他を最適化すると
χ² = 6.40 / 6.41 / 6.41 とほぼ不変（本フィットの 7.0 との差も Δχ² ≈ 0.6 で無意）。
r_s = 15 の谷点では (M_b, M_d, R_d, log10 rho_s) = (4.35, 8.74, 5.51, 6.64) と
全く別のパラメータ組が同等の適合を与える。回転曲線だけでは質量モデルは
1 本の「谷」に沿ってしか決まらないことの直接の現れであり、§4 の診断は
この谷の局所構造を定量化したものと解釈すべきである。

## 4. v2 診断（フィット点）

| | r_eff | log10 CN | 数値ランク | 固有値 |
|---|---|---|---|---|
| Raw | **1.04 / 5** | 7.02 | 5/5 | 1.14e3, 5.74, 0.244, 0.0487, 1.09e-4 |
| Scaled | **1.74 / 5** | 6.02 | 5/5 | 4.00, 0.931, 0.0552, 0.00994, 3.84e-6 |

- 感度チェック（bootstrap 標本共分散版）: Raw 1.03 / Scaled 1.76 — 主結果とほぼ一致
- 谷点（r_s = 15）での診断: Raw 1.17 / Scaled 1.73、sloppiest 方向も同一
  （下記）→ 診断結論は評価点の選び方に依らない

### sloppy / stiff 方向

- 最も stiff（Raw）: log10 rho_s 主体（−0.99）。ハローの全体規格化は最もよく決まる
- 最も sloppy（Raw）: r_s +0.94 に M_disk +0.30、M_bulge +0.13 が混入
- 最も sloppy（相関化）: **log10 rho_s −0.77 と r_s +0.63 の組**

### 円盤–ハロー縮退は現れるか → 明確に現れる

パラメータ相関（FIM 逆行列）:
corr(log10 rho_s, r_s) = **−1.000**、
corr(M_disk, log10 rho_s) = **−0.994**、
corr(M_disk, r_s) = **+0.991**、
corr(M_bulge, M_disk) = +0.986。
bootstrap でも corr(M_disk, log10 rho_s) = −0.94、corr(M_disk, r_s) = +0.90。
すなわち「円盤を重くする ↔ ハローを軽く（rho_s を下げる／r_s を伸ばす）」の
トレードオフが相関 ≈ 0.99 で存在し、最も sloppy な固有方向は
NFW の (rho_s, r_s) 縮退軸そのものに円盤が乗り入れた方向になっている。
5–25 kpc の回転曲線が決めるのは実質「総質量プロファイルの振幅＋大まかな形」の
約 1.7 次元（Scaled）までであり、成分分解は外部情報（バリオンの測光質量、
外側トレーサー等）なしには決まらない、という古典的結論がスペクトルで再現された。

- r_eff は全 38 点で 1.035、上位半分 19 点でも 1.035（**保持率 100%**）。
  実質 4–5 点で r_eff は飽和し、残りは log det の緩やかな増加のみに寄与する
- 解釈: 情報は「両端＋太陽半径」に集中する。最外側でも誤差の大きい
  21–23 kpc の点群（順位 14–27 位）は下位に沈んでおり、
  外側ならどこでも良いのではなく**精度の良い外側点**が効く

## 6. ボイド検証との対比

| | ボイド（386 個スタック） | 天の川（回転曲線） |
|---|---|---|
| パラメータ数 | 4 | 5 |
| Raw r_eff | 1.40 | 1.04 |
| Scaled r_eff | 3.42 | 1.74 |
| Scaled log10 CN | 0.77 | 6.02 |
| 最も sloppy な方向 | β（外側スロープ）係数 0.99 | NFW (rho_s, r_s) 縮退組＋円盤の混入 |
| 貪欲選定 第1位 | 中心ビン（0.07 Rv、最も空な場所） | R = 18.24 kpc（外側レバー） |
| 上位半分の r_eff 保持率 | 98.3%（7/14 ビン） | 100%（19/38 点、数点で飽和） |

対比の要点:

- **ボイドでは「形」は決まる**（Scaled 3.42/4）。問題は外側の裾 β の S/N だった。
  天の川では逆に、データの S/N は高いのに**成分分解そのものが縮退**し、
  スケーリング不変に見ても 1.74/5 しか決まらない。空な環境の主敵は「信号の弱さ」、
  密な環境の主敵は「縮退」である
- 観測点の効き方も対照的: ボイドでは最も空な中心が最優先だったが（近傍ボイドでは
  S/N の都合で壁内側に反転）、天の川では最内アンカー・太陽半径・外側レバーの
  「両端と基準点」が効く
- 両者に共通するのは、r_eff がパラメータ数より大幅に小さいことと、
  「上位半分の観測点で情報のほぼ全てが賄える」こと —
  観測点選定の余地が大きいのは環境の密度によらない

## 8. 限界

- 球対称・軸対称近似。バーや渦状腕などの非軸対称性は無視（データが R < 5 kpc を
  欠くため内側構造は外挿依存）
- バリオン形状の固定: バルジスケール 0.6 kpc 固定、円盤は単一指数型、
  ガス円盤は独立成分として扱っていない（円盤質量に吸収される）
- 系統誤差の取り扱いはモデル化（3%・相関長 5 kpc のカーネル）であり実測ではない。
  ただし共分散の取り方を変えた感度チェックでも r_eff はほぼ不変だった
- フィット範囲（R_d, r_s の文献的範囲）という仮定を置いており、最適解は両端に
  張り付く。診断は局所的なもので、§3 に記録した「平らな谷」の大域構造と
  併せて読む必要がある（谷点での再診断で結論の頑健性は確認済み）
- R0 はデータ側の前提（8.122 kpc）に固定。R0 の不確かさは誤差予算に入っていない
