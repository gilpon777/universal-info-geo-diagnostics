# GW240925_005809 波形レンズ残差解析レポート

作成: 2026-11-08 / 対象: GW240925_005809 (GPS 1411261108.0, H1+L1+V1 検出、
本解析は H1+L1 を使用、ネットワーク SNR 31.2 (GWOSC カタログ値))
位置づけ: GW231123_135430 (遠方ボイド型)・GW250114_082203 (高 SNR 型) と異なり、
本イベントは local_voids.md で「Local Void (天の川銀河の側のボイド) を最終区間で
長く通る経路」の代表候補として挙がったもの (Tully 球モデルで弦長 44.8 Mpc、
距離 356 Mpc、A90 = 25.9 deg²、Pcov = 1.00) であり、**Local Void 区間そのものを
直接問う初めての波形チェック**である。手法は先行 3 件と同一 (μ-GLANCE 流:
最良適合波形の差引 + 残差の検出器間相互相関、窓・統計量も同一)。

---

## 1. 結論 (上限的表現)

- 計画窓 [-1.5, +0.5] s: 残差統計量 S_resid = 0.067。オフソース背景 (n=936 窓) の
  中央値 0.066 とほぼ一致し、経験的 p ≈ 0.46。**有意な残差相互相関なし。**
- 信号整合窓 [-0.6, +0.3] s: S_resid = 0.100 (背景中央値 0.098、p ≈ 0.42)。
  こちらも有意でない。
- 正対照 (未差引データ): S_raw = 0.199 / 0.348 で、両窓とも背景の全窓を超過
  (exceed = 0、p は背景サイズの分解能限界 ≈ 1.1×10⁻³)。パイプラインが
  コヒーレント成分を捉えることは本イベントでも実証された。
- よって結論は: **「この感度では、Local Void を長く通るこの経路について、
  干渉の証拠は得られなかった」**。これはボイド内の不可視天体の不存在を
  意味しない (存在の否定ではない)。また本結果は本イベントの視線・最終区間に
  対する上限であり、**Local Void 全体の存否に一般化できるものではない**。
- 感度の実測 (注入法、§5): 背景 99% 点を超えるのに必要な信号同形コヒーレント
  残差は信号振幅の **約 58% (計画窓) / 36% (信号整合窓)**。先行 2 件の同一手法
  実測 (GW231123: 82% / 47%、GW250114: 26% / 24%) の中間に位置し、SNR 約 30 の
  イベントとして想定通り。10% 級の波動光学レンズ増幅は本イベントでも感度外。

### 2.1 較正バージョン: PE は C01 のみ (C00 は存在しない)

- 本イベントの Hanford データは較正に事情があり、C00 は誤較正・C01 が
  較正済みとされる (GWOSC イベントポータルでも本イベントは version v2 として
  掲載)。ダウンロードした PE ファイルのグループは **全て C01**
  (C01:IMRPhenomXPHM-SpinTaylor / C01:IMRPhenomXPNR / C01:SEOBNRv5PHM /
  C01:Mixed) で、C00 グループは存在しない。すなわち公開 PE 自体が較正済み版
  であり、本解析は自動選択により **C01:IMRPhenomXPHM-SpinTaylor**
  (20,000 サンプル) を使用した。要件 (C01 の使用) はこの形で満たされる。
- ストレインは GWOSC の標準公開リリース (O4b_4KHZ_R1) を使用。差引時の
  複素振幅フィット α (§3) が両検出器とも 1 の数 % 以内であり、C01 PE と
  公開ストレインの間に実務上の不整合は見られなかった。

### 2.2 データの注意: H1 の NaN 区間と有効区間の限定

- L1 は 4096 s 全区間が有効。一方 H1 は NaN 区間を 2 つ含む:
  **[590.0, 661.0) s の 71 s 欠落**と、**[1773.0, 4096.0) s の末尾欠落**
  (有効総量 1702 s)。イベント (692.0 s 地点) 自体は欠落の外にある。
- このため解析は両検出器共通の有効区間 **GPS [1411261075, 1411262189)**
  (ファイル内 [659.0, 1773.0) s、1114 s) に限定した。ただし H1 はこの区間の
  先頭 2 s ([659, 661) s) が NaN のためゼロ充填した。この 2 s はオンソース
  64 s セグメントの先頭 (Tukey テーパー域、重み ~0.04 以下) かつマージャーの
  31 s 以上前に位置し、統計量への影響は無視できる水準と判断した (充填量は
  ログと control_results.json に記録: H1 = 8192 サンプル、L1 = 0)。
- 背景は同区間のホワイトニング済み 1088 s (17 ブロック × 64 s) から取り、
  窓数は計画窓 936 / 信号整合窓 921 (RMS 外れ値窓の除外は計画窓 78 件、
  信号整合窓 94 件)。p 値の分解能限界は約 1.1×10⁻³。

## 3. 手法と検証

1. **テンプレート再選択**: 先行件と同一手順 (logL 上位 2000 サンプルを 8 s
   セグメント・PE PSD での network MF で測り直し)。採用サンプルは idx 8369
   (m1 = 12.5, m2 = 5.9 Msun (検出器系)、DL = 394 Mpc、χeff = +0.14)、
   network MF (8 s) = 29.61 (H1 = 16.55, L1 = 24.56)。カタログの
   ネットワーク SNR 31.2 (Virgo 込み) と整合的。
2. **較正の整合性**: argmax logL サンプルの MF は H1 = 16.13, L1 = 24.23 で、
   再選択後の値とほぼ一致。先行件のような大きな不整合はない。
3. **複素振幅フィット**: |α| は H1 = 0.966 (実効距離 408 Mpc)、L1 = 1.036
   (同 380 Mpc)。両検出器とも α ≈ 1 の数 % 以内で、テンプレート振幅の
   再調整は小さい。時間ずれフィットは H1 = −4.88 ms、L1 = −3.91 ms
   (両検出器で同符号・同程度であり、正対照の相互相関ピーク lag = −4.9 ms
   とも一致)。64 s セグメントでの MF は H1 = 16.69、L1 = 25.99
   (H1+L1 合成で約 30.9)。
4. **統計量**: S = max_{|lag|≤50 ms} |C(lag)| (正規化相互相関)、先行件と同一。
   背景は同一ファイル内のオフソース窓 (イベント ±40 s 除外)。

## 5. 感度の実測 (注入法)

方法は先行件と同一: 差引後の残差 (ホワイトニング済み) に差引済みテンプレート
そのものを割合 f で加え、同一統計量 S(f) を測り、背景 p99 (および参考として
背景 max) を超える f を線形内挿で求める。検証として f=0 で S_resid、f=1 で
S_raw を両窓とも厳密に再現した。

| 窓 | GW240925 f99 | GW240925 f (背景 max) | GW231123 f99 | GW250114 f99 |
|---|---|---|---|---|
| 計画窓 | **0.58** | 0.67 | 0.82 | 0.26 |
| 信号整合窓 | **0.36** | 0.49 | 0.47 | 0.24 |

- 本イベントの S(f) の実測点 (抜粋): 計画窓では f=0.40 まで S ≈ 0.068 と
  ほぼ横ばい (S_raw 自体が 0.199 と小さいため)、f=0.5 で 0.081、f=0.6 で
  0.100、f=1 で 0.199。信号整合窓では f=0.10 で 0.099、f=0.25 で 0.116、
  f=0.40 で 0.149、f=1 で 0.348。
- 解釈: f99 は SNR の中間にある本イベントで想定通り中間の値となった。
  本統計量 (正規化相互相関) では背景のばらつきが支配的で、必要残差割合は
  SNR に単純比例しない、という先行件の知見と整合する。10% 級の波動光学
  レンズを本手法で見るには、さらなる高 SNR イベントか、テンプレート型
  (レンズモデル付き) 解析・複数イベントの組合せが必要、という見通しも
  変わらない。

## 6. 限界と注意

- **感度**: §5 の通り、本解析が届くのは信号振幅の約 36〜58% 以上の信号同形
  コヒーレント残差まで。10% 級の波動光学レンズは感度外であり、本結果は
  「証拠なし (上限)」に留まる。
- **一般化の禁止**: 本結果は単一イベント・単一視線の最終区間 (Local Void の
  一部の弦) に対する上限である。Local Void 全体、あるいは他の経路について
  不可視天体の存否を結論するものではない。
- **窓と信号長の関係**: 本イベントは軽い系 (検出器系チャープ質量 ≈ 7.4 Msun)
  で、20 Hz からの信号長は約 8 s ある。比較可能性のため窓は先行件と同一
  (マージャー前後の 2.0 s / 0.9 s) に揃えたため、窓外のインスパイラル区間に
  仮に署名があっても本統計量の対象外である。正対照が両窓とも背景全窓を
  超過していることから、窓内のコヒーレント成分の検出能力自体は確認済み。
- **注入形状の仮定**: 感度はテンプレート同形の残差に対する定義。実際の
  波動光学レンズの署名 (周波数依存の増幅・うなり) はテンプレートと完全には
  同形でなく、直交成分は本統計量で見えにくい可能性がある。
- **背景の分解能**: 有効区間の制約で背景窓は約 900 個、p の分解能は
  約 1.1×10⁻³。正対照の p は分解能限界での上限表現に留めた。
- **H1 のゼロ充填**: §2.2 の通り、有効区間先頭 2 s の NaN をゼロ充填した。
  位置 (セグメント先頭のテーパー域) と α・較正 MF の整合から影響は小さいと
  判断するが、厳密には未検証の近似として残る。
- **テンプレートの不完全さ**: PE 標本内再選択 + 線形 α フィットであり完全な
  再 PE ではない。Virgo は本パイプライン (H1×L1) では未使用であり、
  カタログ SNR 31.2 に対し本解析の実効は H1+L1 の約 30.9。
- **経路側の近似**: 弦長 44.8 Mpc は Tully 球モデルに基づく近似値であり、
  Local Void の形状・境界の不確かさを含む (local_voids.md の留保を参照)。
