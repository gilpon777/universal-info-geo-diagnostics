# 重力波イベント × 近傍ボイド 重ね合わせ — 所見

作成: 2026-11-07 / 図: [gw_overlay.png](gw_overlay.png)

## 1. この重ね合わせの目的と解釈

この図は「GW イベントがボイドの中にあるか」を見るものではない。見るのは、
**観測された重力波の伝播経路（視線方向）が、近傍宇宙（z < 0.114 の殻）にある
ボイドを横切っているか**である。遠方のイベントでも、その重力波は地球に届くまでに
近傍の殻を必ず通過する。したがって天球上の重なりは「経路がボイドを横切る方向」
として意味を持つ。

さらにこの重なりは、ユーザーの仮説——「ボイド内にブラックホールのような
見えない天体があれば、そこを通過する重力波は必ず干渉（重力レンズ等の影響）
を受けるはず。電磁波では見えなくても、重力波の経路解析からは『見えないけどある』
が浮かび上がるはず」——に対する**候補選定の第一歩**と位置づける。
すなわち、ここで抽出されるのは「経路上にレンズ候補天体が存在し得る視線」を
持つイベントであり、干渉の有無そのものは各イベントの波形解析
（レンズ付き波形との照合・残差解析）でしか判定できない。

## 2. 使用データ（出典・件数・取得日: 2026-11-07）

### ボイド（従来の検証と同じ）
- VAST void catalogs for SDSS DR7（Douglass et al. 2023, ApJS 265, 42）、
  Zenodo record 6081273（v1.1.0）、VIDE/ZOBOV 系 531 ボイド。
- うち今回も「使用ボイド」386 個（Rv ≥ 10 h⁻¹Mpc、中心 + 2Rv が z = 0.114 の殻内）。
- 各ボイドは天球上の円盤として扱う。角半径は視線の衝突パラメータ条件
  θ = asin(Rv / DC)（DC = ボイド中心の共動距離）で定義した。
  これは「その方向の重力波がボイド球の内部を通過する」条件そのものである。
  角半径は 1.8°〜28.7°。円盤の合併は全天の 18.2%（7,490 deg²）、
  カタログ範囲（RA 113.8–257.6°、Dec −1.2–66.7° の矩形）の 92.2% を覆う。

### 重力波イベント
- イベント一覧と距離・赤方偏移: GWOSC（gwosc.org）Event Portal API v1 の
  統合カタログ「GWTC」bulk JSON。総数 **391 件**
  （内訳は各イベントの最新帰属: GWTC-5.0: 161、GWTC-4.1: 140、
  GWTC-2.1-confident: 54、GWTC-3-confident: 35、GWTC-1-confident: 1）。
- skymap（FITS）: 各 GWTC の公式 Parameter Estimation データリリース（Zenodo）
  に収録のアーカイブから取得し、**228 件**を処理した。
  - GWTC-3 PE リリース（record 22685054）`PESkyLocalizations.tar.gz`: 36 件
  - GWTC-4.1 PE リリース（record 20275769）`Archived_Skymaps.tar.gz`: 88 件
  - GWTC-5.0 PE リリース Part 1（record 20348005）`Archived_Skymaps.tar.gz`: 104 件
  - イベント毎に複数波形モデルの skymap がある場合は
    IMRPhenomXPHM 系を優先して 1 枚を採用した。
- 処理できなかった 163 件の内訳: GWTC-2.1-confident 54 件
  （同リリースには skymap FITS がなく統計テキストのみ）、GWTC-1-confident 1 件、
  GWTC-4.1 の 52 件と GWTC-5.0 の 57 件（各 PE リリースに skymap が
  収録されていないイベント）。これらは位置を推測で補わず除外した。
  GW170817・GW150914 の GraceDB 上の skymap は認証が必要（HTTP 401）で取得不可だった。

### 処理方法
- 90% 局在領域は最高確率密度領域（確率密度の降順に確率質量を累積し 90% に達する
  ピクセル集合）として skymap から再計算した。ピーク位置は最大確率密度ピクセルの中心。
- 解析グリッドは HEALPix NSIDE=256（NESTED、ピクセル約 0.052 deg²）。
- イベント毎に記録した量: ピーク位置、90% 面積 A90、90% 領域の確率のうち
  使用ボイド円盤内にある割合（確率被覆率 Pcov）、90% 領域と交わる使用ボイドの数、
  横切る最大のボイド、ピーク視線自体が使用ボイドを横切るか。
  全イベントの数値は `gw_skymaps/gw_events_processed.json` にある。

## 3. 結果サマリー

- 処理した 228 件のうち、**139 件（61%）** の 90% 領域が少なくとも 1 個の
  使用ボイド円盤と重なった（＝その視線候補の一部がボイドを横切る）。
- **42 件** はピーク位置（最尤の視線）自体が使用ボイドを横切った。
- 確率被覆率 Pcov ≥ 0.9 が **7 件**、≥ 0.5 が **22 件**。
  これらは「局在領域の確率の大部分がボイド円盤の中に収まる」イベントで、
  経路選定の観点では最もクリーンな候補である。
- 横切るイベントが横切る使用ボイド数の中央値は 63 個（ボイド円盤同士が
  天球上で大きく重なるため）。最大は GW230911_195324 の 374 個
  （ただし A90 ≈ 36,000 deg² 級の巨大局在で、経路は実質定まっていない）。
- A90 の中央値は 1,563 deg²。局在が広いイベントでは重なりは必然的に増えるため、
  重なりの「有無」より「小さい A90 で高い Pcov」が選定指標になる（§5 の注意参照）。
- 図の表示範囲内にピークが入ったのは 228 件中 57 件（GW は全天分布、
  ボイドカタログは北天の SDSS フットプリントのみ）。

### 最大ボイドを横切るイベント群
最大の使用ボイド（Rv = 46.9 h⁻¹Mpc、z = 0.042、角半径 21.9°）を
90% 領域が横切るイベントは **65 件**。うち Pcov が高いものは
GW231123_135430（1.00）、GW240512_024139（0.98）、GW240515_005301（0.81）、
GW231213_111417（0.78）、GW240621_200935（0.76）。
このボイドは天球上で非常に大きいため横切る件数自体は多くなるが、
上記のように高 Pcov のものは「大きなボイドを横切る視線」として優先度が高い。

## 5. 近傍イベントと GW170817

- 処理済みで最も近い **GW230529_181500**（光度距離 203 Mpc、z = 0.04、
  NSBH 候補）は A90 = 24,497 deg² とほぼ全天に広がり、経路は定まらない
  （Pcov = 0.09）。近さと経路選定のしやすさは別問題である。
- **GW200105_162426**（NSBH）は A90 = 8,258 deg²、Pcov = 0.26。
  なお GWOSC bulk JSON ではこのイベントの光度距離・赤方偏移が欠落していた。
- **GW200115_042309**（光度距離 290 Mpc）はピークが RA 40.8° と
  フットプリントの外にあり、90% 領域も使用ボイドと重ならなかった。
- **GW170817**（z ≈ 0.01、光度距離 ≈ 40 Mpc）は、全経路が近傍殻の内側にある
  唯一級のイベントで、本来は真っ先に判定したい対象である。しかし
  (1) skymap が GraceDB 認証の壁で取得できず、
  (2) 対応天体 NGC 4993 の方向（Dec ≈ −23°）は南天で、SDSS DR7 ボイドカタログ
  （Dec ≥ −1.2°）の範囲外にあるため、**本カタログでは経路判定ができない**。
  南天のボイドカタログ（DES 等）を用意すれば判定可能になる。

## 6. 解釈上の注意（線引き）

1. **重なりは候補選定であって干渉の検出ではない。** 干渉の有無は、
   選定したイベントについてレンズ付き波形モデルとの照合や波形残差の解析を
   行って初めて言える。本図と本所見は、その解析対象を絞り込む段階の成果物である。
2. **偶然の重なりの基線が高い。** 使用ボイド円盤はカタログ範囲の 92.2% を覆う
   （円盤同士の重なりを含む）。したがって「どれか 1 個のボイドと重なる」こと
   自体は珍しくない。意味を持つのは、§4 のように小さい A90・高い Pcov・
   ピーク視線の横切り・大型ボイド中心近傍の通過が揃ったケースである。
3. **近傍ボイドは経路の最終区間にある。** z < 0.114 のボイドは、遠方イベントの
   重力波にとって経路の地球側末端（最後の最大で約 500 Mpc）に位置する。
   レンズ天体が観測者に近い場合、一般に像の分離角は大きく・時間遅延は
   短くなる傾向があり、署名の出方は遠方レンズとは異なる。
4. **干渉の現れ方（一般論）。** レンズ天体の質量と重力波の波長の関係で
   振る舞いが変わる。波長がレンズのシュバルツシルト半径より十分短い
   幾何光学の極限では、多重像・時間遅延・像ごとの拡大率差として現れる。
   波長が comparable になる波動光学の領域では、周波数依存の増幅と
   干渉による「うなり」（周波数方向の振動パターン）が波形に刻まれる。
   地上検出器帯域では、恒星質量〜中間質量級のコンパクト天体で
   波動光学的な署名が問題になり得る。
5. **ボイド自体は干渉源として想定していない。** 低密度領域そのものの
   重力レンズ効果は発散レンズとして微小である。本仮説の対象は、
   ボイド内に潜むコンパクトな不可視天体（ブラックホール等）であり、
   ボイド内は銀河が少なく電磁波サーベイの目が届きにくいことが
   「見えないけどある」を探す動機になっている。

## 7. 限界

- skymap を処理できたのは 391 件中 228 件（§2 の内訳）。O1/O2/O3a の
  GWTC-2.1 世代は skymap FITS の公開がなく、系統的に欠けている。
- ボイドは球近似し、円盤判定は NSIDE=256 グリッド（約 0.23° 角）で行った。
  円盤境界付近の判定にはこの程度の離散化誤差がある。
- 90% 領域は公開 skymap からの再計算値であり、各カタログ論文の公表値と
  丸め・波形モデル選択の範囲で差があり得る。GW200105_162426 のように
  GWOSC bulk JSON 側に距離値がないイベントもある。
- ボイドカタログ自体の限界（z < 0.114、北天のみ、エッジカット）は
  従来の検証（results.md）と共通。
