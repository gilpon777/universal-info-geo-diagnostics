# GW231123_135430 波形レンズ残差解析レポート

作成: 2026-11-07 / 対象: GW231123_135430 (GPS 1384782888.7, H1+L1, ネットワーク SNR 21.8)
目的: zoom_analysis.md で特定した「2つの大型ボイドをほぼ中心で貫く経路」について、
経路上の不可視天体による波動光学レンズ等の干渉の署名が、公開波形データの残差に
残っているかを μ-GLANCE 流のモデル非依存手法 (最良適合波形の差引 + 残差の
検出器間相互相関) で初めて確かめる。重なりは候補選定であって検出ではない、が前提。

---

## 1. 結論 (上限的表現)

- 主窓 [-1.5, +0.5] s: 残差統計量 S_resid = 0.061。オフソース背景 (n=3703 窓) の
  中央値 0.065 と同水準で、経験的 p ≈ 0.68。**有意な残差相互相関なし。**
- 感度変種窓 [-0.6, +0.3] s: S_resid = 0.109 (背景中央値 0.097、経験的 p ≈ 0.20)。
  こちらも有意でない。
- 正対照 (未差引データ): S_raw = 0.122 / 0.231 で、両窓とも背景の全窓を超過
  (p < 2.7×10⁻⁴、背景サイズによる分解能限界)。検出パイプライン自体は
  コヒーレント成分を確かに捉えることが実証された。
- よって結論は: **「この感度では、干渉の証拠は得られなかった」**。
  これはボイド内の不可視天体の不存在を意味しない (存在の否定ではない)。
- 感度の目安: 本統計量で背景 99% 点を超えるには、信号と同形のコヒーレント残差で
  信号振幅のおよそ 6〜8 割 (窓依存) が必要と見積もられる。計画メモに挙げた
  μ-GLANCE の目安 (SNR≈30 で増幅 10% 級から) には届いておらず、10% 級の
  波動光学レンズ増幅は本イベント・本手法の感度外である。

  - https://gwosc.org/archive/data/O4a_4KHZ_R1/1384120320/L-L1_GWOSC_O4a_4KHZ_R1-1384779776-4096.hdf5

## 3. 手法と検証

1. **テンプレート候補の再選択**: GWTC-4.1 PE は距離 (と位相・時間) が周辺化されて
   おり、保存された最尤サンプルの luminosity_distance (800 Mpc) と保存
   optimal SNR が再生成と整合しないことを実測で確認した
   (保存 (h|h): H1=180, L1=266 に対し、再生成では H1=1036, L1=2002)。
   そこで logL 上位 2000 サンプルについて、8 s セグメント・PE PSD での
   network MF SNR を実データで測り直し、最大のサンプル (idx 19435、
   m1=173.4, m2=102.5 Msun (検出器系)、DL=716 Mpc、χeff=0.12) を採用した。
2. **複素振幅フィット**: 検出器ごとに複素振幅 α=(d|h)/(h|h) と微小時間ずれ
   (H1: −6.8 ms, L1: −3.9 ms) をフィットしてから差し引いた。
   |α| は H1=0.649, L1=0.592 で、実効距離は 1104 / 1211 Mpc に相当する
   (採用サンプルの保存 DL 716 Mpc とは異なる。周辺化 PE の再構成に伴う
   不整合の現れと解釈する)。
3. **検証の数値**:
   - 較正サンプルでの FD 内積 MF が独立な TD 計算と一致 (H1: 12.42 vs 12.48)。
     相互相関系列の規格化も直接和と一致 (照合スケール 1.000)。
   - 採用サンプルの MF: H1=12.62, L1=15.39、network=19.90
     (探索パイプラインの network MF SNR 21.8 と整合的な水準)。
   - 差引後のオンソース窓エネルギー (ホワイトニング済み): 計画窓で
     H1 56.9→54.4、L1 56.6→53.1 (ノイズのみの期待 ~45.3)。
     ノイズ水準までは落ち切らず、テンプレート形状の残存ミスマッチ
     (歳差位相の再現限界) が残る。これは感度を制限する要因として扱う (§5)。
4. **統計量**: S = max_{|lag|≤50 ms} |C(lag)| (正規化相互相関)。
   背景は同一 4096 s ファイルのオフソース窓 (2.0 s または 0.9 s、1 s ステップ、
   イベント ±40 s 除外、RMS 外れ値窓は除外して件数を記録: 計画窓で 311 件)。

### 4.1 カタログ全体 (処理済み 228 イベント) の中での GW231123_135430

既存の視線解析の枠組み (使用ボイド 386 個、Planck2018) で全 228 イベントの

| Pcov (90% 領域の被覆確率) | 1.000 | 1.0 は 228 件中 3 件のみ。中央値は 0.05 |
| ピーク視線の最小 b/Rv | 0.088 | 視線がボイドを横切る 42 件の中で最小 = **全体で最も中心を貫く** |
| 最大ボイド idx283 の横切り | 該当 (b/Rv=0.146) | 該当は 7/228 件のみ |
| 弦長合計 | 239 h⁻¹Mpc = 355 Mpc | 順位 10/228 (95.6 パーセンタイル)。中央値は 0 |
| ピーク視線の横切り数 | 6 個 | 順位 16/228。横切り ≥1 は 42/228 件のみ |
| A90 | 471 deg² | 順位 55/228 (小さい側から 23.7%) |

つまり GW231123 の経路は、現在の観測イベントの中で被覆率・中心貫通・弦長の
複合で最上位クラスにあり、特に「視線がボイド中心に最も近い」点では
カタログ全体で単独 1 位である。今回この経路を選んで波形解析の第一号とした
判断は、カタログ定量の上でも裏付けられる。

**GW240413_022019 (実施済み)**: GWTC-5.0、GPS 1397010037.8、O4b ストレイン

経路条件は A90=37 deg²、Pcov=1.00、距離 570 Mpc で、GW231123 と並ぶ
「クリーンな経路」の対照である。物理系は対照的に軽い
(再選択サンプルで m1=15.3, m2=3.9 Msun、network MF 16.4)。

| 窓 | S_resid | 背景中央値 | p (残差) | S_raw (対照) |

| 計画窓 [-1.5,+0.5] s | 0.065 | 0.067 | 0.562 | 0.065 |
| 信号整合窓 [-0.6,+0.3] s | 0.086 | 0.098 | 0.825 | 0.132 |

- なお本イベントでは未差引の S_raw も計画窓では背景水準 (信号が軽く長く、

## 5. 限界と注意

- **感度**: §1 の通り、10% 級の波動光学レンズは本解析の感度外。μ-GLANCE の
  本来の適用 (最適窓設計、複数イベントの組合せ、検出器間遅延の精密化) が
  次段階として必要。
- **テンプレートの不完全さ**: PE 標本内再選択 + 線形 α フィットであり、
  完全な再 PE ではない。差引後も窓エネルギーがノイズ水準まで落ち切らない
  残存ミスマッチがある。ただし残差統計量は背景水準にあり、その残存が
  本統計量の偽陽性にはなっていない (逆に言えば、感度はこの残存にも制限される)。
- **背景の分解能**: 背景窓は ~3700 個で、p 値の分解能限界は ~2.7×10⁻⁴。
  FAR 換算は試行レート基準の参考値に留め、本文では p 値で述べる。
- **経路側の近似**: ボイドは球近似、カタログは z<0.114 の近傍のみ。
  経路の残り (z>0.114) の構造は未考慮。
- **単一イベント**の結果であり、レンズ候補天体の存在・不存在については
  何も結論しない (上限的結論のみ)。
- 実装経緯: 当初 pycbc の matched_filter で進めたが、テンプレートとデータの
  FD 時間原点 (epoch) の不一致で差引が無効になる問題があり、numpy+LAL の
  明示的な内積実装に切り替えて全数値を検証し直した (較正値の一致で確認)。

## 7. 追記 (2026-11-07): GW250114_082203 の実施結果

§4.2 で「未実施・次段階」とした GW250114_082203 (SNR 78.6) の残差解析を
実施した。詳細は gw250114_waveform.md。要点のみ:

- 残差は両窓とも背景と整合 (計画窓 S = 0.061, p ≈ 0.71 / 信号整合窓
  S = 0.086, p ≈ 0.81)。正対照は S_raw = 0.598 / 0.742 と背景全窓を超過。
  結論は本解析と同じく「この感度では干渉の証拠なし (上限)」。
- 感度を注入法で実測: 背景 p99 を超えるのに必要な信号同形残差は信号振幅の
  約 26% (計画窓) / 24% (信号整合窓)。本解析 (GW231123) に同一注入法を
  適用した実測は 82% / 47% で、改善は約 3.2 倍 / 2.0 倍。10% 級の波動光学
  レンズは依然として感度外。
- 注意点: GWOSC O4b 配布ファイルは末尾 (1275 s 以降) が NaN で、解析は
  非 NaN の先頭 1275 s 区間に限定した (背景窓は約 1000 個)。

## 8. 追記 (2026-11-08): GW240925_005809 の実施結果 (Local Void 区間)

local_voids.md で「Local Void を最終区間で長く通る経路」の代表候補とした
GW240925_005809 (弦長 44.8 Mpc、356 Mpc、A90 = 25.9 deg²) の残差解析を
実施した。詳細は gw240925_waveform.md。要点のみ:

- 残差は両窓とも背景と整合 (計画窓 S = 0.067, p ≈ 0.46 / 信号整合窓
  S = 0.100, p ≈ 0.42)。正対照は S_raw = 0.199 / 0.348 と背景全窓を超過。
  結論は先行件と同じく「この感度では干渉の証拠なし (上限)」。本結果は
  本イベントの視線・最終区間に対するもので、Local Void 全体への
  一般化はしない。
- 感度を注入法で実測: f99 は計画窓 0.58 / 信号整合窓 0.36 で、
  GW231123 (0.82 / 0.47) と GW250114 (0.26 / 0.24) の中間。
  10% 級の波動光学レンズは本イベント (SNR 31.2) でも感度外。
- データの注意: (a) PE は較正済み C01 版のみが公開されており
  (C01:IMRPhenomXPHM-SpinTaylor を使用、C00 は存在しない)。
  (b) ストレインは O4b_4KHZ_R1 (準備段階の想定 O4a は誤り)。
  (c) H1 ファイルは [590, 661) s と [1773, 4096) s が NaN のため、
  解析は共通有効区間 GPS [1411261075, 1411262189) に限定し、
  先頭 2 s の NaN をゼロ充填した (背景窓は約 900 個)。

詳細は gw241011_waveform.md。要点のみ:

- データの注意: (a) PE は C00 のみ (C00:IMRPhenomXPHM-SpinTaylor を使用、
  C01 は存在しない。GW240925 とは逆の構成)。(b) ストレインは
