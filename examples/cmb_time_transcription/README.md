# 背景放射を「時間の転写」として読む — ボイドとの重ね合わせと、晴れ上がりから初期銀河までの帳簿

*Reading the CMB as a transcription over time: overlaying voids on the background
radiation, and the ledgers from recombination to the first galaxies.*

著者: Kenichi Nakatani（中谷）

## これは何か

宇宙背景放射（CMB）は「昔の宇宙の写真」として説明されることが多い。しかし
実際に届いているのは、スープの時代から晴れ上がり（再結合、z≈1100）を経て
138億年を旅した光子の**履歴の転写**である。光子は途中で重力ポテンシャルに
出入りし（ISW）、構造に曲げられ（レンズ）、再イオン化した電子に散乱され（τ）、
そして出発前のプラズマでは熱注入の総量がスペクトルの形に溶け込んだ（μ歪み）。
これらはすべて「時間積分」の量であり、積分として読めば、晴れ上がりの前と後に
何がどれだけ起きたかを、**上限の数字**として帳簿に付けられる。

本パッケージは、この読み方で 2026-11-12 の一晩に実行した検証の記録である。
題材は著者自身のボイド（宇宙の大規模な空洞）カタログと、公開データ
（Planck、COBE/FIRAS）である。結論の文法は一貫している:

> **null は「無かった」ではなく「この感度での上限」。**
> 予言が上限の内側にあるかどうかまで数値で示す。

## 時間軸の全体（結果一覧）

| 段階 | 時代・対象 | 読んだ量 | 結果 |
|---|---|---|---|
| 1–2 | ボイド内の原始 BH 種 | 存在数と GW レンズの当選確率 τ | 種はいても視線は当たらない（下記） |
| 3 | ボイド銀河の中心 BH | 過重テストの設計 | δ=0.3 dex を n=44–90/群で分離可能（設計） |
| 4 | 晴れた後（z≈0.1 のボイド） | ISW（ポテンシャルの変化率） | −0.15 ± 1.30 µK、2σ ≲ 2.6 µK |
| 5 | スープ時代（z 5万–200万） | μ歪み（熱の総量） | μ = (−3.2 ± 6.6)×10⁻⁵、Δu/u ≲ 1.2×10⁻⁴ |
| 6 | 晴れた後の積分 | レンズ収束 κ（育った構造の総質量） | 補償κ −3.6×10⁻⁵ ± 4.4×10⁻⁴、2σ ≲ 9.1×10⁻⁴ |
| 7 | 晴れた後→初期銀河（z 20–6） | τ × 崩壊割合 × 光子予算 | 2つの帳簿が z≈7.5 で一致 |

## 段階1–2: ボイドの中に種はいるか、視線は当たるか

問い: 宇宙初期に生まれた原始ブラックホール（PBH）が銀河の種として
ボイド内にいたとして、著者の重力波レンズ検証（波形残差、別リポジトリ内
`results/` の先行作業）で見えるはずだったか。

- **v1（`pbh_void_estimate.py`）**: 種の存在量を最小の種付けシナリオ
  f=10⁻¹² で置いても、大きなボイド（R=30 Mpc）には太陽質量 3 倍の種が
  約 **189 個**、局所ボイドには約 **80 個** 入る。「空に見える」と
  「種がいる」は両立する。一方、重力波の視線がレンズに当たる確率 τ は、
  f=1（あり得ない上限）でも GW231123 のボイド弦長で **1.7×10⁻⁴**、
  局所ボイド視線で 2.5×10⁻⁶。τ は固定 f ではレンズ質量に依らない
  （総質量密度だけの量）ことも数値で確認した。既存の null は
  「いない証明」ではなく「当たらない確率が支配的」という読みが正しい。
- **v2（`pbh_void_estimate2.py`）**: 一番軟らかい仮定「PBH が暗黒物質と
  同じ割合でボイドに残る」を2方向から改善。(A) 形成バイアス:
  peak-background split で、形成時代（δ_b ~ 10⁻⁵）には将来ボイドになる
  場所でも形成率比は **0.996–1.004** — PBH はボイドの地図が描かれる前に
  配られていた。(B) 集団誕生＋暴走合体: 残骸（150–1500 M☉）が大きな
  ボイドに 0.2–1.9 個残り、こちらの質量帯は重力波の波動光学窓
  （w ≈ 0.7–2.5）に入る。設計への帰結として、ボイド銀河の中心 BH の
  質量オフセット Δ の分布は「尾・二峰性」を持つはずで、尾の超過を
  見る検定は n ≈ 51/群で届く。

## 段階3: ボイド銀河の中心 BH 過重テスト（設計）

`void_bh_power.py` ＋ `results/reports/design_void_bh_test.md`。

観測量は Δ = log₁₀(M_BH) − 局所 M_BH–M* 関係の予測値、ボイド群と
フィールド群の平均差。予測はシナリオで符号が分かれる:

| シナリオ | 予言（ボイド − フィールド） |
|---|---|
| 重い種が先行（PBH・直接崩壊） | +0.5 ～ +1.5 dex |
| 標準シミュレーション（EAGLE 等） | +0.1 ～ +0.2 dex |
| 軽い種がボイドで飢える | −0.3 ～ −1.0 dex |

分離目標 δ=0.3 dex、σ_tot=0.5 dex/天体で必要数は n=44/群
（上限値 50% を含むモンテカルロでは 90/群）。SDSS DR12 のボイド AGN
3,100 件で Stage 1 は既存データから可能で、本当の壁は統計でなく
ビリアル質量の系統誤差（~0.4 dex）。本パッケージでは設計までで、
実行はしていない。

## 段階4: ISW スタック — ポテンシャルの変化率

`isw_stack.py`。Planck PR3 SMICA 温度マップ × 著者の VAST/VIDE ボイド
441 個（0.02<z<0.114、R_v ≥ 12 h⁻¹Mpc、|b|>20°）。推定量は補償開口
（円盤 r<R_v から輪 1.4–1.8 R_v を引く）と動径プロファイル、
誤差は同一フットプリント内のランダムスタック 200 回。

- 補償開口: **−0.15 ± 1.30 µK（−0.11σ、p=0.91）— null**
- 中心ビン: −0.94 ± 2.44 µK。2σ 上限は補償開口 ≲ 2.6 µK
- ΛCDM の予言（中心 −0.5～−2 µK）は上限の内側。検出（−1 µK を 3σ）
  には σ≈0.33 µK、つまりボイド数 **約15倍** が要る — 制限資源は
  1個の深さではなく個数である

## 段階5: FIRAS μ — スープ時代の熱を自分で測る

`firas_mu.py`。COBE/FIRAS の単極スペクトル（Fixsen et al. 1996 Table 4、
43 点、68–640 GHz）に、黒体＋ΔT＋μ＋y＋銀河モデルのテンプレートを
重み付き最小二乗で当てた自前の再測定（χ²/dof = 1.12）。

- **μ = (−3.2 ± 6.6)×10⁻⁵**（ゼロと整合）、y = (+2.5 ± 7.0)×10⁻⁶、
  T = 2.7250 K（統計のみ）
- 公表値（Fixsen 95% 上限 |μ| < 9×10⁻⁵、y < 1.5×10⁻⁵）と同桁・整合。
  プロの答えを見ずに、公開表と理論テンプレートだけで同じ場所に着いた
- 熱の予算への換算: μ期（z ≈ 5万–200万）に注入できた熱は背景放射
  エネルギーの **≲ 1.2×10⁻⁴**（2σ）。分解イベントがゼロと示された
  わけではなく、総量に自前の上限が付いた
- 窓の外: z ≳ 2×10⁶ は光子の数を変える反応が熱を黒体に溶かし直すため
  光の帳簿に残らない。その時代の記録係は軽元素比と、物そのもの
  （生き残った BH と合体の重力波）に移る

## 段階6: κ の重ね合わせ — 育った構造の総質量

`kappa_stack.py`。Planck PR3 のレンズ収束 κ（COM_Lensing_4096_R3.00、
球面調和係数として配布される MV 推定値を平均場差し引き・l≤1024 で
地図化、C_l 照合で検証済み）× 同じボイド 441 個。ISW が「変化率」なら
κ は「晴れた後の全履歴の積分」である。

- **補償開口 κ: −3.6×10⁻⁵ ± 4.4×10⁻⁴（−0.08σ）— null**、2σ ≲ 9.1×10⁻⁴
- 理論予言（著者の実測銀河プロファイル: 中心は平均の 0.7%、壁 1.55 倍
  @1.07 R_v をバイアス b=1.0/1.45 で物質に換算）: 補償 −2.5/−1.7×10⁻⁴。
  予言は実測の 0.3–0.5σ 内で、感度は約2倍（個数で約40–50倍、約2万個）
  足りない。z の高いボイドは幾何学因子で 1 個あたりの κ も大きい
- 正直な注意: ランダム平均を引いた素のプロファイルは全半径で
  −0.002～−0.003 の平らな偏り（最大 ~3σ/ビン）に見えるが、予言の
  約10倍で半径減衰がない — レンズ信号ではあり得ない形であり、
  フットプリント（SDSS 実測域）とランダム描画域（外接矩形）の間の
  大スケール κ モード差と同定した。結論はこの偏りを消す補償開口に
  基づく。見かけの 3σ を検出と呼ばないことも本検証の作法である

## 段階7: 晴れた後 → 初期銀河（2つの帳簿）

`cosmic_dawn_ledger.py`。この時代は2冊の独立した帳簿で読める。

**帳簿A（光子側）**: 再イオン化の光学的厚さ τ。Planck 実測 0.054 ± 0.007 を
「いつから完全電離か」の換算表（自前積分）で読み替える。

- 瞬時再イオン化なら **z_re = 7.4（±1σ: 6.7–8.1）**、Planck の中点 7.7 と整合
- z=10–20 の完全電離は Δτ = 0.143（実測全体の約 2.6 倍）にもなる。
  その時代の平均電離割合は **x_e ≲ 0.08（2σ）** — 初期銀河の時代は
  電子柱の主役にはなれなかった

**帳簿B（構造側）**: Press–Schechter 崩壊割合（Eisenstein–Hu 転送関数、
σ8 規格化、原子冷却閾値）と星の電離光子予算。

- f_coll: z=20 で 10⁻⁶、z=15 で 10⁻⁴、z=10 で 6×10⁻³、z=6 で 6.5×10⁻²
- 光子予算（中央の括り f_*=0.1, f_esc=0.1, N_*=4000）が
  1 本/バリオンに達するのは **z ≈ 7.7** — 帳簿A の中点と、
  合わせ込みなしで一致。再結合込みの完了（3 本）は z ≈ 5.7 で、
  Gunn–Peterson 吸収で知られる完了時期（z ≈ 5.3–6）とも整合
- 逆拘束: 悲観の括り（f_*×f_esc = 0.0025）では完了の事実と矛盾し
  排除される。積は ~0.01 級以上が必要
- JWST の z~10 銀河（ρ_* ~ 10^5.5–6.5 M☉/Mpc³）は崩壊バリオンの
  0.8–8% の効率で予算内（この閾値で数える限り）

## 再現方法

依存: numpy / scipy / matplotlib / astropy / healpy（ISW・κ のみ）。

- 軽い段階（1, 2, 3, 5, 7）は `code/` のスクリプトをそのまま実行すれば
  `results/numbers/` の JSON と同等の値が得られる（出力はスクリプトの
  隣に書かれる）。
- ボイドカタログは `data/` に同梱（VAST/VIDE、Pan et al. 2012 /
  Sutter et al. 2012 の公開カタログ `V2_VIDE-nsa_v1_0_1_zobovoids.dat`）。
- FIRAS スペクトルは `data/firas_spectrum.csv` に同梱（原典は NASA LAMBDA の
  `firas_monopole_spec_v1.txt`、Fixsen et al. 1996 Table 4）。
- 大きな地図2点は同梱していない。取得先（いずれも NASA IRSA の
  Planck release_3）:
  - 温度: `COM_CMB_IQU-smica_2048_R3.00_full.fits`（約 2.0 GB）を
    `data/planck_smica_2048.fits` として置く
  - レンズ: `COM_Lensing_4096_R3.00.tgz`（約 690 MB）。中の
    `MV/dat_klm.fits` から `MV/mf_klm.fits`（平均場）を引き、
    l ≤ 1024 に切って Nside 512 に合成したものを
    `data/planck_kappa_mv_512.fits` として置き、
    `kappa_stack.py data/planck_kappa_mv_512.fits` の形で渡す

## 限界（正直な棚卸し）

- スタック2件は Planck 共通マスクを使わず |b| カットで代替している。
  κ のランダム描画はフットプリントの厳密な再現ではなく外接矩形であり、
  補償開口でその影響を緩和している
- κ の理論側は球対称・区分線形プロファイルという単純化で、バイアスの
  括り（1.0/1.45）が予言の幅を支配する
- 段階7 の τ は Planck の公表フィット値を入力に使った（低 l 偏光の
  生データからの再測定ではない）。崩壊割合は Press–Schechter で、
  Sheth–Tormen より高 z の尾は控えめ。f_* と f_esc は z 一定の括り
- PBH の推定は玩具レベルの存在量モデルであり、個別天体の同定ではない。
  段階3 は設計のみで、観測の実行結果ではない
