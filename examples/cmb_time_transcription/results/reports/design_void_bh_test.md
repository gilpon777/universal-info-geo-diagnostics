# 設計書: ボイド銀河の中心 BH 過重テスト v0.1

問い: 銀河中心のブラックホールは「星より先に用意された種」か、
「星と一緒に後から育った」か。ボイド銀河は宇宙で一番成長が遅れた
環境なので、この2つはボイドで最も大きく予測が割れる。

検出力計算: `void_bh_power.py` / `void_bh_power_numbers.json`。

## 1. 仮説と予測（符号と大きさ）

観測量 Δ = log10(M_BH) − 局所 M_BH–M* 関係の予測値（dex）。
比べるのは Δ_void − Δ_field（恒星質量でマッチした2群の平均差）。

| 仮説 | 予測 Δ_void − Δ_field | 根拠の置き方 |
|---|---|---|
| H_heavy: 重い種が先（PBH / 直接崩壊種）+ ボイドでは宿主が育たない | **+0.5 〜 +1.5** | JWST 高z の過重個体は 1〜2 dex、スタック中央値は ≤1 dex。z=0 の「一番育たなかった環境」にその化石が残るなら、この帯 |
| H_std: 標準モデル（シミュレーションのベースライン） | **+0.1 〜 +0.2** | EAGLE 解析（Rouse+ 2026）: 同じ M* でボイドの SMBH は「わずかに重い」、AGN 割合もボイドが最高（12% vs 密な環境 6.7%）。ゼロではない |
| H_light: 軽い種がボイドで飢える | **−0.3 〜 −1.0** | 種は小さいまま、フィールド側だけ合体と降着で育つ |

設計の物差し: H_heavy の下限（+0.5）と H_std の上限（+0.2）を
分ける **δ = 0.3 dex** を最小の分離目標とする。

## 2. 観測量
- 主: Δ（まず AGN のビリアル質量、次段で力学質量）。
- 副1: 占有率 × 平均降着率 — eROSITA スタックで非 AGN のボイド矮小銀河
  まで含めた積分チャンネル（「像で負けるなら積分で数える」側）。
- 副2: エディントン比の分布。既存の観測（Constantin+ 2008）では
  ボイド AGN の割合は壁と同程度で、降着率は同等か低め — 「大きくて
  飢えている」絵とは矛盾しないが、結論には使わない（ヒント止まり）。
- 補助軸: M* だけでなく力学質量/速度分散でも Δ を取る。M_BH–M_dyn が
  より基本的な関係だという指摘（thesan-zoom）があり、M* だけだと
  環境差（同じ M* でもハロー質量が違う）を取り違える。

## 3. データの現状（2026-11-12 時点の確認）
- SDSS のボイドカタログ × AGN サンプルは既にある: DR12 の
  1,228 ボイド・メンバー銀河 166,067・ボイド内 AGN 3,100
  （z=0.2〜0.7、明るい側; ApJ 2021）。内側ボイドの AGN 割合は
  4.9±0.7% vs 外側 3.1±0.1%（z>0.42）。
  → Stage 1 の Δ 測定は既存データで今日から可能。
- 力学質量が測れたボイド銀河の中心 BH は、知られている限り
  ほんの一握り。決定的な低質量側の検定は追観測待ち（Stage 3）。
- JWST の過重 BH は高z の話で、選択バイアスの寄与は最大 ~0.2 dex
  （Pacucci+ 2023）。z=0 ボイドへの外挿は仮説側の置き方であり、
  証拠としては使わない。

## 4. 事前登録ルール（結果を見てから動かさない）
- ボイド所属の定義を先に固定（例: r < 0.6 R_eff を内側とする）。
- フィールド対照は同一サーベイ・同一時期から、M* ±0.1 dex でマッチ。
- 質量推定法（ビリアル較正の版まで）を開く前に固定。
- Δ の推定は上限値込みの censored MLE（検出だけの平均は偏る）。
- カットは検証サンプル（既知の力学質量がある銀河）で先に固定する。

## 5. 交絡（先に潰しておくもの）
1. **標準モデル自体が少しプラス**: H_std が +0.1〜0.2 を出すので、
   「重い」だけでは種先行の証拠にならない。δ=0.3 の分離が要る理由。
2. **選択バイアス（Lauer 型）**: AGN で選んだサンプルは過重側に
   寄る（≤0.2 dex）。光度・エディントン比でもマッチし、非 AGN の
   スタック（副1）で裏を取る。
3. **M* の系統差**: ボイド銀河は青く星形成が活発で、M*/L の
   仮定がフィールドとずれる。測光バンドと推定法を両群で統一。
4. **ハロー質量の違い**: 同じ M* でもボイド側はハローが重め
   （EAGLE）。§2 の補助軸で吸収する。

## 6. 検出力（σ_tot = 0.5 dex/天体、両側5%、検出力80%）
誤差予算: 固有散乱 0.35 dex ⊕ 測定 0.35 dex（ビリアル 0.4 系統 /
力学 0.2 の混在）→ 0.49 ≒ 0.5 dex。

| 分離 δ | 必要 n（1群、上限値なし・解析式） | MC（上限値50%） |
|---|---|---|
| 1.0 dex | 4 | 10 |
| 0.5 dex | 16 | 30 |
| **0.3 dex（設計目標）** | **44** | **90** |
| 0.2 dex | 99 | — |

読み: Stage 1（既存 AGN サンプル、n は数百規模）では統計的には
δ=0.2 でも届くが、本当の壁はビリアル質量の系統誤差（0.4 dex）で、
群間比較では共通成分が相殺される分だけ効く。δ=0.3 の決定打は
Stage 3 の力学質量 45〜90 個（上限値込みなら 90）が物差し。

## 7. 段階計画
- Stage 0: 既存のボイド銀河 BH 質量の総ざらい（文献+カタログ）。
- Stage 1: 既存データで Δ を測る（SDSS ボイド AGN のビリアル質量、
  マッチしたフィールド対照、上限値込み推定）。結果は系統誤差の
  括り付きで報告。
- Stage 2: 積分チャンネル — eROSITA スタックでボイド矮小銀河の
  占有率×降着率に上限/測定を付ける。
- Stage 3: 低質量・内側ボイド銀河への力学質量の追観測（45〜90 個）。
  ここが δ=0.3 分離の本番。

## 8. 判定基準（先に決めておく）
- Δ̂ ≥ +0.5（系統括りを引いても +0.3 を超える）: H_heavy 支持、
  H_std は棄却方向。
- Δ̂ ≈ +0.1〜0.2: 標準モデルと区別つかず。結論は積分チャンネル
  （Stage 2）と Stage 3 に持ち越し。この場合も「上限」として報告。
- Δ̂ ≤ 0: 重い種先行は棄却方向、H_light 側に重み。
いずれの場合も null は不存在の証明ではなく、測れた感度での上限
として数値付きで残す（このプロジェクトの共通文法）。

## 9. 追補（v0.2、2026-11-12）: 暴走合体シナリオと「裾」の検定軸
`pbh_void_report2.md` の改善計算を受けた追補。PBH が集団で生まれ
集団ごとに重い残骸（100〜3000 M☉）が残るモデルでは、ボイド銀河の
中心占有は斑になる: 残骸を拾えた銀河だけが重い。この場合 Δ 分布は
平均のずれに加えて **裾が太る（二峰性）** ことが署名になる。
- 副次観測量を追加する: P(Δ > 1) の群間差（裾の過剰）。
- 試算（ボイド側の3割が Δ~N(1.2, 0.4) の重い集団、残りと
  フィールドは N(0.15, 0.5)）: P(Δ>1) は 0.239 vs 0.045、
  必要な n は 1群 51（平均分離の 44〜90 と同じ桁）。
- 判定基準への追加: 平均が +0.1〜0.2 に留まっても、裾の過剰が
  有意なら「斑のある重い占有」として暴走モデル側に重みを置く。
  逆に裾まで一致すれば、重い種の斑モデルも上限で縛れる。
