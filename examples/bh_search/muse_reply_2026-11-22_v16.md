## 1. GW — 3分布を分離した。因果の表現は規約 §12 に分けて記録した

重心で分離すると: SNR 重み w(f) 単独 = 51.25 Hz、射影残差 |r(f)|² 単独 = 344–370 Hz、実効寄与 C(f) = 54–78 Hz。実効寄与が高周波側へ移るのは残差自体が高周波側に分布するためで、重みがそれを引き戻した結果が C(f) である、と切り分けられた。「F の振動が高周波ほど速い」という因果の言明は F の解析形に根拠を置き、C(f) はその測定上の対応物として扱う、という書き分けを参照規約 §12 に記録した。複数テンプレート・複数ノイズ実現は次期実験の設計項目のまま（実行は中谷さんのゴーサイン待ち）。

## 2. M1 反転境界 — lo == crit の扱いを修正し、境界テストを追加した

指摘は正しい。M1 = crit でちょうど M2 = 3 になるため、lo == crit は「全域で超」ではない。条件を `lo > crit` に変更し、提案の境界テスト T1–T6 をスクリプトに組み込んだ（全て合格）。現在の13件の分類は変わらないことを修正前後で確認した。

## 3. 減光の最大値規則 — 2段階方式を採用する（規則の確定は中谷さんの判断）

分類の提案は、現在の実務（GSP の直接推定 / TGE a0 の代理量としての天井 / 連星モデル MSC を分けて保持し、a0 には換算係数 k = 0.8–1.1 の感度を付ける）を形式化するもので、その方向で採用する。正確に区別すると:

- 直接推定（GSP-Phot A_G、DR4 の対応量）: 比較可能な推定上限として扱う。
- 代理量（TGE a0）: A_G そのものとは同一視せず、換算の感度範囲を含めた独立の保守側天井として扱う（従来どおり）。
- 誤差の扱い: TGE 側には a0_uncertainty（トレーサー平均の標準誤差）があるが、GSP 側の推定誤差は現在の取得データに含まれていない。DR4 当日の取得項目に GSP の誤差列を加える。

この形で、v11 §3.1 の量ごとの規則とあわせて「入力版の規則パッケージ」として中谷さんの判断を待つ。採用されれば統合規則への追記（固定後の追記）として実施する。

## 4. 保留帯 — 用語は「ガードバンド」に改める

指摘のとおり、状態を保持しないのでヒステリシスではない。規則は「flip_margin が 1.2–1.8 等の範囲（閾値 1.5 ± 0.3）に入れば自動的に判定保留とする判定保留帯（ガードバンド）」と定義し、1.8 を超えても閾値との差が小さい場合は警告を残す。DR4 公開前に、当日の入力チェックリストへ組み込む（上記パッケージと一体で判断を待つ）。

## 5. K の共分散 C — データ構造を実データで確認し、正則化まで事前登録した

対照 A v2 の保存データは、まさに提案の構造になっている: **200 実現 × 441 ボイド**（stack_comp / stack_prof）。したがって標本共分散の階数は最大 199 で、正則化は必須である。この点を仕様書の追補 3 として記録した:

- 正則化は C_reg = (1−ρ)C + ρ·diag(C)、ρ は Ledoit–Wolf 型推定（方法を事前に固定、値はデータから計算）。対角のみの C での σ_Â を対照として併記し、ブラケットで報告する。
- C の推定誤差は σ_Â の不確かさとして別記する（実現の分割再推定で評価）。
- N・対照の版・ρ の値は、K′ の数値を見る前に記録する。
