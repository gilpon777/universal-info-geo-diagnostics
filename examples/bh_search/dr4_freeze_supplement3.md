作成: 2026-11-15（Muse）/ 対象: `dr4_freeze.md`（凍結本体）、`dr4_freeze_supplement.md`（追記 1）、`dr4_freeze_supplement2.md`（追記 2）

## 1. 判定の2軸化（Claude v5 §3.1・§7A を採用）

判定は次の2軸を別々に評価する。

- **質量軸**（f 区間と M1 範囲から決まる）: 支持 / 非支持 / 保留。
  - 支持: M2 下限（M1 下端で評価）> 3 M☉
  - 非支持: M2 上限（M1 上端で評価）< 3 M☉
  - 保留: M2 区間が 3 M☉ をまたぐ、または M2 の上限が原理的に定まらない（§3）
- **測光軸**（BH 候補の認定にのみ必要）: 排除済み / 排除できない。
  - 排除済み: 追記 2 §1 の式（§2 の A_G,max を用いる）を満たす
  - 排除できない: 式を満たさない、または系の M_G,0 < 2

最終ラベル: 質量軸が「支持」かつ測光軸が「排除済み」のときだけ「BH 候補」。質量軸が「支持」で測光軸が「排除できない」なら「判定不能（測光）」。**質量軸が「非支持」なら、測光軸に関係なく「BH非支持」**。質量軸が「保留」なら「判定保留」。

これにより #13 のラベルを、追記 2 §6 の「判定不能（測光）」から **「BH非支持」（測光軸: 排除できない、を付記）** に変更する。#13 は f から M2 上限が 1.15（M1=5 でも 1.44）しかなく、質量軸は非支持である。M_G<2 の条文はもともと「候補ラベルを付けない」ためのもので、非支持の判定とは無関係だった（軸の混線。原因は Claude v3 の提案文面にあり、v5 で Claude 自身が訂正した）。

## 2. A_G,max の実装と記述の訂正（ChatGPT 第2回 §2.1、Claude v5 §3.4）

- 追記 2 §1 の式は正しかったが、v1 のルールチェックでは A_G,max を差し引いておらず、13件の A_G も未取得だった。本書で実装を完了する。
- 記述の訂正: 係数 2.74 は Wang & Chen 2019 の R_V（= A_V/E(B−V)）であり、A_G の係数ではない。A_G は色と消光量に依存し A_G ≤ A_V であるため、**天井は A_V で取る**（安全側）。実務の A_G,max は次の最大値とする:
  **A_G,max = max(Gaia GSP-Phot の A_G, Gaia TGE マップの a0（全視線・A_V 天井として）)**
  GSP-Phot が無い天体は TGE のみで決める。SFD の E(B−V) を使う場合は A_V = 2.74 × E(B−V) を天井とする。
- 実測値（2026-11-15、Gaia TAP 経由で取得、`gaia_extinction_13.json`）: 13件の A_G,max は 0.93–2.67。BH1 は GSP-Phot 0.5575、TGE a0 1.4387、採用 A_G,max = 1.4387。
- **BH1 の測光余裕は 8.09 等 → 6.65 等**（A_G,max 控除後）。依然として要求（≥1 等）を大きく上回り、測光軸は「排除済み」、「BH 候補」は不変。
- 他の軌道解天体の余裕は負値（#4: −5.47、#7: −4.42、#8: −2.90、#9: −5.25、#10: −4.02、#12: −2.06、#13: −8.34）。これは「M2 下限相当の主系列星より系が明るい（主星の光が支配的）」という意味で、質量軸が非支持の天体では最終ラベルに影響しない。

## 3. #10 のラベル変更（ChatGPT 第2回 §2.2 を採用）

- #10 は分光質量関数 f_rv = M2³ sin³i /(M1+M2)² を使う。軌道傾斜角 i が未知のため、**M2 には上限が存在しない**（i→0 で M2 はいくらでも大きくなりうる）。v1 評価表の M2 ≈ 0.03–0.07 M☉ は sin i = 1 の最小質量であり、上限ではない。
- よって #10 のラベルを「BH非支持」から **「判定保留（軌道傾斜角未確定）」** に変更する。傾斜角が独立の観測から得られた場合に限り、質量上限を再評価する。
- 注記: Claude v5 §3.3 の感度リストにある「#10: 0.18」は sin i = 1 を仮定した最小質量側の値であり、上限ではない。この点は ChatGPT の指摘が正しく、§5 の M1 感度でも #10 は「M1 に依らず常に保留」とする。

## 4. 光心軌道の前提（ChatGPT 第2回 §2.3）

- Gaia NSS の位置天文軌道は**光心**の軌道である。a_phot = a_1 が成り立つのは伴星の光度比がほぼ 0（暗い伴星）の場合に限る。したがって f_astrom は、暗い伴星の仮定の下でのみ主星の質量関数と等しく、それ以外では「見かけの」質量関数である。
- §1–§2 の測光排除は、この光度比を測光的に縛る手続きでもある。測光軸が「排除できない」天体については、f_astrom を見かけの値として扱い、候補ラベルを付けない（§1 の2軸規則と整合）。
- DR4 での確認事項として記録する: 対象ごとに、NSS 解が光心軌道として解釈すべきものか、伴星の光度比の上限を測光排除以外（分光・画像）で縛れるか。

## 5. M1 範囲の和集合と感度列（Claude v5 §3.2・§3.3）

- 主系列仮定が不適な天体の M1 範囲は、計算範囲と [1.0, 3.0] の**和集合**を採る（#13 は [1.0, 3.45]）。
- 感度列を評価表に追加した: **M1 を [0.3, 5] に振っても、質量軸の判定が変わる天体は 13 件中ゼロ**（ルールチェック v2 で確認。Claude v5 §3.3 の独立計算と一致）。
- 色のずれによる主系列仮定の旗は二段とする: 0.15–0.30 を「弱い注意」、0.30 超を「要注意」（Claude v5 §7D）。
