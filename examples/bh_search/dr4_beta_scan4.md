## 1. 補間方式の比較

### 1.1 方式の定義と、用語の訂正

scan3 までの現行補間は `np.interp(log10(M), log10(ANCH_M), ANCH_G)`、すなわち **M_G を log M に対して線形補間する半対数方式**である。ChatGPT 第4回査読はこれを「対数–対数補間」と表現したが、実態はこの半対数であることをここに正確に記録する。

比較した3方式（アンカー集合は scan3 と同一の22点）:

- **方式A（現行）**: M_G を log10(M) に対して線形補間。
- **方式B（光度基準）**: アンカーを相対光度 L ∝ 10^(−0.4·M_G) に変換し、log L を log M に対して線形補間（区間ごとの冪乗則）してから M_G に戻す。
- **方式C（参考）**: L を log M に対して線形補間してから M_G に戻す。

### 1.2 方式A と方式B は数学的に同一である

log10 L = −0.4·M_G という関係のため、「log L を log M で線形補間して M_G に戻す」操作は「M_G を log M で線形補間する」操作と恒等的に等しい。実際、今回の全対象・全許容幅で方式A と方式B の解（M2 の範囲全体）は完全一致した。したがって ChatGPT の懸念した「絶対等級そのものを対数変換して補間する」問題は、方式B では発生しない代わりに、方式B は現行方式の言い換えにすぎない。真に異なる補間は方式C（光度そのものを線形補間）であり、そちらで頑健性を確認した。

## 4. 減光のモデル別ブラケット（要約）

詳細は `gaia_extinction_bracket_13.json`。13件について GSP-Phot A_G（単独星モデル）・MSC A_G（連星モデル）・TGE a0 を並べ、現行 A_G,max = max(GSP, TGE) と変種 A_G,max' = max(MSC, TGE) を比較した。ChatGPT の提案どおり、GSP-Phot と MSC はどちらが正しいと決めず、モデル間系統差として両端を保持する形にした。

- **A_G,max が変わるのは #12 のみ**: 現行 2.6713（GSP-Phot が支配的）→ 変種 1.4664（TGE が支配的）。他の12件は両変種とも TGE a0 が支配的で不変。
- **BH1 の測光余裕は不変**: 両変種とも A_G,max = 1.4387（TGE）で、余裕 6.65 等のまま。
- **#12 の測光余裕は −2.06 → −0.86 等**に変わるが、要求（≥1 等）には届かず測光軸は「排除できない」のまま。#12 の最終ラベル「判定保留」は質量軸（f 区間 [0.078, 90.3]）で決まっており不変。
- **M1 範囲は全件不変**: rule_check_v2 の M1 範囲は A_G,max ではなく GSP-Phot の A_G そのもので補正して構築されているため、この変種では定義上変わらない。参考（定義外）: #12 の M1 上端の補正に MSC（0.0018）を使えば上端は 1.14 → 0.78 になるが、#12 のラベルは質量軸で保留が確定しており影響しない。
- **結論: 減光ブラケットによるラベル変更はなし。** モデル間系統差が実際に効くのは #12 の減光だけであり、その影響範囲（測光余裕の値そのもの）もここに記録した。
