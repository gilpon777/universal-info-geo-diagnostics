## 注記

- 測光余裕が負の天体は、M2 下限に相当する主系列星より系が明るい（主星自体の光が支配的）ため、その質量の下限側では測光排除が効かないことを示す。質量軸が非支持の天体では最終ラベルに影響しない（測光軸は候補判定にのみ必要）。
- **減光の 3 つの量の区別**: 本表で使う減光は性質の異なる 3 量であり、混同しないこと。(i) **GSP-Phot の A_G** は単独星モデルによる当該星の減光推定（16/84 パーセンタイル幅は小さいがモデル仮定に依存）。(ii) **TGE の a0** は視線方向の全銀河減光の上限（A_V の天井）で、当該星の減光そのものではない。(iii) **MSC の A_G**（`gaiadr3.astrophysical_parameters` の ag_msc）は連星モデルによる推定で、`gaia_extinction_bracket_13.json` に全 13 件分を保持する。#12 では (i) 2.6713 / (ii) 1.4664 / (iii) 0.0018 と大きく食い違う。用途による使い分け: 測光排除の天井 A_G,max は (i) と (ii) の max（保守側、Claude v5 §7E の規約）、M1 推定では (i) が (ii) を超える場合は (i) を使わず (ii) を用いる（追記 7 §2 の条項。該当は #12 のみ）。**#12 の最終ラベルは減光のモデル差では覆らない**: 質量軸は凍結 f 区間 [0.078, 90.3] が M1 範囲の全域で 3 M☉ をまたぐため「保留」で決まっており、測光軸は現行規約（余裕 −4.01）でも変種（−2.81）でも「排除できない」のままだからである。
- f 区間の出典: #6 と #12 は凍結・全共分散 MC（追記 3 §6）、他は独立周辺 MC。#12 の独立周辺 MC は f [0.2039, 82.7]、M2 [0.632, 84.9] で、v2 では主表の主値だったものを v3 で本注記への併記に降格した（どちらの区間でも質量軸は保留で不変）。#12 の測光余裕（v4）は凍結側の M2 下限 0.39 で計算しており、独立周辺の下限 0.632 は使っていない。
- #12 の減光の旗: GSP-Phot の A_G (2.6713) が TGE a0 (1.4664) を上回る。A_G ≤ A_V で、TGE a0 は視線方向の全銀河減光の天井（A_V として）であるため、この GSP-Phot 値は物理的にあり得ない。M1 推定には使用せず A_G = TGE a0 = 1.4664 を用いる（M1 範囲: 旧 [0.48, 1.14] → 新 [0.48, 0.95]。下端は A_G を含まない式のため不変）。新 M1 範囲で凍結 f から M2 端点を再計算すると [0.39, 92.2] で、主表の凍結値 [0.39, 92.5] と同様に 3 M☉ をまたぎ、質量軸「保留」は不変。測光軸の A_G,max（天井規約）は別用途のため変更しない（2.6713（GSP））。
- M1 範囲は主系列アンカーによる暫定推定で、減光・金属量・進化・未分解連星の系統は M1 感度列で吸収する設計（感度列が全件「不変」であることが根拠）。
- 「BH非支持」は暗い伴星の仮定（光心軌道の前提）のもとでの判定である（追記 7 §3）。明るい伴星の場合の検証は β走査（追記 4〜6、モデル A の範囲）と、今後の 4 モデル評価の対象である。
- 光心軌道の問題（ChatGPT 第2回 §2.3）: 測光排除は「伴星が暗い」仮定の確認を兼ねるが、光度比を含む光心モデルの導入自体は本表の範囲外（別課題として残す）。
