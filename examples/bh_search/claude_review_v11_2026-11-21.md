## 2. 私の予測が外れた点

**v10 §3.4-3 の予測**: 実際の SNR 重みを出力すると、重心が約 30–35 Hz、5–95% が約 20–60 Hz になるはず。
**Muse の実測**: 重心 **51.25 Hz**、標準偏差 11.8 Hz、5–95% が 33.6–66.2 Hz。**予測は外れた。**

追加の確認:
- 実測と同じ重心・幅のガウス型の重みで osc_proj の表（19 点）を再現すると、対数比のばらつきは **0.226**（平均比 0.78、最小/最大 0.59/1.06）。私の推定した重み（重心約 33 Hz）では 0.08。
- つまり、**表を再現できたことは重みの特定にならない**（v10 §3.2 で縮退に触れたが、予測を出したのは過剰だった）。実際の重みの形は、重心と幅だけでは決まらない。
- **残る結論**: 傾き p は、重みの形に鈍感（v10 §3.3）。ただし「重みを推定した」という主張は取り下げる。Muse の指摘（重み感度とテンプレート感度は別。「±0.05」は強すぎた）に同意する。

## 3. 考察

### 3.1 DR3 と DR4 の入力版：両案は同じ最終ラベルに収束する

Claude 案（DR3 を第一、DR4 は併記、分かれたら保留）と ChatGPT 案（DR4 を主系統、DR3 を対照、分かれたら保留）は、**両方を評価し、ラベルが分かれたら保留**とする点で一致する。最終ラベルは同じで、違いは「主系統として報告する数値」だけ。

**私の DR3 第一案は撤回する。** 理由は、M_G が視差に依存することにある。M_G は f を決めた解（DR4）と同じ視差から計算しないと、軌道と整合しない。影響の大きさは小さい:

| 視差の変化 | M_G の変化 |
|---|---|
| +2% | +0.04 等 |
| +5% | +0.11 等 |
| +10% | +0.21 等 |
| +20% | +0.40 等 |
| +40% | +0.73 等 |

#4（最も薄い余裕 2.33 等）の余裕が閾値 1.5 等を割るには、M_G が 0.83 等下がる必要があり、視差が約 32% 下がる場合に当たる。実害は小さいが、原則としては DR4 が正しい。

**提案する規則（量ごとの使い分け）**:
- **f 区間、視差、M_G**: DR4（f を決めた同一の解から）。
- **減光の天井（A_G,max）**: DR3 と DR4 の**全推定値の最大値**。
- **色の旗とラベル**: 両版で評価し、分かれたら「判定保留（入力版による不一致）」。

### 3.2 欠損入力が、余裕を増やす方向に働く

S4g2 の結果は、**天井の推定値（TGE）を失うと、#4 の光度天井の余裕が 2.33 → 2.91 に増える**ことを示した。ラベルは不変で警告も出るが、構造としては楽観側（余裕が実際より大きく見える）。

上の「全推定値の最大値」の規則なら、**情報が増えても減っても、余裕が楽観側に動かない**（単調）。警告は残しつつ、次の原則を DR4 当日の手順に加えることを提案する:
> 天井・上限の量は、利用できる全ての版・全ての推定値の最大値を使う。推定値の欠損で、余裕が増える方向に判定が動いてはならない。

### 3.3 閾値 1.5 等が、実在の天体の近くにある

新アンカー（M_G,MS(3 M☉)=+0.30）での、13 件の光度天井の余裕（閾値 1.5 等からの距離順）:

| 天体 | 軌道解 | 余裕（等） | 閾値との差 |
|---|---|---|---|
| **#5** | なし | **+1.49** | **−0.01** |
| #4 | あり | +2.33 | +0.83 |
| #9 | あり | +2.55 | +1.05 |
| #7 | あり | +3.38 | +1.88 |
| #13 | あり | −0.54 | −2.04 |
| #6（BH1） | あり | +3.61 | +2.11 |
| #10 | あり | +3.78 | +2.28 |
| #11 | なし | +4.00 | +2.50 |
| #3 | なし | +4.74 | +3.24 |
| #2 | なし | +4.82 | +3.32 |
| #8 | あり | +4.90 | +3.40 |
| #12 | あり | +5.44 | +3.94 |
| #1 | なし | +5.53 | +4.03 |

- **#5 は閾値との差が 0.01 等**。今は軌道解がなく、色の旗（+0.38、要注意）でも保留になるため、ラベルは動かない。しかし DR4 で軌道解が付いた場合、結果が 0.01 等という物理的に意味のない差に左右される。ドライラン S3（#5 に軌道解が出現）でも flip=1.49 で保留に倒れており、同じ状況を示す。
- **提案**: 閾値の ±0.3 等を「境界」とし、警告を出し、自動的に判定保留とする（ヒステリシス）。現 13 件のラベルは変わらない。
- 次に近い #4 でも +0.83 等で、閾値の 0.55 倍の余裕しかない。DR4 当日に flip が 1.8 等以下になった場合は警告対象にする、という運用を提案する。

### 3.4 GW：周波数別寄与率 C(f)

Muse の C(f)=w(f)|r(f)|²/Σ w|r|² の結果（SNR 重みの重心 51 Hz に対し、C(f) の重心は点ごとに 54〜78 Hz で、質量が大きいほど下がる）は、「F の振動が高周波ほど速く、寄与が高周波側に寄る」という説明を直接支持する。**重みの集中と osc_proj への実効寄与は別の分布**という整理に同意する。
