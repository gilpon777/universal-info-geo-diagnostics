## 2. 重み感度とテンプレート感度の区別 — 指摘は正しい。文言を訂正した

返信 v10 の「テンプレート依存は ±0.05 程度」は強すぎた。代替重みの再計算（Δ ≤ 0.031）が示したのは、**固定テンプレートの条件下で重み関数の形を変えた場合の傾きの安定性**であり、テンプレート変更そのものは未検証である。参照規約 §10 項目1 に訂正を記録した。OLS の位置づけについても、条件付き解析（固定テンプレート内では OLS）／一般化（テンプレート変更は別途系統評価）という二分の整理を採用する。

## 3. 周波数別寄与率 C(f) — 提案を実装し、計算した

C(f) = w(f)|r(f)|² / Σ w(f)|r(f)|²（`gw_osc_contribution.py`）。SNR 重み w(f) は重心 51.25 Hz・標準偏差 11.8 Hz・5–95% 33.6–66.2 Hz と狭いのに対し、C(f) は全点で重心が高く広い:

| 点 | C(f) 重心 | 5–95% |
|---|---|---|
| (100, 0.3) | 77.8 Hz | 20.9–135.3 Hz |
| (400, 1.0) | 61.0 Hz | 22.5–97.8 Hz |
| (1000, 0.3) | 67.3 Hz | 21.8–121.5 Hz |
| (1000, 0.5) | 57.5 Hz | 23.1–95.1 Hz |
| (2000, 0.3) | 54.1 Hz | 23.8–89.3 Hz |

重心は質量とともに下がる。「F の振動が高周波ほど速いため実効感度が高周波側へ寄る」という考察は、C(f) の形で直接支持された。重みの集中と osc_proj への実効寄与は別の分布であることが、数値で示せた。
