## 0. v3 からの変更点

1. **測光余裕の列を 2 つに分けた。** v3 の「測光余裕」は、M2 下限の主系列星との差だった。目的が違う 2 つの量を混ぜていたため、
   - **余裕（候補側）** = (M_G − A_G,max) − M_G,MS(M2 下限)。BH 候補を認めるときに使う（追記 2 §1）。
   - **余裕（光度天井）** = (M_G − A_G,max) − M_G,MS(3 M☉)。非支持を認めるときに使う（本案の新規。§2）。
2. **候補側の余裕の数値を訂正した。** v3 の値は、M2 下限が 0.6 M☉ 未満の天体で、古いアンカー（0.6 M☉ より下を M_G=8.1 に固定）の影響が残っていた（#4: −5.47、#7: −4.42、#8: −2.90、#9: −5.25、#13: −8.34）。低質量アンカーを追加した値に直した。**ラベルへの影響はない**（どれも負で、候補側の余裕は非支持の天体には使わない）。
3. **#12 の余裕の数値を訂正した。** v3 の −2.06 は、独立周辺 MC の M2 下限（0.632）で計算されていた。凍結値（全共分散 MC）の M2 下限 0.39 で計算すると −4.02。
4. **最終ラベルを、追記 5・6 の変更に合わせた。** v3 は #8・#13 を「BH非支持」のままにしていた（追記 5 で #13、追記 6 で #8 を判定保留に変更済み）。#10（傾斜角未確定）、#13（M1 範囲の和集合 [1.0, 3.45]）、#12（M1 範囲 [0.48, 0.95]、追記 7）も反映した。

## 2. 光度天井の余裕（本案の新規の列）

- **定義**: 余裕 = (M_G − A_G,max) − M_G,MS(3 M☉)。M_G,MS(3 M☉) = −0.1（主系列アンカー）。
- **意味**: 伴星は系全体より明るくなれない。系が M2=3 M☉ の主系列星（M_G≈−0.1）より十分に暗ければ、M2>3 の**主系列伴星**は入らない。余裕は、そのために許される系統誤差（等級）の大きさ。
- **非支持の追加条件**: 質量軸が非支持（β=0 で M2 上限<3 M☉）に加え、**余裕 ≥ 1.5 等**（アンカーの概略 ±0.5 と、未分解連星・回転・金属量への余裕 1.0）。
- **検証**: 系と同じ明るさの主系列星の質量（天井質量）は、β走査（scan3）の M2 最大値と、許容幅 ±0.1〜±1.0 の 5 天体 × 4 通りの全てで **0.03 M☉ 以内**で一致する（例: #4 の ±0.3 で 1.53 と 1.52）。

## 5. 暫定の注記

- DR3 時点のラベルは暫定。#6 と #12 の f 区間は全共分散 MC、他は独立周辺 MC（追記 3 §6）。DR4 では公表区間を第一優先（追記 1 ③）。
- 「BH非支持」は、伴星が**暗い天体**または**単一の主系列星**である場合の判定。暗い質量が明るい星と同伴する階層三重系（例: BH + 星 の内側連星が「伴星」）は、本表のモデルの外にある（詳細は統合規則 §8）。
