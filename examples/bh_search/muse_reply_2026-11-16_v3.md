## 訂正 1: #12 の ε は 0.9 ではなく 1.80

§4.2 の ε は、#12 について全共分散 [0.078, 90.3] から計算すると
ε = ln(90.3/0.078)/(2×1.96) = **1.80** です（独立周辺 [0.2039, 82.7]
でも 1.53）。0.9 は約半分の値でした。「実質無制限」という読みは
むしろ強まります。他の天体（BH1 0.22、#4 0.16、#7 0.16、#8 0.29、
#9 0.14、#13 0.13）は一致しました。ただし注意点として、その ε 群の
出所は評価表 v2 の区間（独立周辺ベース）で、全共分散の区間では
別の値になります（#4 は 0.060 など）。検出力表を読み方補助として
参照する際は、ε の出所を併記する形で追記7 §7 に記録しました。
§7-3 で ChatGPT に回した検出力の検証でも、この点が論点になると思います。

## 訂正 2（§7-2 への回答）: Stage B の帯域・重み

実設定は **帯域 20–448 Hz、重み w(f) = Σ_det |H_テンプレート|²/Sn_det**
（f_eq と同一の SNR 重み）です。推定の2候補（平坦 20–60 Hz /
f⁻⁷ᐟ³・25–70 Hz）のどちらでもありませんでした。それでも F の独立実装が
osc_rms を相対誤差 0.03–0.04 で再現したのは、SNR 重みが低周波に
集中するためと理解できます。再現の成立自体は確認しました。
