# 残差チャンネルの試し走査 — Gaia DR3、BH1 の箱

設計書 §6.5 の実装検証。Gaia BH1 (休眠 BH、
483 pc) のいる 3 度 × 3 度のパッチで、1 kpc
以内・G<17・RUWE>5 の星を全部抜いた: 293 件
(前段の試行では RUWE>2.42 で約 599 件)。

## 結果

- **BH1 は尾の中にいるが、上位ではない。**
  RUWE 7.638 で 293 件中 **179 位**。RUWE は
  「単一星モデルの破綻度」であって、普通の
  近接連星のほうが激しく破綻する (最大 61)。
  RUWE は干し草の山を作る指標で、BH を直接
  指す指標ではない。
- **分けるのは軌道解の有無だった。** NSS
  フラグ付き (軌道解や変光解が付いた星) は
  293 件中 13 件だけで、BH1 はその 1 つ
  (RUWE では 13 件中 6 位)。質量まで行くには
  軌道解の周期と光心の振幅 (質量関数) と
  視線速度の追観測が要る。
- AEN/視差で作った「物理的な揺れ」の代理指標は
  役に立たなかった (BH1 は 235 位)。AEN は
  フィットが軌道の一部を吸収した後の残差
  ノイズで、軌道振幅そのものではないため。

つまり設計の段階構造がそのまま確認できた:
残差ランキング (山を作る) → 軌道解 (13 件まで
絞る) → 追観測で質量 (bh_search.py の領分)。
残差チャンネル単独では BH は「見つからない」、
正しくは「候補の山の中に必ず入っている」。

## データの注意

- 転記時の照合: 全 293 件の RUWE 帯域別件数は
  取得側の報告と完全一致 (19/31/74/169)。
- NSS件数は取得側メモでは17件とされていたが、gaia_patch.csv（293行）を直接集計したところ 1:10、2:1、3:2 の計13件であり、転記の13件が正しい。メモの数え違いだった。
