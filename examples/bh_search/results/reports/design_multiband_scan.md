# 多バンド走査の設計 (v0.1、設計のみ・未実行)

## 目的と非目的

- 目的: 放射で光るコンパクト天体の棚卸しと、
  バンド間ベクトルによる分類の足場を作る。
- 非目的: 完全に休眠した連星 BH の発見。それは
  力学チャンネル (Gaia 位置天文学 + 視線速度、
  bh_search.py の領分) が担当する。混同しない。
- ただし §6 の幾何チャンネル (重力レンズ) は
  休眠・孤立 BH にも届く。放射ゼロでも効く唯一の
  光学的手法として、別枠で設計に含める。

## 1. バンドとカタログ

主キーは eRASS1 の X 線源リスト (パッチ内 5117 件、
明るい 58 件で型を固めてから全数へ)。

| 帯 | カタログ | 運ぶ成分 |
|---|---|---|
| γ | Fermi 4FGL-DR4 | ジェット・パルサー。PSF 0.1 度級なので「領域フラグ」としてのみ |
| 硬 X | Swift BAT 105 か月 | 硬い状態の有無 |
| X | eRASS1 (済) + hard サブカタログ | 降着の主信号、硬さ |
| UV | GALEX AIS | 白色矮星・CV の分離。銀河面は回避領域あり (§4) |
| 可視 | Gaia DR3 | 対応天体の等級・固有運動・視差。密度過大のためコーン照合専用 |
| 近赤外 | 2MASS (Ks<14 で切る) | 減光の向こうの伴星 |
| 中赤外 | AllWISE | W1-W2 色で AGN を弾く |
| 電波 | RACS (南) / NVSS (北) | ジェット。電波/X 線比は BH/NS 分離の補助 |

## 2. 照合の設計 — 偶然一致を先に数える

照合半径は各バンドの位置精度から決め、偶然一致率
P = 1 - exp(-ρ π r²) が 5% を超えない範囲に切る。
パッチ (300 平方度) の面密度での計算値:

- Gaia (ρ=30000/平方度): r=2 秒角で 2.9%、3 秒角で 6.3%
  → 半径は 2 秒角まで
- 2MASS Ks<14 (ρ=6000): r=5 秒角で 3.6%
- AllWISE (ρ=8000): r=3 秒角で 1.7%、6 秒角で 6.7%
  → 3 秒角まで
- RACS (ρ=150): r=20 秒角で 1.4%、45 秒角では 7.1%
  → 20 秒角まで
- Fermi: 0.2/平方度しかないので領域フラグで足りる

(面密度は銀河面での代表値という仮定。実行時に
パッチ実測で置き換える。)

## 3. 明るい源の扱い — 今回の教訓を仕様化

- EXT フラグで源を落とさない。GX 339-4 (パッチ
  最輝の BH) が EXT=9.7 で点状リストから漏れた。
  明るすぎる源は「広がって見える」ことがある。
- PSF 分裂片の併合: 最輝源から 60 秒角以内にあり
  フラックスが 10 分の 1 以下の弱い衛星源は、
  独立源と数えず fragment 印を付ける
  (最輝源の隣の J173901.3 が実例)。

## 4. 欠測の意味論 — 「見えない」を 3 つに分ける

各バンド・各源について、次の 3 値を区別する:

1. detected (検出あり)
2. below-limit (観測範囲内だが検出限界以下)
3. not-covered (カタログの範囲外・回避領域)

eRASS1 の半球制限 (はくちょう座側が範囲外) と
GALEX の銀河面回避が典型例。「暗い伴星のはずが
実は範囲外だった」という取り違えを防ぐのが目的。

## 5. 分類ベクトルと検証

各源に [γ, 硬X, X, UV, 可視等級, 近赤外, 中赤外色,
電波] の有無とフラックス比 (Fx/Fopt、Fx/Fradio、
X の硬さ) を付け、顔つきで分ける:

- BH 候補の顔: X 線あり + 電波あり + 光学で異常に
  暗い (Fx/Fopt 大) + バースト/パルスの記録なし
- NS の顔: バースト/パルスあり、または軟らかい
  熱的成分が卓越
- AGN の顔: W1-W2 > 0.8、固有運動ゼロ
- 星・CV の顔: 光学で明るい、固有運動あり

検証プロトコル: 選別のカットは、パッチ内の
BlackCAT 7 件と SIMBAD 同定済みの LXB に
当ててみる前に固定する。結果を見てから動かさない。
今回の単バンド結果 (活動中 3 件を回収、静穏 4 件は
カット以下、上位の未同定は全て既知の NS 連星) が
ベースラインになる。

## 6. 幾何チャンネル — 重力レンズ (屈折) を足す

重力レンズは帯域ではなく、光源の明るさ・位置・
時刻への「歪み」として現れる。だからバンド表では
なく時系列チャンネルとして足すのが正しい置き方。

主役はマイクロレンズ: BH が背景星の前を横切ると、
星が数十〜数百日かけて対称に増光する。時定数
tE はレンズ質量の平方根に比例するので、BH では
長い。署名は次の組み合わせ:

- tE が長い (100 日級)
- マイクロレンズ視差 πE が小さい (重いレンズの顔)
- ブレンド光がない (レンズ自体が光っていない
  = 暗いレンズ)
- 位置天文学的ずれ (ミリ秒角級) があれば質量が
  直接測れる

実績: OGLE-2011-BLG-0462 はこの方法で見つかった
確認済みの孤立 BH (約 7 太陽質量)。増光は OGLE の
測光、質量は HST の位置ずれ測定で確定した。
レンズ自体は無色収差 — 検出を担うのは光学バンドの
測光監視で、感度は「監視している光源の数 × 時間」
で決まる (波長走査のときに見た構図と同じ)。

入力データ: OGLE-IV / MOA-II のイベントカタログ、
Gaia の測光アラートと位置時系列 (本格化は DR4)。

設計上の問題 — 場所: イベント率はバルジ方向に
集中し (光学的深さ 約 1e-6)、今のパッチ
(l=330-350 の円盤方向) では 1〜2 桁低い。
分岐は 2 案:

- 案 A: パッチ自体をバルジ向きに移し、全バンド +
  レンズを同じ空で走らせる
- 案 B: レンズチャンネルだけは既存イベント
  カタログ (バルジ) で別枠にし、放射バンドの
  パッチとは切り分ける

検証セット: OGLE-2011-BLG-0462 が選別を
通ること。

## 6.5 残差チャンネル — アーカイブの星の「エラー」を掘る

新規観測を待たず、過去の画像・時系列そのものを
検出器として使う。星ごとに通常の振る舞い
(ベースライン) を引いて、その残差を見る —
GW の波形残差解析と同型の方法。

ベースラインと残差の対応:

- 測光: 参照画像との差分 (差分イメージング) が
  増光イベントそのもの。OGLE/MOA/ZTF のパイプ
  ラインはこれで動いている
- 位置: Gaia の 5 パラメータ解 (位置・視差・
  固有運動) からの残差。「単独星として合わない」
  度合いは RUWE や astrometric excess noise と
  してカタログに既に数値で載っている

BH の署名は、測光残差と位置残差の同時性で出る:

- 対称な増光 (長い tE) と同じ時刻に、重心の
  位置ずれが同方向に出る → レンズ質量が測れる
- 増光なしに位置だけが周期的に揺れる → 見えない
  伴星 (Gaia BH1-3 はこの顔で事前選別された)

規模の会計: Gaia は約 18 億星 × 数十〜百数十
エポック、OGLE はバルジの約 10 億星を長基線で
監視している。全部で 1e10〜1e11 点の測定が
既にアーカイブにある。一つずつ見るのではなく、
星ごとにモデルを引いて残差統計量で順位付けし、
分布の尾を候補リストにする。感度は星の数 ×
エポック数 × 時間基線で決まる。

実績: OGLE-2011-BLG-0462 の質量確定は、
イベントから約 10 年後にアーカイブの HST
位置データを掘り直して行われた。アーカイブの
再処理は「新しい観測」なしに新しい検出を
生みうる。

実装の型 — 2 エポック差分: 過去の画像と最新の
画像に**同じ抽出コード**を通して点リストを作り、
照合して変位ベクトルを取る。同じコードで両方を
処理することが要で、別々のパイプラインの較正差が
「偽のずれ」になるのを防ぐ。地元 (天の川、特に
近傍) が一番確認しやすいのは、角度信号が距離に
反比例して大きく、追観測で答え合わせができるから。

変位の分解 — ずれた点について「何が動いたか」は
次の 3 つに分かれる:

1. 星自身の固有運動と視差: 直線 + 年周の予測
   可能な動き (1 kpc、30 km/s で 6.3 mas/年)。
   これはベースラインとして引く側
2. 引いた後に残る周期的な揺れ: 星が物理的に
   動かされている = 見えない伴星に引っ張られて
   重心の周りを回っている。振幅は伴星質量と
   軌道と距離で決まる (Gaia BH1 型で 2.7 mas、
   BH3 型では 27 mas)
3. 一方通行のずれ: 星は動いていない。光が曲げ
   られて見かけの位置がずれた = 前面を重い
   何かが横切った (位置天文学的マイクロレンズ)。
   最大ずれは 10 太陽質量・1 kpc のレンズで
   約 3 mas。増光と同時に出て、通過すれば
   元に戻る

BH 自身は点として写らない。だから「ずれた点」は
常に星の側で、BH はずれの**型** (周期か、一方
通行か) としてだけ現れる。

検証セット: OGLE-2011-BLG-0462 (増光 + 位置
ずれ) と Gaia BH1-3 (位置の揺れ) がこの選別を
通ること。

## 7. 感度の会計

各バンドの検出限界から、代表的な BH の状態
(静穏 / ハード状態 / アウトバースト) ごとの
距離ホライズンを先に表にする (枠組みは
wavelength_sweep.py のものを流用)。どのバンドが・
どの状態を・どこまで見られるかを、走らせる前に
固定しておく — null が出たときに「感度の上限」
として返せるようにするため。

## 8. 実行の段階 (将来やるときの順序)

1. 明るい 58 件で X + 電波 + 近赤外 + 中赤外の
   4 バンド照合をし、分類ベクトルの型を固める
2. Gaia コーン照合 (58 件) で Fx/Fopt と
   固有運動を付ける
3. 5117 件全数へ拡張し、偶然一致率を実測で検証
4. γ と BAT は領域フラグとして最後に重ねる
5. レンズチャンネルは §6 の分岐を決めてから
6. 検証結果 (BlackCAT 回収率、既知 NS の混入率)
   を報告して止まる。候補の断定はしない
