# X 線走査の結果 — eRASS1 パッチ × BlackCAT

データ: eROSITA eRASS1 メインカタログ (VizieR
J/A+A/682/A34)。はくちょう座側は公開半球の外だった
ため、パッチは GX 339-4 側 (RA 245-265 度、
Dec -55..-40 度) に取った。全 5117 源のうち、
点状 (EXT=0) かつフラックス >= 1e-12 の 58 件を
走査対象にした。検証セットは BlackCAT (73 件)。

## 既知 BH の回収 (パッチ内に 7 件)

| BH | 結果 |
|---|---|
| GX 339-4 | カタログにある (5.5e-10、パッチ最輝の BH)。ただし EXT=9.7 のため点状源リストから漏れた — 明るすぎる源が「広がりあり」に分類される落とし穴 |
| MAXI J1631-479 | 回収 (7.6e-12、位置差 1 秒角未満) |
| 4U 1630-472 | 回収 (4.3e-12、位置差 1 秒角未満) |
| XTE J1650-500 / XTE J1652-453 / XTE J1726-476 / Swift J1658.2-4242 | カット以下。サーベイ期間 (半年) に静穏だったため |

つまり「現在の候補と同じ結果」は、活動していた
ものについては出た。残りは感度ではなく
デューティサイクルの壁 (BlackCAT 自身の見積もり:
銀河系の BH トランジェント約 1300 件中、発見は
5% 未満)。

## 未同定だった上位源の正体 (SIMBAD 照合)

明るい順の上位 6 件は全部、既知の低質量 X 線連星
だった: V926 Sco (= 4U 1735-444)、V801 Ara
(= 4U 1636-536)、Ara X-1、4U 1642-45 (GX 340+0)、
1RXS J170855.6-440653、4U 1701-407。多くは
中性子星系として知られるもので、新規の BH 候補は
明るい側からは出なかった。

例外として 1RXS J170855.6-440653 (2.1e-11) は
X 線連星として同定済みだが、コンパクト天体の
種類は未分類で BlackCAT にも入っていない。
「次に分けるならここ」という候補にはなる。

## 教訓

- フラックスの順位だけでは BH と中性子星は
  分かれない。分離には NS の署名 (バースト・
  パルス) の有無、硬さ、光学対応天体の暗さ
  (Fx/Fopt) が要る — 選別の次の段はそこ。
- 明るい源の周りには PSF の分裂片らしい弱い
  衛星源が付く (最輝源の隣の J173901.3 など)。
  源の数え上げには注意が要る。
