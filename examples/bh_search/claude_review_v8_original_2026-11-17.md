## 2. 事例 A：DR4 の非支持を「光度天井」で閉じる

### 2.1 主張

「M2>3 M☉ の主系列伴星は、系全体の光度が M_G,MS(3 M☉)=−0.1 より十分に暗ければ入らない」は、**伴星の光 ≤ 系の光**という不等式だけで成り立つ。したがって、β走査（主系列同士の同時解）の M2 最大値は、解析的な天井質量 M_MS(M_G,0 − 許容幅)になる。

### 2.2 検証

- **閉形式 vs 走査**: 5 天体（#4, #7, #8, #9, #13）× 許容幅 4 通り（±0.1〜±1.0）の 20 セルで、天井質量と scan3 の M2 最大値が **0.03 M☉ 以内**で一致（例: #4 ±0.3 で 1.53 と 1.52、#13 ±0.3 で 3.02 と 3.00）。
- **余裕（反転に要る系統誤差、減光は A_G,max で天井済み）**:

| 天体 | #4 | #7 | #8 | #9 | #13 | （#12） | （BH1） |
|---|---|---|---|---|---|---|---|
| 光度天井の余裕（等） | +2.73 | +3.78 | +5.30 | +2.95 | **−0.14** | +5.84 | +4.01 |

- BH1: 系と同じ明るさの主系列星の質量は約 1.0 M☉ で、f の下限が要請する M2≥7.6 とは全く両立しない。候補側の結論は光度モデルに依存しない。
- **帰結**: 低質量アンカーに依存しない（補間の欠陥が無関係になる）。主星の進化段階（モデル C/D）にも依存しない。#13 だけが負で、保留は定量的に正しい。

### 2.3 反証の試み：階層三重系

**問い**: 光度天井は「光る伴星」を縛るだけで、**暗い質量が光る星と同伴する場合**を縛らない。そのような配置は、光心軌道の式 f_phot=(M1+M2)|B−β|³ の上で、非支持の天体と矛盾しない解を持つか。

**試験**: 主星 M1（主系列）と、「伴星」＝光る星 Ms + 暗いコンパクト天体 Mc、の 3 体を考え、系の光度（±0.3 等）と f の区間を同時に満たす (M1, Ms, Mc) を全探索した（M1: 0.3–5、Ms: 0.1–5、Mc: 0.05–15 M☉）。

**結果（反証は成功）**: #4、#7、#8、#9 のいずれにも、**Mc ≥ 3 M☉ の解が存在する**（探索の上限 15 M☉ まで。Mc≥3 の解の数: #4 は 883、#7 は 331、#8 は 337、#9 は 283）。解の共通点は、
- 光る星が**主星より明るい**（β≈0.54–0.86、Ms/M1≈1.04–1.41）。つまり、ほぼ同質量の 2 つの星のうち、重い方が暗い質量と内側連星を組んでいる配置。
- 光心が質量中心の近くに来る（|B−β|≲0.26）。この「光と質量の中心の一致」が、見かけの f を小さく保っている。

**含意**:
1. **「BH非支持」は排除ではない**。単一の伴星（暗い天体、または単一の主系列星）を仮定した場合にだけ成り立つ。この限定は統合規則 §8 と追記 8 案 §1.2 に明記した（改訂 1）。
2. 一方、この配置は**微調整を要する**（光度比が質量比と数十%以内で整合し、かつ内側連星が安定）。事前確率は低いと考えられるが、私は定量化していない。
3. **閉じる手段**: 内側連星の存在は、光る星の**視線速度の変動**（内側軌道）として現れうる。DR4 の RVS エポック視線速度が使えるかは**要確認**。使えるなら、追記 9 で「内側連星の兆候なし」を第 3 の条件にできる。

### 2.4 その他の限界（反証できなかったが残る）

- 光度天井の閾値 1.5 等と、M_G,MS(3 M☉)=−0.1 のアンカーは、概略 ±0.5 等の不確かさを持つ。余裕 +2.73（#4）は閾値に対して 1.2 等の余裕で、#4 が最も薄い。
- 色の旗（#8 を保留にしている根拠）は、光度天井では独立に支持されない。**中谷さんの判断（現行基準）で保留を維持**。

## 3. 事例 B：GW231123 の検出統計量の幾何

### 3.1 主張

注入した振幅 g に対する統計量 S の応答は、「雑音ベクトル n（|n|=S0）に、注入による残差ベクトル a·g·r が加わる」と見なせる:

> S(g)² ≈ S0² + b g + a² g²　（b = 2 a S0 cosθ）

ここで a は応答の大きさ、cosθ は雑音ベクトルと応答ベクトルの向きの内積。**a は「g=1 あたりの応答」で、g99 より雑音に鈍感な量**になる。

### 3.2 検証

**(a) あてはまり**: 16 の格子点と新しい 3 点で、S0 を実測の無注入値に固定して b・a² を最小二乗で求めた。応答が有意な点（S(4) が背景 p99 を超える点）で、フィットの rms は多くが 0.001–0.03。例外は (2000, 0.5) の信号整合窓（0.068）で、S が 1 に近づく飽和（相関係数の上限）が効く。**近似として使えるが、厳密なベクトルのノルムではない。**

**(b) 応答 a は osc_proj に比例する**（実設定の osc_proj、`gw_osc_diagnostic.md`）:

| 窓 | n | a ∝ osc_proj^p の p | 一つ抜き予測誤差 ln a |
|---|---|---|---|
| 計画窓 | 8 | **1.00 ± 0.20** | 0.34（約 ±40%） |
| 信号整合窓 | 11 | 1.02 | 0.55 |

他の物差しとの比較（一つ抜き予測誤差、信号整合窓）: osc_proj 0.55、osc_rms 0.70、f_eq_distortion 0.86、√(⟨|F|²⟩−1) 0.87。**傾きが 1 に最も近く、予測誤差も最小なのは osc_proj**。v7 の g99 ∝ 1/osc_proj（傾き −1.07±0.07、信号整合窓）と整合する。

**(c) 窓長スケーリング（新しい予測と検証）**: 計画窓は 2.0 s、信号整合窓は 0.9 s。統計量が窓長で規格化されているなら、雑音も応答も L⁻¹ᐟ² で変わるはず（√(2.0/0.9)=1.49）。

| 量 | 信号整合窓 ÷ 計画窓 |
|---|---|
| 背景 p99 | 1.46 |
| 背景の最大値 | 1.55 |
| 応答 a（両窓で有意な 8 点） | 1.59 ± 0.10（標準偏差 0.28、中央値 1.53） |
| 予測 √(L_計画/L_整合) | 1.49 |

**3 つとも予測と 1σ 以内（応答）または 2% 以内（p99）で一致**。これは、Muse の「窓による希釈」を、**窓長 L の関数**として定量化したもの。

**(d) 交差項（雑音と応答の向き）**: fit された cosθ は、計画窓で平均 −0.19・標準偏差 0.26（n=16）、信号整合窓で平均 −0.08・標準偏差 0.28（n=17）。最大絶対値は 0.54。向きが 2 次元でランダムなら、16 点全部が |cosθ|<0.5 になる確率は 2×10⁻⁸。**向きは高次元（実効次元 D≈13–15）のベクトルのように、ほぼ直交している**。

### 3.3 反証の試み

**予測**: 交差項が独立な乱数なら、g99 の単一実現の相対ばらつきは σ_cos·S0/√(p99²−S0²) になる。計画窓で ±22%、信号整合窓で ±35%。観測された g99×osc_proj の変動係数は、計画窓 0.19、信号整合窓 0.16–0.17。

**結果**:
- 計画窓は予測と整合（±22% vs 0.19）。
- **信号整合窓は予測（±35%）が観測（0.17）の約 2 倍で、棄却**。独立な交差項の仮定は成り立たない。
- **説明（仮説）**: 全ての格子点が**同一の雑音実現 n を共有**している。向きの偏りは格子点間で相関する共通モードになり、ばらつきとして現れず、**g99 の定数 c 全体を一斉にずらす**。平均 cosθ が負（計画窓 −0.19）なので、c は雑音なしの値より**約 +16%（計画窓）／+10%（信号整合窓）大きく出ている**と見積もれる。
- 計画窓の (500, 0.5) の外れ値（g99=3.47）は、この点の応答 a が小さい（a/osc_proj=0.090、他の有意な点は 0.12–0.22）ことで説明が付く。この点の g99 が取りうる範囲（交差項が ±1 のとき）は 1.20–5.53 で、3.47 はその内側。**単一実現では「雑音の揺らぎ」と「真の希釈」を分けられない**。

### 3.4 検証可能な予測（要ゴーサイン）

1. **多実現化**（off-source の N≥100 位置に同じ注入）: g99 の分布は、計画窓で中央値が現在の値の約 0.86 倍（共通モードの +16% を除く）、幅 ±20–25% を予測する。(500, 0.5) の計画窓も同様に、実現ごとに g99 が 1.2–5.5 の範囲で動くはず。
2. **窓の掃引**（L=0.5 s など）: p99 と応答 a は ∝ L⁻¹ᐟ²（L=0.5 s で 0.9 s の約 1.34 倍）。S0 は 2 窓の比（1.79）から L⁻⁰·⁷³ と粗く見積もれるが、これは **2 点からの外挿で、信頼しない**。窓を絞りすぎると S0 が p99 に近づき、余裕 √(p99²−S0²) が減る。最適な窓は、掃引で決める。
3. 予測が外れれば、「S が窓長で規格化されている」という描像を棄却する。

### 3.5 限界

点質量レンズのみ。テンプレートは固定（再選択なし。Stage C が未実施）。S は厳密なベクトルのノルムではない（フィットの飽和）。**g=1 での結果は条件付きで、「排除」とは呼ばない**（v5 §5.3 の書き直し案のとおり）。

## 4. 事例 C：κ 混線行列 K の「指紋」

### 4.1 主張

K（441×441）は、物理的な応答を測る意味では**単一パラメータ b（振幅）だけが測れる**構造をしている。個々のボイドの振幅を K で逆畳み込みするのは、不良設定になる。

### 4.2 事実（Muse の K の再解析）

| 量 | 値 |
|---|---|
| 一様平均の回収率 | 0.7151 = 対角の寄与 0.9886 + 非対角の寄与 −0.2734 |
| t と K·t の余弦 | 0.332 |
| 自分のテンプレートと符号が逆の応答になるボイド | 171 / 441 |
| 応答の大きさが自分のテンプレートを上回るボイド | 298 / 441 |
| 特異値の最大 / 最小、条件数 | 10.1 / 6.7×10⁻⁴、約 1.5×10⁴ |
| 実効ランク（参加比） | 約 186 |
| 実部が負の固有値の数 | 102 |

- 非対角の寄与の −0.2734 は、K 記録の「混線 −0.273」と一致する。隣接ボイドの補償環（負の κ）が自分の補償環に重なることによる。
- **含意**: 個々のボイドの期待応答は、自分のテンプレートとの余弦が 0.33 しかなく、隣接ボイドに支配される。条件数 1.5×10⁴ の K を逆に解くと雑音が増幅されるため、**1 パラメータ b に絞る（K·t を物差しにする）のは理にかなっている**。

### 4.3 反証：私の旧基準を攻撃する

**旧基準**（私の v6・追記 7 案 D）: 全格納要素について |ΔK_ij·t_j| ≤ 0.01σ（σ=4.4×10⁻⁴）。

**攻撃**: 全非対角要素に、符号方向へ一律 +0.005 のコヒーレントな誤差を加える（これは要素ごとの基準を満たす: 最大 |ΔK·t|/σ=0.0056）。結果は、**回収率が 0.715 から 0.881 に（+23%）変わる**。非対角の寄与は −0.273 から −0.108 になる。

| 摂動 | 回収率 | 非対角の寄与 | t と K·t の余弦 |
|---|---|---|---|
| なし | 0.7151 | −0.2734 | 0.332 |
| 非対角 ×1.01（コヒーレント） | 0.7124 | −0.2762 | 0.328 |
| 非対角 ×1.05（コヒーレント） | 0.7015 | −0.2871 | 0.314 |
| 非対角 ±5%（独立な乱数） | 0.7169 | −0.2717 | 0.332 |
| 対角 ×1.01 | 0.725 | −0.2734 | 0.336 |
| 要素ごとの基準を通す最悪摂動（+0.005） | **0.881** | −0.108 | 0.381 |

**結論**:
- **要素ごとの基準は、コヒーレントな誤りを通す**。34,054 個の誤差が足し合わさって積に効く。私の旧基準は**棄却**。
- 一方、**独立な乱数の誤差（±5%）は、指紋にほとんど現れない**（回収率の変化 0.002）。スタックに効くのは、コヒーレントな成分だけなので、これは妥当。

### 4.4 改訂：指紋による受け入れ基準（提案）

独立実装が、次の**全てを**満たすことを受け入れ基準とする（要素ごとの基準と併用）。

| 指紋 | 基準の値 | 検出できる誤り |
|---|---|---|
| 回収率 | 0.7151 ± 0.002 | 非対角のコヒーレントな 1% の規格化誤差（−0.0027）、対角の 1% の誤差（+0.010） |
| 非対角の寄与 | −0.2734 ± 0.002 | 同上 |
| t と K·t の余弦 | 0.332 ± 0.005 | +0.005 のコヒーレントな誤差（+0.05）、非対角 5%（−0.018） |
| 符号が逆のボイドの数 | 171 ± 3 | 大きな系統誤差 |
| 応答が上回るボイドの数 | 298 ± 3 | 同上 |

（許容は私の感度試験からの提案値。Muse・ChatGPT の確認が要る。）

### 4.5 必要ボイド数の更新（v6 の確認）

一様平均で 3σ に必要なボイド数は、K を無視すると約 30,900、K を入れると約 60,400。PR4（S/N 1.2 倍）を使うと約 42,000。K·t を使う重み付けの利得は、雑音の共分散 C がないと評価できない（iid 仮定では 3.6–5.1 倍だが、重なる開口の相関を無視した過大評価）。
