## 4. ラベルの安定性（対象ごと）

- **#4・#7・#9: 安定。** 補間修正による M2 最大の変化は ±0.3 等で最大 0.01（#9 の 1.28→1.29、#7 の ±0.1 で 1.15→1.16 はグリッド刻み 0.01 の差）。許容幅を ±1.0 等まで広げても最大 1.72 で、3 M☉ に遠く届かない。主系列同士モデルの範囲では「BH非支持」は補間修正と許容幅の両方に対して安定。
- **#8: 「同時解なし」は撤回すべきものだった。** 補間修正で解が現れた（問題A の指摘どおり）。ただし現れる解は全て M2 ≤ 0.91 で、M2 > 3 の主系列伴星解はどの許容幅でも存在しない。したがって結論の向き（非支持）は変わらないが、その根拠は「解なし」から「解は全て低質量側」に置き換わる。なお #8 は主星自体の色に「要注意」旗があり、主系列同士という前提自体が弱い点は従来どおり。
- **#13: 不安定。** M2 最大は ±0.3 等で 3.00（境界上）、±0.5 等で 3.20 と 3 M☉ を超える。±0.3 等の選択に誤差評価からの根拠が無い現状では、「BH非支持」は許容幅の恣意的な選択に依存しており、確定扱いにできない。主星が進化星の疑い（色の旗「不適」）もあり、進化星モデルを導入するまで #13 は保留に戻すのが妥当、という ChatGPT の判断に同意する。
- **#6 BH1: 不変。** どの許容幅・どちらのアンカーでも主系列同士の同時解は存在しない。候補性は今回の問題の影響を受けない。

## 5. 留保

- 本走査は主系列同士モデル（ChatGPT の言うモデル A）のみ。進化星主星（モデル C/D）やコンパクト天体伴星（モデル B）の検証は未実施で、特に #8・#13 の確定にはモデル C の導入が要る。
- ±0.3 等の許容幅の根拠づけ（観測誤差・消光誤差・質量–光度関係の系統誤差からの導出）は今回も行っていない。§3 の感度表が示すとおり、結論が許容幅に依存するのは #13 のみだが、根拠づけ自体は残課題。
- アンカーは ±0.5 等級級の概略値であり、金属量・年齢のばらつきは入っていない。
