## v1 からの変更点

1. **測光余裕に A_G,max を反映**: 余裕 = (M_G − A_G,max) − M_G,MS(M2下限)。A_G,max は `gaia_extinction_13.json` による: A_G ≤ A_V のため、A_G,max = max(GSP-Phot の A_G, TGE の a0 を A_V 天井として)（Claude v5 §3.4/§7E の規約）。取得経路は Gaia TAP（ARI ミラー。ESA 本体は本環境から到達不可だったため）。TGE は HEALPix level 6・NESTED の該当ピクセル。
2. **#10 は判定保留へ**: 分光質量関数 f_rv は sin³i を含み、傾斜角が未知では M2 の上限が存在しない（下限のみ）。v1 の「BH非支持」を取り下げ、「判定保留（軌道傾斜角未確定）」とする（ChatGPT 第2回 §2.2）。
3. **2 軸ラベル**（Claude v5 §7A）: 質量軸と測光軸を分離。M_G,0 < 2 は測光軸を「排除できない」とするだけに留める。これにより #13 は質量軸=非支持のため最終「BH非支持」（測光軸の判定不能を付記）となり、v1 の「判定不能（測光）」から変わる。
4. **M1 範囲の和集合**（Claude v5 §3.2/§7B）: 主系列仮定が不適な #13 は従来範囲 [1.74, 3.45] と [1.0, 3.0] の和集合 [1.0, 3.45] を採る。
5. **M1 感度列**: M1 を [0.3, 5] に振っても質量軸の判定は **13 件すべてで不変**（Claude v5 §3.3 の結論と一致）。
6. **表示精度**: f 区間は有効数字 4 桁（%.4g）。#10 の上限が 0.0 に丸められる v1 のバグは解消（0.0002134 と表示）。
