## 1. 補間方式: 提案された「光度基準」は現行方式と数学的に同一

査読の指摘: 現行の補間（等級を質量に対して補間）は物理的に適切でない可能性があり、
質量–光度の関係を光度で構築してから等級に変換すべき、という提案。

検証結果:

- 現行方式（方式A）の実態は、M_G を log10(M) に対して線形補間する**半対数**補間である
  （査読の言う「対数–対数」ではない。この点は記録として正確に残す）。
- 提案方式（方式B: log L を log M に対して線形補間し M_G に戻す）は、
  log10 L = −0.4·M_G + 定数 のため、**方式A と恒等的に同一**である。
  実際、全対象・全許容幅で解が完全一致した。
  つまり提案された修正は、現行方式の言い換えであり、別の計算にはならない。
- 真に異なる方式C（L 自体を log M に対して線形補間）で頑健性を確認した。
  M2 最大値の変化は #4 −0.03、#7 −0.03、#8 −0.01〜−0.02、#9 −0.01、
  #13 0.00（±0.3）/ −0.10（±0.5）M☉ で、**どの対象でも判定は変わらない**。
- #13 が 3 M☉ の境界をまたぐ原因は補間方式ではなく**許容幅の選択**であることが
  確定した（全方式で ±0.3 → 3.00、±0.5 → 3.10〜3.20）。追記5 の保留判断は不変。

## 3. #8 のラベル変更: BH非支持 → 判定保留

査読の問題②（#8 は主系列同士モデルでのみ非支持であり、最終判定は保留とすべき）
を受け入れる。根拠は主星の色の旗の実数である:

Δcolour（減光補正後の色 − 主系列の色、`dr4_m1m2_table.json`）:

| 対象 | Δcolour | 区分（追記3 の二段基準） |
|---|---|---|
| #8 | **+0.42** | 要注意（> 0.30）— 進化星 / 未分解連星の可能性 |
| #13 | +1.01 | 不適（進化星の疑い、個別分類済み） |
| #4 | +0.24 | 弱い注意（0.15–0.30） |
| #7 | +0.23 | 弱い注意 |
| #9 | +0.12 | 旗なし |

- #8 は主星の主系列前提自体が弱い（Δcolour +0.42）。モデルA（主系列同士）の
  範囲では M2 ≤ 0.91 M☉（全許容幅・全補間方式）で BH を支持しない方向は保たれるが、
  進化星を含むモデル（C/D）の検証が済むまで最終判定にはできない。
  よって #8 を **判定保留（主星の主系列前提が弱い）** に変更する。
- #4・#7 は弱い注意の範囲であり、モデルA の結論（M2 最大 1.2〜1.7、3 M☉ から遠い）
  と併せて BH非支持 を維持する。#9 は旗なしで BH非支持 を維持する。
- 付記: 評価表コードの旗の閾値（0.25）と追記3 の二段区分で #4・#7 の呼び方が
  食い違う（コードでは「概ね妥当」、区分では「弱い注意」）。判定への影響はないが、
  今後は追記3 の二段区分の呼称に統一する。

## 4. 減光はモデル別ブラケットとして保持する

査読の問題④を受け入れ、減光は単一の値を「正しい」と決めず、
GSP-Phot / MSC / TGE の3推定を並記してモデル間系統差として保持する
（`gaia_extinction_bracket_13.json`）。

- 現行規約 A_G,max = max(GSP-Phot, TGE) と変種 max(MSC, TGE) で変わるのは
  **#12 のみ**（2.6713 → 1.4664）。他12件は両変種とも TGE が支配的で不変。
- BH1 の測光余裕は両変種とも 6.65 等で不変。#12 の測光余裕は −0.86 等まで
  改善するが要求（≥ 1 等）には届かず、測光軸は「排除できない」のまま。
- **ラベル変更はなし。** モデル間系統差が実際に効くのは #12 の減光だけで、
  その影響範囲（測光余裕の値のみ、最終ラベルには不達）を記録した。
