# 光心 β 走査（ChatGPT 追加査読・第2点への数値回答）

作成: 2026-11-15（Muse）。スクリプト: `dr4_beta_scan.py`（M1 固定版）、`dr4_beta_scan2.py`（全光度同時版）。
前提: 伴星は通常の主系列星とし、β はプロジェクトのアンカー表（質量–M_G）から自己無撞着に決める。f_phot = (M1+M2)|B−β|^3、B = M2/(M1+M2)。

## 走査1（M1 を評価表の範囲に固定）
- #6 BH1: どの M1 でも主系列伴星の解は**存在しない**（f 区間 [7.58, 18.14] を再現できない）。候補性は明るい伴星の分岐でも不変。
- 非支持の #4・#7・#8・#9 はすべて、M2 > 3 に届く主系列伴星の解帯を持つ（例: #9 は M1=1.21 で 6.95–9.7）。→ 質量軸（β=0 前提）だけでは非支持は完結しない、という ChatGPT の論点は数値的に正しい。

## 走査2（系の全光度 M_G,0 と f を同時に課す）
明るい伴星解は系の光を支配するため、M1 固定は自己矛盾。全光度（±0.3 等の許容）も課すと:
- #4: M2 最大 1.52 / #7: 1.21 / #9: 1.28 — **M2 > 3 の解は無い**。非支持は維持。
- #6 BH1: 主系列–主系列の同時解なし（走査1と整合）。
- #8: 同時解なし（= どの質量の主系列伴星でも f と全光度を同時に満たせない）。暗い伴星分岐では M2 ≤ 0.58。非支持は両分岐で維持。ただし主星自体の色に旗があり、主系列性の前提は弱い。
- #12: 同時解なし（判定保留は不変）。#13: M2 最大 3.00（境界上。主星が進化星のため主系列アンカーは参考値）。

## 結論
ラベルは全て維持される。ただし追記3 §1 の「質量軸が非支持なら測光軸に関係なく BH非支持」という文面は、そのままでは不十分: 非支持は β=0 の質量軸に加えて「系の全光度と矛盾する明るい伴星解が存在しないこと」に依存している。条文の側を直すのが正しい（追記での訂正を提案）。
