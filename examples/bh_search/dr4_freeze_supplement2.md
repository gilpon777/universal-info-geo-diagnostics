# DR4 凍結 追記文書 2 — 判定規則の固定

作成: 2026-11-15（Muse）/ 対象: `dr4_freeze.md`（凍結本体）、`dr4_freeze_supplement.md`（追記 1）
位置づけ: 凍結本体と追記 1 の測定層（凍結した f の区間と判定基準）は一切変更しない。本書は Claude v3・v4 と ChatGPT の追加査読、および Muse の意見書・返信で合意した**解釈・判定の運用規則だけ**を、DR4 公開（2026-12-02）前に追加で固定する。本書自体の固定方法は §8。

## 1. 可視伴星の測光排除（条文）

「BH 候補」の判定には、伴星が明るい主系列星でないことの測光的な確認を必須とする。

- M2 下限に対応する主系列星の絶対等級を M_G(M2 下限) とする（質量–光度関係は Pecaut & Mamajek 系の主系列表による）。
- 次式を満たす場合に限り、主系列伴星を測光的に排除できたとする:
  **(観測 M_G − A_G,max) − M_G(M2 下限) ≥ 1 等**
  - 1 等は質量–光度関係のばらつき等への余裕、A_G,max は減光の上限。両者は独立した誤差源なので加算する（Muse の当初案の max 形式は v4 査読で撤回済み）。
  - A_G,max は、その視線方向の銀河全体の減光を天井とする。実務上は A_G,max = 2.74 × E(B−V)（全視線積分値、係数は Wang & Chen 2019 の標準値）とし、Gaia GSP-Phot の A_G がこれより大きい場合はそちらを採る。
  - 参考: BH1 の余裕は約 8.1 等あり、A_G,max の取り方で現 13 件の判定は変わらない。
- 系の補正後絶対等級 M_G,0 が **2 未満**の天体は「判定不能」とし、BH 候補のラベルは付けない（分光データが追加されるまで保留）。

## 2. M1 の範囲（条文）

- M1 は単一値でなく範囲で扱う。構成は評価表（`dr4_m1m2_table`）の実装どおり:
  - M1 下端 = 0.8 × M1(観測 M_G)（減光補正なし。減光は M1 を小さく見せる方向にのみ働く）
  - M1 上端 = 1.3 × M1(M_G − A_G)（A_G は Gaia DR3 GSP-Phot。無い天体は観測 M_G で代用し、その旨を記録する）
- 主系列仮定が不適と判断される天体（色が主系列から大きく外れる等）については、範囲を **[1.0, 3.0]** に広げる。
- 判定の評価端: 「BH 候補」の支持判定は M1 の**下端**で、「BH候補ではない」の判定は M1 の**上端**で行う（両方向で保守的になるよう固定する）。

## 3. 判定表（条文）

DR4 の入力（公表 f 区間を第一優先とする追記 1 の規則は維持）に対し、出力を次の通り一意に定める。M2 は f = M2³/(M1+M2)² の逆変換による。

| 入力の状態 | 出力 |
|---|---|
| 対応付けが 対応 D（確認できない） | 「対応不明」— 判定しない |
| 系の M_G,0 < 2 | 「判定不能（測光）」— 候補ラベルを付けない |
| M2 下限（M1 下端で評価）> 3 かつ §1 の測光排除を通過 | 「BH 候補」 |
| M2 上限（M1 上端で評価）< 3 | 「BH非支持」（＝BH候補ではない。通常の恒星伴星であることの証明ではない） |
| M2 区間が 3 をまたぐ | 「判定保留」 |
| 軌道解が無い | 「軌道解なし」— 判定しない |

- 3 M☉ は中性子星の上限（約 2.3 M☉）に対する実務上の保守的な境界であり、自然界の絶対的な境界ではない。
- 「BH 候補」はブラックホールの発見を意味しない。

## 4. 対応付けの確信度（条文）

DR4 との照合結果には、対応付けの確信度を必ず記録する。検証分類の A–D との混同を避けるため「対応」を冠する。

| 確信度 | 意味 |
|---|---|
| 対応 A | 公式の対応表（neighbourhood 表）で一致 |
| 対応 B | 位置・固有運動・等級で整合（追記 1 の対応付け規則による） |
| 対応 C | 複数候補が残る（全候補を記録し、最近傍を採用したうえで明記） |
| 対応 D | 対応を確認できない |

## 7. DR4 の公開が遅れた場合（条文）

DR4 の公開日が変更されても、凍結した基準（本体・追記 1・本書）は有効のまま維持する。追加の追記が必要になった場合は、日付と理由を明記した新しい追記文書として追加し、既存の文書は書き換えない。
