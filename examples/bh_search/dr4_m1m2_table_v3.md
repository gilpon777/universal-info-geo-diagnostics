## v1 からの変更点

1. **測光余裕に A_G,max を反映**: 余裕 = (M_G − A_G,max) − M_G,MS(M2下限)。A_G,max は `gaia_extinction_13.json` による: A_G ≤ A_V のため、A_G,max = max(GSP-Phot の A_G, TGE の a0 を A_V 天井として)（Claude v5 §3.4/§7E の規約）。取得経路は Gaia TAP（ARI ミラー。ESA 本体は本環境から到達不可だったため）。TGE は HEALPix level 6・NESTED の該当ピクセル。
2. **#10 は判定保留へ**: 分光質量関数 f_rv は sin³i を含み、傾斜角が未知では M2 の上限が存在しない（下限のみ）。v1 の「BH非支持」を取り下げ、「判定保留（軌道傾斜角未確定）」とする（ChatGPT 第2回 §2.2）。
3. **2 軸ラベル**（Claude v5 §7A）: 質量軸と測光軸を分離。M_G,0 < 2 は測光軸を「排除できない」とするだけに留める。これにより #13 は質量軸=非支持のため最終「BH非支持」（測光軸の判定不能を付記）となり、v1 の「判定不能（測光）」から変わる。
4. **M1 範囲の和集合**（Claude v5 §3.2/§7B）: 主系列仮定が不適な #13 は従来範囲 [1.74, 3.45] と [1.0, 3.0] の和集合 [1.0, 3.45] を採る。
5. **M1 感度列**: M1 を [0.3, 5] に振っても質量軸の判定は **13 件すべてで不変**（Claude v5 §3.3 の結論と一致）。
6. **表示精度**: f 区間は有効数字 4 桁（%.4g）。#10 の上限が 0.0 に丸められる v1 のバグは解消（0.0002134 と表示）。

## 注記

- 測光余裕が負の天体は、M2 下限に相当する主系列星より系が明るい（主星自体の光が支配的）ため、その質量の下限側では測光排除が効かないことを示す。質量軸が非支持の天体では最終ラベルに影響しない（測光軸は候補判定にのみ必要）。
- f 区間の出典: #6 と #12 は凍結・全共分散 MC（追記 3 §6）、他は独立周辺 MC。#12 の独立周辺 MC は f [0.2039, 82.7]、M2 [0.632, 84.9] で、v2 では主表の主値だったものを v3 で本注記への併記に降格した（どちらの区間でも質量軸は保留で不変）。
- #12 の減光の旗: GSP-Phot の A_G (2.6713) が TGE a0 (1.4664) を上回る。A_G ≤ A_V で、TGE a0 は視線方向の全銀河減光の天井（A_V として）であるため、この GSP-Phot 値は物理的にあり得ない。M1 推定には使用せず A_G = TGE a0 = 1.4664 を用いる（M1 範囲: 旧 [0.48, 1.14] → 新 [0.48, 0.95]。下端は A_G を含まない式のため不変）。新 M1 範囲で凍結 f から M2 端点を再計算すると [0.39, 92.2] で、主表の凍結値 [0.39, 92.5] と同様に 3 M☉ をまたぎ、質量軸「保留」は不変。測光軸の A_G,max（天井規約）は別用途のため v2 のまま（2.6713（GSP））とし、測光余裕 −2.06 も変更しない。
- M1 範囲は主系列アンカーによる暫定推定で、減光・金属量・進化・未分解連星の系統は M1 感度列で吸収する設計（感度列が全件「不変」であることが根拠）。
- 光心軌道の問題（ChatGPT 第2回 §2.3）: 測光排除は「伴星が暗い」仮定の確認を兼ねるが、光度比を含む光心モデルの導入自体は本 v2 の範囲外（別課題として残す）。
