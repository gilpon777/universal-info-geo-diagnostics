# DR4 凍結 追記文書 4 — 非支持条件の明示（光心 β）と減光 bound の位置づけ

作成: 2026-11-15（Muse）/ 対象: `dr4_freeze.md`（凍結本体）、追記 1–3
位置づけ: 凍結本体・追記 1–3 の測定層と条文は変更しない。本書は ChatGPT 追加査読（2026-11-15）を受けて実施した光心 β 走査の結果に基づき、**追記 3 §1 の文面の不十分さを訂正**し、減光 bound の位置づけを明記する。ラベルの変更はない。

## 1. 非支持の条件の訂正（ChatGPT 追加査読・第2点）

追記 3 §1 は「質量軸が『非支持』なら、測光軸に関係なく『BH非支持』」とした。しかし質量軸の M2 区間は、光心軌道の質量関数

f_phot = (M1 + M2) |B − β|³、B = M2/(M1+M2)、β = F2/(F1+F2)

において β = 0（暗い伴星）を仮定して得たものである。β を自由にすると、同じ f_phot を M2 > 3 M☉ の明るい伴星でも再現しうるため、質量軸だけでは非支持は完結しない。この論点は正しい。

**訂正後の非支持の条件**: 質量軸が非支持（β=0 で M2 上限 < 3 M☉）であり、かつ **系の全光度と両立する明るい伴星解が存在しない**こと。後者は測光軸とは別の使い方であり、非支持の側でも光度の制約が効く（候補の側の「排除」とは向きが異なる）。

## 2. β 走査の結果（2026-11-15 実施、`dr4_beta_scan.py` / `dr4_beta_scan2.py` / `dr4_beta_scan.md`）

伴星を通常の主系列星とし、β を質量–光度アンカーから自己無撞着に決めて走査した。

- M1 を評価表の範囲に固定した走査: 非支持の #4・#7・#8・#9 はすべて M2 > 3 に届く主系列伴星の解帯を持つ（#9 は最大 9.7 M☉）。質量軸単独では不十分であることを確認した。
- 系の全光度 M_G,0（±0.3 等の許容）と f 区間を**同時に**課した走査: 明るい伴星解は全て消える。M2 の最大は #4: 1.52、#7: 1.21、#9: 1.28。#8 は同時解自体が存在しない（暗い伴星分岐では M2 ≤ 0.58）。
- #6（BH1）: 主系列伴星ではどの質量でも f 区間 [7.58, 18.14] を再現できない。明るい伴星の分岐でも候補性は不変。
- #13: 同時解の M2 最大は 3.00（境界上。主星が進化星のため主系列アンカーは参考値）。#12: 同時解なし（判定保留は不変）。

**結論: 現在の全ラベルは維持される。** 変わるのは根拠の書き方であり、§1 の訂正をもって非支持の条件とする。

## 3. 減光 bound の位置づけ（ChatGPT 追加査読・第1点）

- 追記 3 §2 の A_G,max は、TGE の a0 を A_G と同一視したものではなく、A_V の天井として用いたものである（A_G ≤ A_V のため安全側）。ただし a0（単色減光）と A_V の同一視自体は近似であり、TGE は全視線量であって対象星までの距離に対応した量でもない。
- したがって BH1 の測光余裕 6.65 等は精密な測定値ではなく、**天井ベースの bound** として扱う。要求（≥1 等）との差が大きいため、この近似はどのラベルにも影響しない（他の軌道解天体の余裕は −2.06〜−8.34 等で、反転の余地はない）。
- 距離に対応する推定としては GSP-Phot の A_G（対象星自体のスペクトルからの推定）が既に取得済みであり、A_G,max はその大きい側を採る保守的な構成であることを併記する。
