## 考察: 物差し仮説の判定は「条件付き支持」

1. **M_z = 2000 では仮説は支持される。** 計画窓の予測比は 1.00 と 1.24 で、
   2 点とも積が格子の既存範囲内にある。新 3 点のうち M=2000 の 2 点を加えた
   計画窓の積統計は平均 0.570・変動係数 0.19（n=7）と、格子のみの時点
   （0.574・0.21）とほぼ変わらず、同じ母集団として扱える。
2. **(500, 0.5) の計画窓では仮説は支持されない。** 実測は予測の 2.19 倍。
   定数を格子較正値 0.574 に置き換えても比は 1.91 で、定数の選び方の問題ではない。
   計画窓（−1.5〜+0.5 s）では、この点の歪みの残差相関が窓内に薄く広がり、
   osc_proj が示すほどには S が立ち上がらない、という窓固有の希釈が起きている。
3. **信号整合窓では 3 点とも物差しが成り立つ。** 積は 0.379 / 0.410 / 0.427 で、
   全て格子の既存範囲 [0.311, 0.579] 内にあり、(500, 0.5) は格子平均 0.427 と
   ほぼ一致する。新 3 点を加えた信号整合窓の積統計は平均 0.421・変動係数 0.16
   （n=11）と、むしろ少し締まった。つまり osc_proj が感度を決める変数である
   という描像自体は (500, 0.5) でも壊れておらず、壊れたのは「計画窓・定数 0.5」
   という組み合わせである。
4. **実務的な帰結**: 物差しで感度地図を描く場合は窓ごとの定数
   （計画窓 ≈ 0.57、信号整合窓 ≈ 0.43）を使い、計画窓については
   M_z ≲ 500 の領域を物差しの外挿で埋めてはいけない（直接測定が必要）。
   なお (500, 0.5) の計画窓 g99 = 3.47 は有限であり、g=4 でも届かなかった
   格子の (400, 0.5) と比べれば、この領域は「感度なし」ではなく
   「物差しの予測より弱いが、強い歪みなら届く」が正しい記述になる。

## 留保

- **単一ノイズ実現**: 実ストレインの同一区間・同一背景配列に対する測定であり、
  g99 の実現ごとのばらつきは格子の積の散らばり（変動係数 ~0.2）が示す程度にはある。
  比 1.24 の点はこのばらつきと区別できない。比 2.19 の (500, 0.5) 計画窓は
  ばらつきでは説明しにくいが、その g99 自体が浅い S 曲線の g=2–4 間補間に
  依存しており、補間誤差も通常より大きい。
- テンプレートは idx 19435 に固定（Stage B の流儀どおり再選択なし）。
  多実現化・テンプレート再選択は別の段階の課題として残る。
- 予測の定数 0.5 は計画窓に対する仮説値であり、信号整合窓の実測との比較は
  「窓固有の定数で物差しが成り立つか」という補助的な検算として位置づける。
