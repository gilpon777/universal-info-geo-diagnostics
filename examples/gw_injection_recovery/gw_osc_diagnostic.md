# GW231123 osc 診断: 再現照合と射影版 osc_proj

Stage B 本体（実ストレインへの注入・回収）は再実行していない。g99 は保存済み結果（`wf_data/gw231123_inject_recover.json`）の値をそのまま使う。本ファイルは診断量 F(f) の計算のみ。

## 設定（gw231123_inject_recover.py と同一）

- 帯域 20–448 Hz（64 s セグメント、df = 1/64 Hz）
- 重み w(f) = Σ_det |H_det(f)|² / Sn_det(f)（H1+L1、PE サンプル idx 19435 のテンプレート、PE PSD。f_eq と同一の SNR 重み）
- osc_rms: F から複素加重平均 ⟨F⟩_w を引いた残りの加重 RMS
- osc_proj: F−1 を {1, f} の張る複素空間へ加重最小二乗射影し、残差の加重 RMS を取る（Claude v6 §4.3(b)）。{1} のみへの射影が平均除去に相当するので、osc_proj は「平均＋周波数線形成分」を除いた残り。線形成分はフィットの τ（到着時刻ずれ）が吸収する方向に対応する。

## 注意

- g99 は単一ノイズ実現・固定テンプレートでの Stage B 保存値であり、その不確かさは積のばらつきにそのまま乗る。
- 射影基底の f は Hz 単位の生の周波数。射影は加重内積による厳密な最小二乗。
- F のスプライン補間誤差（帯域内ランダム点での直接評価との最大相対誤差）は JSON に点ごとに記録した。
