## 1. 問うこと — 既測の感度との違い

すでに測ってあるのは**フィット後の感度**である。
残差にテンプレート同形の信号を割合 f で加える方法（`gw231123_sensitivity.py`、
`wf_data/gw231123_sensitivity.json`）で、背景 p99 を超えるのに必要な f は

- 計画窓 [-1.5, +0.5] s: **f99 = 0.82**
- 信号整合窓 [-0.6, +0.3] s: **f99 = 0.47**

（`waveform_analysis.md` §7–§9。GW250114 は 0.26 / 0.24、GW240925 は 0.58 / 0.36、
GW241011 は 0.47 / 0.37。）

しかしこの数字は、**フィットが信号をどれだけ吸収するかを測っていない**。
主解析は検出器ごとに複素振幅 α と微小時間ずれ τ をフィットしてから差し引く
（GW231123: |α| = 0.649 / 0.592、τ = −6.8 / −3.9 ms）。
`collapse_mechanism.md` の潰れ4が示す通り、滑らかなレンズ効果は
(a) 周波数に依らない増幅 → α に、(b) 一様な時間遅延 → τ に、
それぞれ**完全に吸収**され、その成分の FIM は恒等的にゼロである。
潰れないのは周波数依存の増幅 A(f) だけである。

本試験が問うのはこの一点である。
**実ストレインにレンズ信号を入れてからフィット込みで回収したとき、
どれだけが残るか。** フィット後注入の f99（0.82 / 0.47）と
フィット込み注入の f99 の差が、吸収の実測値になる。

## 3. Stage A — 同形注入（吸収の上限を測る）

目的: フィットが同形信号をどれだけ吸収するかの、最も悪い場合の実測。

1. 実ストレイン（ホワイトニング前の 8 s セグメント）に f·h(t) を加える。
   h(t) は採用サンプル idx 19435 の再生成テンプレート（検出器投影済み）。
   f のグリッド: 0.1, 0.2, 0.3, 0.5, 0.7, 1.0（既存の感度グリッドと対応させる）。
2. 注入後のデータに主解析と同一の α・τ フィットをかけ、差し引いて残差を得る。
3. 各 f で S(f) と、フィットされた α の変化 Δα（= α_injected − α_0）を記録する。
   α_0 は無注入時の値（H1 0.649、L1 0.592）。
4. 報告する量（事前に固定）:
   - フィット込みの f99（両窓、背景 p99 との交点。既存と同じ線形内挿）
   - 吸収率: 各 f での（注入した f − 残差に残った実効 f）/ f。
     実効 f は残差への寄与から推定する。目安として Δα/f が吸収の一次指標。
   - フィット後注入の f99（0.82 / 0.47）との比較表。

判定（事前）: フィット込み f99 がフィット後 f99 を上回れば、その差が
「フィットによる感度劣化」の実測である。下回ることは原理的にないはずで、
下回れば実装バグを疑う（注入がフィット前に入っていない等）。検出の主張は
しない。null の場合は上限として扱う（従来通り）。

## 4. Stage B — 波動光学レンズ注入（潰れない成分だけを測る）

目的: 現実のレンズが残すはずの周波数依存成分 A(f) に対する感度。
Stage A は「吸収される側の上限」を測るが、物理的に残るのはこちらだけである
（`collapse_mechanism.md`「潰れないもの（唯一の例外）」）。

1. 注入モデル: 2像の波動光学レンズ。パラメータはレンズ質量 M と衝突パラメータ y。
   質量範囲は **10²–10³ M_sun 級**（`zoom_analysis.md` §7。視線で署名が効く質量）。
   y のグリッドと M のグリッドは、A(f) のうなり周期が解析帯域 20–448 Hz に
   入る範囲で事前に選ぶ。グリッドの具体値はスクリプト作成時に固定し、
   本書の追記として記録する（実行前に決める。結果を見てから変えない）。
2. 注入は Stage A と同じく実ストレインへ、フィット前に行う。
   フィット込みで回収し、S と (M, y) ごとの f99 相当（= 検出に必要な増幅）を
   記録する。
3. 報告: (M, y) 平面上の感度マップ（回収できた領域／できなかった領域）。
   10% 級の増幅（f=0.10 相当）がどの (M, y) でも感度外なら、その旨を
   上限として明記する。

Stage B は Stage A の結果を見てから細部を決める。Stage A を飛ばして
Stage B だけを走らせることはしない（吸収の基準値なしに Stage B の
数字は解釈できないため）。

## 追記 (2026-11-15 実行時): Stage B グリッドの固定 (実行前に記録)

Stage A の結果 (フィット込み f99 は両窓ともグリッド上限 f=1.0 で交差なし,
S は f に依らず平坦, 吸収率の実測は報告書 `gw231123_inject_recover.md` 参照)
を確認したうえで, Stage B のグリッドを以下のとおり固定する. 結果を見て変更しない.

- レンズ質量 (赤方偏移込み質量 M_z): **100, 200, 400, 1000 M_sun**
- 衝突パラメータ: **y = 0.3, 0.5, 1.0, 2.0** (計 16 点)
- 歪みの全体スケール: **g = 0.1, 0.25, 0.5, 1.0, 2.0, 4.0**
  (注入は g*(F(f)-1)*h. g=1 が物理的なレンズ歪みそのもの)
- 選定基準: 2 像の時間差 Δt = 4 G M_z / c^3 * ΔT(y) から決まるうなり周期
  Δf = 1/Δt が解析帯域 20–448 Hz に入ること. 16 点中 13 点が
  20 <= Δf <= 448 Hz を満たす (Δf の範囲 24–421 Hz).
  境界ケースとして次の 3 点も地図の完全性のため残し, 報告書で明示する:
  (M, y) = (100, 0.3) Δf=843 Hz, (100, 0.5) Δf=502 Hz (帯域内に
  うなり 1 周期が入らない低質量・小 y 側), (1000, 2.0) Δf=11 Hz
  (帯域内に多数のうなりが入る高質量・大 y 側).
- F(f) の数値評価: scipy の hyp1f1 が複素引数を受け付けず, 複素128 の
  級数展開は大きな w*y^2 で桁落ちするため, mpmath (50 桁) で 0.25 Hz
  グリッドを直接評価し 3 次スプライン補間する. 帯域内ランダム点での
  直接評価との照合 (最大相対誤差) を数値ファイルに記録する.
