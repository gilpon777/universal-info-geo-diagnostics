## 0. 結論サマリ

1. **ChatGPT の負の q は正確に再現した。** 信号整合窓 (400, 1.0) で q = **−3.174×10⁻⁴**（ChatGPT の値 −3.17×10⁻⁴ と3桁一致）。S 直接フィット（M2: −5.26×10⁻⁵）、S0 自由（M3: −9.83×10⁻⁴）でも負であり、符号は方法に依らない。負の q はほかにも計画窓で3点、信号整合窓で2点ある。
2. **ChatGPT の p ≈ 0.86 / 0.76 は再現した。ただし、それは a 空間の通常最小二乗（OLS）の傾きとしてである**（計画窓 0.864±0.205, n=8／信号整合窓 0.759±0.233, n=10＝有意点のうち q>0）。交差項 b を落として反転すれば g99 空間でも同じ値になるが、b を含む完全な2次式から g99 を導出すると傾きは 1.13 / 1.63 となり、0.86 / 0.76 にはならない。ChatGPT の方法記述（「g99 を導出して回帰」）は反転の手順が不正確。
3. **Claude の p = 1.00 / 1.02 は OLS では再現しない。** 再現するのは **TLS（直交回帰・主軸回帰）** を M1 の a に適用した場合のみ（計画窓 0.999／信号整合窓 1.007）。ただし Claude の ±0.20 は TLS のジャックナイフ誤差（≈0.6）では再現せず、数値としては OLS の傾き標準誤差（0.205）と一致する。Claude の cosθ 要約統計（計画窓 平均−0.19・標準偏差0.26・n=16／信号整合窓 −0.08・0.28・n=17／最大0.54）と窓間 a 比（1.59±0.10、中央値1.53）は、M1–M3 のどの方法・どの自然な点集合でも再現しなかった。
4. したがって両者の数値に算術的な矛盾はない。**p はフィット方法と回帰方法を明示しないと意味を持たない**。「p=1.00±0.20」を確定値として扱うべきではない。
5. 解釈の格下げ（ChatGPT の整理）には**同意する**。根拠は §4。

- フィット方法:
  - **M1**: S²、S0 固定、OLS（S(g)²−S0² = b·g + q·g²）。ChatGPT・Claude が明示した方法。
  - **M2**: S そのものを非線形最小二乗（S0 固定、モデルは sqrt(S0²+b·g+q·g²)）。

  - **M4**: S²、S0 固定、q ≥ 0 制約。
- p の定義は2通り: **a 空間** = log a vs log osc_proj の回帰傾き（a=√q）。**g99 空間** = フィット係数から解いた g99（S(g99)=p99）の log–log 回帰傾きの符号反転。b=0 でない限り両者は一致しない。

## 4. 物理的解釈への見解：格下げに同意する

ChatGPT の整理 —「S² の2次式は経験的近似としては使えるが、cosθ をベクトル間角度として扱ったり実効次元 D を直接推定したりするのは慎重であるべき」— に**同意**する。根拠:

1. **S はベクトルのノルムではない**（コードで確認）。`gw231123_inject_recover.py` の `xcorr_stat` は、白色化した残差同士の**正規化相関**をラグ ±50 ms（LAG_MAX=0.050）の範囲で走査し、その**最大絶対値**を返す。S ∈ [0, 1] で上限があり、注入で分子だけでなく分母（残差のノルム）も変わり、最大化するラグは跳び得る。さらに残差そのものが注入ごとに α・τ を再フィットして得られるため、「雑音ベクトル＋g×応答ベクトル」という固定した内積空間での和の形をしていない。b = 2aS0cosθ は2次係数の**代数的な読み替え**であって、測られた内積ではない。
2. **直接の反証が係数自身に出ている**。真の余弦なら |cosθ| ≤ 1 のはずが、M1 では +5.03、+3.57、+1.29 が出る（§2）。真のノルムの2乗係数なら q ≥ 0 のはずが、両窓で3点ずつ負になる。2次式は局所的な経験フィットとしては良い（有意点の rms(S) は多くが 0.001–0.02）が、恒等式ではない。
3. **19点は独立ではない**。全点が同一の実ストレイン区間・同一の背景を使い、S0 は窓ごとに文字どおり同一の数値である。点ごとの cosθ を「ランダムな向きの独立試行」として扱う確率計算（Claude §3.2(d) の 2×10⁻⁸）も、その広がりから実効次元 D≈13–15 を読む推論も、前提（独立性＋等方ランダムモデル）が成り立たない。Claude 自身が §3.3 で独立な交差項の仮定を棄却して共通モードに改訂した以上、§3.2(d) の D と確率は、その改訂と矛盾する形で残っている。撤回するか、「独立性を仮定した目安」と明記すべき。
4. **残るもの**。S² の2次式は経験的な応答モデルとして保持できる。a は g99 よりノイズに鈍感な応答の物差しになり得るし、a が osc_proj とともに増えること自体は全方法で支持される（a 空間の傾きは方法・集合で 0.58–1.14 と幅があるので、「p=1」と読むのではなく「正の相関がある」と読むのが妥当）。背景 p99 の窓比 1.46（予測 1.49）はベクトルモデルに依らない経験的事実として残る。一方、窓間 a 比は本検証では Claude の値に届かなかった（§3）ので、L⁻¹ᐟ² の応答側の検証は係数公開後にやり直すのがよい。

## 5. 限界

- Claude のフィット／回帰コードと全点の係数表が未公開のため、「TLS が Claude の方法である」は同定ではなく、点推定を再現する唯一の候補という意味。
- 本検証は保存 JSON の S(g) 系列のみに基づく。S の再計算（注入・回収の再実行）はしていない。
- 多実現化すれば cosθ の分布と D の議論は原理的に検証可能になるが、それは新しい実行段階であり、本検証の範囲外。
